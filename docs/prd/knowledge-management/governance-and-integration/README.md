# 知识管理治理与集成决策

> 本目录承载五篇核心 PRD 中的第四、第五篇，使上级目录在包含规划文档和前三篇 PRD 后仍符合每目录不超过五个内容项的约束。

## 文档列表

1. [协作、权限与隐私治理](./collaboration-permission-and-privacy.md) — 定义主体责任、协作流程、动作级授权、学生隐私、保留删除、审计和真实数据 P0 门禁。
2. [构建与集成决策](./build-and-integration-decision.md) — 定义 AAF 自研主链、供应商中立解析 Adapter、WeKnora 候选证据、准入基准、运维和退出策略。

## 与上级文档的关系

两篇文档延续上级目录的场景、统一对象和生命周期合同。权限文档约束所有读取与处理动作；构建文档只决定能力如何实现，不得放宽产品权限、来源、质量和生命周期要求。
