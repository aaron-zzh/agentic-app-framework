# 知识管理产品需求

> 以高校教师与学生场景为先，融合文件、档案和企业知识管理方法，规划极简、通用、可信的知识管理产品。

## 文档列表

1. [场景与产品范围](./scenarios-and-product-scope.md) — 定义高校核心场景、相邻管理场景、阶段范围、成功指标与业务验收标准。
2. [统一对象与极简信息架构](./object-model-and-information-architecture.md) — 定义单一知识入口、统一身份、最小本体、投影视图和一致性验收合同。
3. [知识资产生命周期与多模态](./knowledge-lifecycle-and-multimodal.md) — 定义来源权威、多模态采集、治理档案、可信应用、质量指标与生命周期验收合同。
4. [协作、权限与隐私治理](./governance-and-integration/collaboration-permission-and-privacy.md) — 定义主体责任、首期协作、动作级授权、学生隐私、保留删除与安全门禁。
5. [构建与集成决策](./governance-and-integration/build-and-integration-decision.md) — 定义 AAF 自研主链、解析 Adapter 准入、WeKnora 候选证据、运维与退出策略。
6. [PRD 文档大纲规划](./prd-outline-plan.md) — 定义五篇核心 PRD 的边界、大纲、细化顺序与验收门槛。
