# 用户旅程

以自助为主流程，人工服务作为升级出口和高龄、机构场景的服务方式。两条流程共用一个移动端和同一份家族档案。

一期只上线一图一事：子女购买并邀请爸妈，老人配几张照片讲一件事（1 到 3 分钟），预览后发给家人，旅程见 [一图一事 产品方案 主流程](切入点/产品方案.md#主流程)。下文的自助主流程（AI 对话访谈、事实卡片、润色）从二期起适用；人工流程随人工访谈后推，进入条件见 [产品定位 阶段路线](产品定位.md#阶段路线)。

## 角色

| 角色 | 说明 | 使用的端 |
|------|------|---------|
| 讲述者 | 老人。会用手机的自己使用自助版；高龄老人由交付人员访谈，不需要操作设备 | 移动端老人模式 |
| 家属 | 子女和家人：陪同、补充、共享、付费、升级；人工流程中确认时间线和《事实核对报告》 | 移动端家属模式 |
| 交付人员 | 自营团队成员或 OPC：人工访谈、整理、成稿、核对 | 移动端交付模式、工作台 Web |
| 机构人员 | 养老机构管理者、护理员、社工：组织老人，使用照护档案 | 移动端机构模式、管理 Web |
| 平台运营 | 顾问、品控、OPC 派单与结算 | 管理 Web |

## 三种入口

| 入口 | 起点 | 进入的流程 |
|------|------|-----------|
| 老人自己开始 | 看到家人分享的短片、老年大学工作坊、短视频内容 | 自助主流程 |
| 子女为父母开通 | 子女扫码创建档案，邀请父母加入，或陪同父母使用 | 自助主流程；父母用不了手机时转人工 |
| 机构或高端定制 | 机构签约试点、家族传承定制、寿宴节点 | 人工流程；档案同样开放给家属 |

## 自助主流程

```text
开通与授权 → 对话讲述（多次） → 确认事实卡片 → AI 整理润色 → 预览与生成
     → 分享给家人 → 家人加入、补充 → 长期档案与订阅 → 需要时升级人工
         ↑                                    │
         └──────── 每周提问、继续讲述 ←──────┘
```

### 开通与授权

| 项 | 内容 |
|----|------|
| 参与角色 | 讲述者，可由子女陪同 |
| 关键动作 | 微信登录进入老人模式；语音朗读授权说明，老人本人分项授权（内容、声音、肖像）；填写方言和不想谈的话题 |
| 确认卡点 | 老人本人授权，子女不能代替 |
| 流转条件 | 内容采集授权完成 |

### 对话讲述

| 项 | 内容 |
|----|------|
| 参与角色 | 讲述者；子女可陪同或远程提问 |
| 关键动作 | 每次 10 到 15 分钟，AI 按人生阶段和老照片提问并追问；可以上传老照片后对着照片讲；每次讲完生成一段小短片 |
| 确认卡点 | 老人随时可以停下、跳过问题；不想谈的话题不会被问到 |
| 流转条件 | 一次对话结束即可进入确认；也可以先连续讲几次再确认 |

### 确认事实卡片

| 项 | 内容 |
|----|------|
| 参与角色 | 讲述者，子女可协助 |
| 关键动作 | 系统把对话中的时间、地点、人物、事件做成大字卡片并朗读；老人选"对""要改""删掉" |
| 确认卡点 | 只有确认过的卡片能用于润色和生成文字 |
| 流转条件 | 本次对话的卡片处理完毕 |

### AI 整理润色

| 项 | 内容 |
|----|------|
| 参与角色 | 系统 |
| 关键动作 | 用已确认的卡片和原话生成标题、字幕、旁白、电子小传章节；高风险内容不润色；生成后逐句反向溯源 |
| 确认卡点 | 找不到来源的句子自动删除 |
| 流转条件 | 生成完成 |

规则见 [产品定位 内容规则](./产品定位.md#内容规则先确认事实再润色)。

### 预览与生成

| 项 | 内容 |
|----|------|
| 参与角色 | 讲述者或家属 |
| 关键动作 | 完整预览短片或小传，可删除任意段落；确认后生成正式文件；生成、重新生成和按需印刷消耗积分，余额不足时提示家属充值 |
| 确认卡点 | 未完整预览不能生成正式文件和分享链接 |
| 流转条件 | 正式文件生成 |

### 分享与家人加入

| 项 | 内容 |
|----|------|
| 参与角色 | 讲述者、家属 |
| 关键动作 | 把短片发到家族群；家人点开后受邀加入档案，可以补充照片、补充记忆、给老人留言提问 |
| 确认卡点 | 分享默认只对受邀家人可见；家人补充的内容标注来源人，涉及老人的事实仍需老人确认 |
| 流转条件 | 无终态，进入长期档案 |

## 长期档案

| 项 | 内容 |
|----|------|
| 参与角色 | 讲述者、家属 |
| 关键动作 | 每次讲述、照片、家人补充都合并到同一份人生记忆图谱；子女设置每周提问；节日和生日提醒；每年生成一次更新版；随时导出全部资料 |
| 确认卡点 | 老人决定分享范围；指定档案继承人 |
| 付费 | 家属充值积分，用到 AI 的地方按用量扣；记忆托管订阅：长期存储、家属共享、每年增量访谈与更新版、每月赠送积分 |
| 流转条件 | 无终态，档案持续存在直到申请注销 |

## 升级人工

自助用户在以下情况升级为人工服务：

- 想要正式出版级的故事书，需要深度编辑和《事实核对报告》。
- 老人讲到一定程度后不想再用手机，或身体原因无法继续。
- 寿宴、金婚等节点需要按日期交付。

升级时，已确认的事实卡片、录音、照片直接带入人工流程，交付人员从已有素材出发补采，不重新开始。订单由自营团队承接；第 6 到 12 个月起可派给众包 OPC。

## 人工流程

适用于自助升级、高龄老人、养老机构和高端定制。

```text
线索与签约 → 授权 → 访谈 → 转写与结构化 → 成稿 → 事实核对与确认 → 交付 → 进入长期档案
               ↑                   │                     │
               └──── 补采 ←────────┴──── 存疑退回 ←──────┘
```

每个阶段对应 [智能体工作流](../../design/memoir/agent-workflow.md) 中的一层或几层。

### 线索与签约（L1）

| 项 | 内容 |
|----|------|
| 参与角色 | 家属或机构、顾问 |
| 关键动作 | 自助升级时直接带入已有档案；新客户填写预问卷（基本信息、健康状况、话题禁忌、方言）；顾问查看 AI 可行性评估；选择 SKU 和增值项，签约付款 |
| 人工卡点 | 顾问确认能否接单（健康状况不适合访谈的不接） |
| 流转条件 | 签约完成，首期款到账；平台派单给自营交付人员或 OPC |

### 授权

| 项 | 内容 |
|----|------|
| 参与角色 | 讲述者，必要时监护人 |
| 关键动作 | 自助阶段已授权的项目沿用授权，新增用途补授权；无法自主表达时由监护人代为授权并上传证明 |
| 人工卡点 | 交付人员现场向讲述者朗读授权说明并确认理解；监护人代授权需顾问审核 |
| 流转条件 | 内容采集授权完成 |

授权规则见 [伦理与合规 授权原则](伦理合规.md#授权原则)。

### 访谈（L2）

| 项 | 内容 |
|----|------|
| 参与角色 | 讲述者、交付人员；机构场景下护理员在场 |
| 关键动作 | 从已有档案的空缺处补采；按人生阶段分次访谈；用老照片、老物件、年代歌曲唤起记忆 |
| 人工卡点 | 交付人员主导对话和情绪照顾，判断是否追问敏感话题 |
| 流转条件 | 计划访谈完成 |

访谈安全：日常单次 45 到 60 分钟，上限 2.5 小时，超时提醒交付人员；讲述者不适即终止；讲述者只需要说话，不需要操作设备。

### 转写与结构化（L3、L4）

| 项 | 内容 |
|----|------|
| 参与角色 | 交付人员、家属 |
| 关键动作 | 方言转写、说话人分离、事件抽取、时间线和矛盾标记；自助阶段确认过的卡片作为中等强度证据并入；交付人员抽审转写；家属确认时间线 |
| 人工卡点 | 抽审 10% 转写；家属确认时间线 |
| 流转条件 | 时间线确认，关键事件无"存疑"；有空缺时退回访谈补采。家属 7 个工作日未确认时，中低风险条目默认通过，高风险条目不能默认通过，规则见 [事实核对模块 时限](../../design/memoir/fact-check-engine.md#时限) |

### 成稿（L5）

| 项 | 内容 |
|----|------|
| 参与角色 | 交付人员 |
| 关键动作 | 选择章节大纲和叙事主线；生成保留原话的初稿；重写关键段落，添加编者注 |
| 人工卡点 | 编辑重写关键段落，确认改写没有改变原意 |
| 流转条件 | 编辑提交初稿 |

### 事实核对与确认（L6）

| 项 | 内容 |
|----|------|
| 参与角色 | 交付人员、讲述者、家属 |
| 关键动作 | 系统生成事实核对清单，逐条附来源；交付人员逐条核实；作品朗读给讲述者听；家属审阅《事实核对报告》并签字 |
| 人工卡点 | 逐条人工核实；讲述者确认；家属签字 |
| 流转条件 | 讲述者和家属均确认；无法核实的事实已删除或标为编者注；不通过时退回成稿或补采。家属 7 个工作日未确认时，中低风险项默认通过；高风险项和《事实核对报告》签字不能默认通过，长期未确认时可先交付已闭环章节组成的分册版 |

### 交付（L7）

| 项 | 内容 |
|----|------|
| 参与角色 | 交付人员、家属；机构场景下机构人员 |
| 关键动作 | 排版、原声二维码、人生短片；印刷；作品并入家族档案并共享给家人；机构场景下交付照护档案和试点报告 |
| 人工卡点 | 设计终审、印刷质检；OPC 交付的作品由平台品控抽查 |
| 流转条件 | 家属验收，尾款结清；作品进入长期档案 |

## 适老化要点

- 老人模式首页只有"开始讲故事"、本周提问和"我的短片"，大字、语音为主、一屏一件事。
- 每次自助对话 10 到 15 分钟，讲完立刻有回报。
- 所有确认都有语音朗读，老人不需要打字。
- 子女可以远程帮忙，但授权和事实确认必须由老人本人完成。
