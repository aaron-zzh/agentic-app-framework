# 一期需求规格（一图一事）

本文细化 [产品功能](产品功能.md) 中标"P0（一期）"的范围，产品方案见 [一图一事 产品方案](切入点/产品方案.md)，验证方案见 [一图一事 验证计划](切入点/验证计划.md)。2026-11-11 经人类确认，一期从"AI 对话访谈自助闭环"改为一图一事；原方案 A 的完整规格保存在 [后续需求规格](后续需求规格.md)，作为二期和后推阶段的基线。

> **编号说明**：本文的 P0-01 到 P0-14 是一期的规格分组，从 P0-01 重新编号，与 [后续需求规格](后续需求规格.md)（原方案 A）的 P0-01 到 P0-18 **互不对应**。例如本文 P0-09 是"家族档案与家人加入"，原方案 A 的 P0-09 是"事实核对"。设计文档中未注明来源的 P0 编号指原方案 A。

数据表与接口草案见 [P0 数据与接口设计 一期一图一事](../../design/memoir/p0-data-api.md#一期一图一事)；任务卡见 [一期任务](一期任务.md)。

## 范围

一期是一个微信小程序，按登录身份进入老人模式和家属模式（子女与家人共用家属模式），在 AAF 已有的初始框架上构建：账号与小程序登录、权限、审计日志、对象存储、异步任务、模型网关、AI 用量记录、EntityDef 管理后台、支付与通知。一期不重复建设这些平台能力。研发估算为 2 名全栈 3 到 4 周，见 [产品方案 研发估算](切入点/产品方案.md#研发估算)，由 architect 在技术设计后校准。

**一期包含**：

- 统一账号与身份切换；老人模式、家属模式
- 老人本人分项授权、撤回与留痕
- 子女购买固定价故事包（尝鲜包、月度包、年度故事包）与首段退款
- 邀请爸妈（称呼、一句语音、邀请卡片）
- 每周话题（52 个话题库、节日与生日话题）与子女出题
- 一图一事讲述：1 到 9 张照片或翻拍老照片，按住说话 1 到 3 分钟
- 原声短片生成：字幕用转写原文，标题从原话摘取，不润色；高风险规则检测
- 预览与发布：本人点"发给家人"后才对家人可见；撤回与删除
- 家族档案、家人邀请与加入；新故事通知
- 家人留言（文字或语音）与语音播报给老人
- AI 内容标识（显式与隐式）、内容安全审核、投诉举报入口
- 运营后台（EntityDef 声明）：档位与价格、订单与退款、话题库、内容复核、投诉、导出与删除请求
- 埋点与 AI 用量记录

**一期不包含**：

- AI 多轮对话访谈、事实确认卡片、受约束润色、电子小传、家人补充记忆，放在二期，一图一事 W6 中期检查达标后启动研发
- 积分充值与按用量扣费；记忆托管订阅（年度故事包次年续费价只在购买页展示）
- 人工访谈与成书交付、交付模式与工作台、顾问、机构、OPC 与派单、运营的订单项目管理，后推到成书订单稳定之后
- 方言专项优化（首发只保证普通话识别效果）；声音克隆、数字人、图生视频；逝者相关功能
- 产品方案中标"后置"的项：兄弟姐妹共同续费、家人补照片、照片与讲述内容对应切换、老照片修复，按验证期数据决定是否加入

二期和后推内容的规格见 [后续需求规格](后续需求规格.md)，进入条件见 [产品定位 阶段路线](产品定位.md#阶段路线) 和 [验证计划 决策路径](切入点/验证计划.md#决策路径)。

**模型选型**：AI 能力全部使用在线模型和云服务，优先阿里云百炼，经 AAF 模型网关调用，可按配置切换；不自建、不自部署模型和合成服务。

| 能力 | 用途 | 服务（初选） |
|------|------|------------|
| 语音识别 | 讲述转写（带时间戳）、语音留言和子女邀请语音转写 | 百炼 fun-asr |
| 文本模型 | 标题摘取、字幕断句、高风险规则辅助判定 | 百炼 qwen3.8-flash |
| 语音合成 | 话题朗读、授权说明朗读、文字留言播报 | 百炼语音合成模型，话题和授权说明预生成并缓存 |
| 内容安全 | 照片、文本、语音转写审核 | 阿里云内容安全，加百炼模型自带安全审核 |
| 模板合成 | 照片推拉、转场、原声、字幕、片尾合成竖屏短片 | 阿里云智能媒体服务 |

**优先级与降级原则**：发布标准是四条主链路端到端可用，而不是功能数量齐全。燃尽落后时先降级界面和效果，以下护栏不降级：

- 本人授权校验；未确认的故事对家人不可见；高风险段落默认仅本人可见
- 字幕和标题只来自转写原文；AI 内容标识；内容安全审核
- 支付、退款与订单状态一致

可降级项与降级方式：

| 项 | 降级方式 |
|----|---------|
| 照片推拉效果 | 改为静态照片加淡入淡出 |
| 配乐开关 | 固定低音量配乐，不提供开关 |
| 节日与生日话题 | 只按话题库顺序推送 |
| 语音留言 | 只保留文字留言（文字仍语音播报） |
| 出片时间 | 超过 1 分钟时提示"做好了会通知您"，生成完成后通知老人 |
| 运营后台 | 只保留订单与退款、内容复核、投诉三个实体，其余由运营在数据库工具中处理并留审计日志 |

## 目标与验收指标

**一期目标**：老人收到子女的邀请后，自己完成"授权 → 看话题 → 选照片 → 按住说话 → 预览 → 发给家人"，家人看到并回应；用 W5 到 W10 的真实付费回答 [验证计划](切入点/验证计划.md) 的四个问题：老人会不会讲第二段、子女会不会再付钱、家人会不会加入和扩散、故事攒多以后有没有家庭想要书。

**验证指标**：指标定义与建议达标线以 [验证计划 指标与达标线](切入点/验证计划.md#指标与达标线) 为准，下表只列达标线和检查时点，计算所用的事件见 [埋点与指标](#埋点与指标)。

| 指标 | 建议达标线 | 检查时点 |
|------|----------|---------|
| 老人激活率 | 70% | W6 中期检查、W10 |
| 第二段留存 | 50% | W6 中期检查、W10 |
| 4 周留存 | 30% | W10 |
| 子女复购 | 30% | W10 |
| 家人加入率 | 50% | W10 |
| 自然扩散 | 0.2 以上 | W10 |
| 成书询问 | 每 100 个付费家庭 3 个以上 | W10 |
| 单段成本 | 0.5 元以下 | 每周 |
| 首单转化、退款率、档位分布 | 只观察；退款率超过 15% 时复盘原因 | 每周 |

W6 中期检查时老人激活率和第二段留存都达标，启动二期研发；不达标时研发继续迭代一期。W10 验证报告按 [验证计划 决策路径](切入点/验证计划.md#决策路径) 给出结论。

**护栏指标**：从 W4 发布起持续监测，任何一项不达标即视为缺陷，按 P0 Bug 处理。

| 护栏 | 验收线 |
|------|-------|
| 出片时间 | 从松开最后一次"按住说话"并提交，到预览可播放：P90 不超过 60 秒，P99 不超过 3 分钟（建议值） |
| 授权流程时长 | 老人从打开邀请卡片到完成授权，中位数不超过 3 分钟 |
| 未确认不可见 | 状态不是"已发布"的故事被老人以外的账号访问成功的次数为 0 |
| 高风险默认仅本人可见 | 命中高风险规则的故事 100% 停在"未确认"等待老人决定，标题 100% 使用话题名 |
| 不润色 | 字幕和标题中不在转写原文里的字数为 0（允许去掉口头语和加标点） |
| AI 标识 | 生成的短片 100% 带显式标识和隐式标识；分享卡片和播放页 100% 显示标识 |
| 内容安全 | 内容安全命中的照片、文字、语音在复核通过前对他人展示的次数为 0 |
| 本人授权 | 以家属身份完成授权、发布、撤回操作的成功次数为 0 |
| 档案隔离 | 非档案成员访问档案列表、未分享故事的成功次数为 0 |
| 订单一致 | 订单状态与微信支付、退款结果的差异数为 0（每日对账） |

## 角色与权限

| 角色 | 是谁 | 系统身份 | 说明 |
|------|------|---------|------|
| 子女（付费人） | 购买故事包并邀请爸妈的子女 | 家属 | 订单的付款人；老人接受邀请并完成授权后，自动成为该老人家族档案的成员 |
| 老人（讲述者） | 接受邀请的老人本人 | 讲述者 | 一位老人只有一份家族档案；故事归老人所有 |
| 家人 | 兄弟姐妹、孙辈、亲戚 | 家属 | 经邀请加入档案的成员；未加入时只能看被分享的单条短片 |
| 平台运营 | 平台内部人员 | 运营 | 在运营后台处理订单、退款、话题库、内容复核、投诉和导出删除请求 |

一个人可以同时是讲述者和家属（例如为自己父母开通的 60 多岁子女），登录后选择模式。

| 操作 | 老人 | 子女（付费人） | 家人（成员） | 平台运营 |
|------|------|-------------|------------|---------|
| 购买故事包、为该老人续费 | 否 | 是 | 一期否（共同续费后置） | 否 |
| 申请首段退款 | 否 | 是（本人付款的订单） | 否 | 处理 |
| 邀请爸妈 | 否 | 是 | 是（为自己的长辈，走新的购买与邀请） | 否 |
| 本人授权、撤回授权 | 是 | 否 | 否 | 否 |
| 出题 | 否 | 是 | 是 | 维护话题库 |
| 讲述、重讲 | 是 | 否 | 否 | 否 |
| 预览、发给家人、撤回、删除故事 | 是 | 否 | 否 | 内容安全或投诉处置时可下架 |
| 查看未发布的故事 | 是 | 否 | 否 | 仅复核队列或投诉中的故事 |
| 查看已发布的故事 | 是 | 是 | 是 | 仅复核队列或投诉中的故事 |
| 邀请家人加入档案 | 是（扫码即加入） | 是（需老人同意） | 是（需老人同意） | 否 |
| 同意加入、移除成员 | 是 | 否 | 否 | 否 |
| 留言 | 否 | 是 | 是 | 否 |
| 查看剩余段数和到期时间 | 否 | 是 | 是 | 是 |

老人端任何页面都不出现价格、余额、套餐和段数。

## 主链路

### 链路 P：购买与邀请

```text
子女进入购买页 → 选档位 → 微信支付 → 填爸妈称呼、录一句 10 秒以内的话 → 生成邀请卡片
→ 在微信里发给爸妈 → 老人点开卡片 → 听子女那句话和语音说明 → 本人授权
→ 订单生效，子女成为档案成员，子女收到"爸妈已开通"通知
```

- 子女可以先付款后邀请，也可以为已开通的老人续费；每笔订单绑定一位老人。
- 老人已有家族档案时（例如另一个子女已为其开通），接受邀请后不新建档案，新订单的段数并入该老人，邀请人成为档案成员。
- 老人 7 天未接受邀请时提醒子女重发；子女可随时申请退款，规则见 [P0-04](#p0-04-故事包购买与退款)。

### 链路 T：老人讲述与发布

```text
老人打开小程序 → 首页看本周话题（语音朗读）→ 选 1 到 9 张照片或翻拍，或不选照片
→ 按住说话 1 到 3 分钟（可松开再继续、可重录）→ 提交 → 约 1 分钟出片
→ 完整预览 → 点"发给家人"（对家人可见，通知子女和成员）或点"重讲"
→ 不点任何按钮时这段只有老人自己可见
```

命中高风险规则时，标题改用话题名，预览页提示老人"这段提到了别人"，由老人决定是否发给家人；内容安全命中时进入运营复核，复核通过前不能预览发布。

### 链路 F：家人加入与留言

```text
老人或子女把短片卡片转发到家庭群 → 家人点开看这一条短片 → 点"加入家族档案"
→ 加入（老人发出的邀请直接加入；成员发出的邀请等老人同意）→ 看全部已发布故事
→ 对某段故事留文字或语音 → 老人收到提醒，文字用语音读给老人听，语音直接播放
→ 片尾和档案页"给自家长辈也开一个" → 进入链路 P
```

### 链路 R：续费与退款

```text
段数用完或临近到期 → 提醒付费子女（老人端只提示"请家人续费"）→ 子女在档案页续费 → 新订单生效

首段生成后不满意 → 子女在订单页申请退款 → 符合条件自动原路退款 → 订单剩余段数作废
→ 已生成的故事保留在老人档案中
```

不做自动续费。月度包和年度故事包到期前提醒子女手动续费。

## 状态机

### 故事卡片

每段讲述存成一张故事卡片，字段见 [产品方案 故事卡片](切入点/产品方案.md#故事卡片)。产品方案中的三种确认状态（未确认、已发布、已撤回）对应下表的 PENDING、PUBLISHED、WITHDRAWN，其余状态是生成和审核过程中的状态，对家人都不可见。

```text
GENERATING ──→ PENDING ──→ PUBLISHED ⇄ WITHDRAWN
    │  ↑          │
    │  └──重讲────┘
    ├──→ IN_REVIEW ──→ PENDING | BLOCKED ──重讲──→ GENERATING
    └──→ FAILED ──重试──→ GENERATING

除 GENERATING、IN_REVIEW 外的任意状态 ──老人删除──→ DELETED
```

| 状态 | 含义 | 谁可见 |
|------|------|-------|
| GENERATING | 已提交，正在转写、检测、合成 | 老人（显示"正在做"） |
| IN_REVIEW | 内容安全命中，等待运营复核 | 老人（显示"稍等一下"）、复核运营 |
| BLOCKED | 复核不通过，不能发给家人 | 老人（显示"这段暂时不能发给家人，可以重讲"） |
| FAILED | 自动重试后仍生成失败，录音和照片已保存 | 老人（显示"稍后为您做好"） |
| PENDING（未确认） | 生成完成，等待老人预览和决定 | 仅老人 |
| PUBLISHED（已发布） | 老人点了"发给家人" | 老人和档案成员；分享卡片持有者只能看这一条 |
| WITHDRAWN（已撤回） | 老人撤回，或因授权撤回、运营处置下架 | 仅老人 |
| DELETED | 老人删除，原声、照片、转写、短片一并删除 | 无 |

| 状态转换 | 放行条件 |
|---------|---------|
| 提交 → GENERATING | 老人以讲述者身份登录；内容采集、声音使用、照片用于短片三项授权有效；有可用段数或可用透支（见 [P0-04](#p0-04-故事包购买与退款)）；录音时长不少于 10 秒 |
| GENERATING → PENDING | 转写完成；字幕和标题通过原文校验（不含转写原文以外的字）；高风险规则检测完成并写入标记；照片、转写、标题通过内容安全审核；短片带显式和隐式 AI 标识 |
| GENERATING → IN_REVIEW | 任一照片、转写或标题命中内容安全 |
| GENERATING → FAILED | 生成失败自动重试 3 次仍失败；服务恢复后由系统自动重新进入 GENERATING，成功后通知老人 |
| IN_REVIEW → PENDING / BLOCKED | 运营复核通过 / 不通过，复核结果和处理人留痕 |
| PENDING → GENERATING（重讲） | 老人点"重讲"并确认"上一段会被替换"；新录音替换上一版，不重复扣段数 |
| PENDING → PUBLISHED | 本次预览播放到结尾；老人本人点"发给家人"；三项必选授权仍有效。命中高风险规则的故事同样需要老人主动点击，系统不自动发布 |
| PUBLISHED → WITHDRAWN | 老人撤回；老人撤回声音使用或照片用于短片授权；运营因投诉或内容安全下架（留痕并通知老人）。撤回后分享卡片立即失效 |
| WITHDRAWN → PUBLISHED | 老人重新完整预览后点"发给家人"；运营下架的故事需运营解除后才能重新发布 |
| 任意 → DELETED | 老人点删除并二次确认；删除不可恢复，删除结果可查询 |

每次状态变更记录操作人、时间、原因和设备。

### 故事包订单

```text
PENDING_PAYMENT ──支付成功──→ PAID ──老人完成授权──→ ACTIVE ──→ EXHAUSTED | EXPIRED
       │                       │                     │
       └──超时──→ CLOSED        └─────申请退款────────┴──→ REFUNDING ──→ REFUNDED
                                                                │
                                                                └──失败或驳回──→ 原状态
```

| 状态 | 含义 |
|------|------|
| PENDING_PAYMENT | 已下单，等待支付 |
| CLOSED | 30 分钟未支付或用户取消 |
| PAID | 已支付，绑定的老人尚未完成授权，有效期未开始 |
| ACTIVE | 生效中，可扣段数 |
| EXHAUSTED | 段数已用完（尝鲜包 3 段、月度包 20 段），有效期内不能再扣 |
| EXPIRED | 有效期结束，剩余段数作废 |
| REFUNDING | 退款处理中，暂停扣段数 |
| REFUNDED | 已原路退款，剩余段数作废 |

| 状态转换 | 放行条件 |
|---------|---------|
| PENDING_PAYMENT → PAID | 收到微信支付成功回调且金额、订单号校验一致；重复回调幂等处理 |
| PAID → ACTIVE | 绑定的老人完成本人授权；为已授权老人购买时支付成功即生效。有效期从生效时起算（建议值） |
| ACTIVE → EXHAUSTED | 已扣段数等于档位段数；年度故事包不设段数上限，不进入此状态 |
| ACTIVE / EXHAUSTED → EXPIRED | 到达有效期：月度包生效后 30 天，年度故事包生效后 365 天，尝鲜包生效后 90 天（三项均为建议值） |
| PAID / ACTIVE → REFUNDING | 付款子女申请且符合退款条件（见 [P0-04](#p0-04-故事包购买与退款)），或运营在投诉处理中发起 |
| REFUNDING → REFUNDED | 收到微信退款成功回调 |
| REFUNDING → 原状态 | 退款失败或运营驳回，原因留痕并通知子女 |

扣段数规则：一段故事首次进入 PENDING 或 IN_REVIEW 时扣 1 段；重讲、生成重试、复核不通过后重讲不再扣。同一老人有多笔生效订单时，先扣最早到期的订单。

## P0 功能规格

### P0-01 账号与身份

对应：MEM-001、MEM-002、MEM-004、MEM-005

- **输入**：微信登录；手机号授权为可选。
- **输出**：一个账号可以拥有讲述者和家属两种身份；登录后进入对应模式，可随时切换。
- **规则**：
  - 一期只有老人模式和家属模式，不出现交付模式和机构模式入口。
  - 老人模式首页只有本周话题大卡片、"我的故事"和新留言提醒；正文字号不小于 20pt，一屏一件事，所有文字可语音朗读；不出现价格、余额、套餐和段数。
  - 家属模式首页为已加入的档案列表、购买入口、出题入口、新故事列表。
  - 权限按身份和档案分配；身份切换和敏感数据访问（原声、照片、转写）记审计日志。
- **验收**：以家属身份看不到未加入档案的任何内容；以家属身份调用讲述、授权、发布接口被拒绝；切换记录 100% 写入审计日志。

### P0-02 本人授权

对应：MEM-201、MEM-202、MEM-203

- **输入**：老人点开邀请卡片后进入授权页。
- **输出**：授权记录（授权项、授权文本版本、时间、方式、授权人账号、设备）。
- **授权项**：
  - 内容采集、声音使用、照片用于短片：为必选项，不授权则无法出片，见 [产品方案 老人端](切入点/产品方案.md#老人端)。
  - 案例展示：可选，默认不勾选；授权后官方账号才能把指定的故事用于对外内容。
- **规则**：
  - 每项一屏，大字号加语音朗读，一句话说明"这项授权会让你的声音或照片用在哪里"；每项由老人逐项点"同意"，不预先勾选。
  - 授权只能由讲述者身份完成；发出邀请的子女账号不能接受自己的邀请成为讲述者。子女在老人手机上代为点击在技术上无法区分，一期靠语音说明和逐项确认降低风险，在验证期联络人回访中观察。
  - 声纹、人脸等敏感个人信息在隐私政策中单独同意，与授权页一并完成。
  - **撤回**：老人在"我的"中可撤回任一授权。撤回内容采集后不能开始新的讲述；撤回声音使用或照片用于短片后，已发布的故事全部转为 WITHDRAWN；撤回案例展示后，运营在 3 个工作日内下架官方账号上的相关内容（建议值）。原始素材在老人删除前保留。
- **验收**：未完成三项必选授权时无法开始讲述；以家属身份调用授权接口被拒绝；授权和撤回记录 100% 留痕并可导出；授权流程时长达到护栏线。

### P0-03 邀请爸妈

对应：MEM-823

- **输入**：子女填写的称呼（如"爸""妈""外婆"，不超过 10 字）；子女录制的一句话（不超过 10 秒，可重录）；绑定的订单（可先付款后邀请）。
- **输出**：小程序分享卡片，标题含称呼，点开后先播放子女的那句话。
- **规则**：
  - 一个子女可以邀请多位老人（如两边父母），每位老人一张邀请卡片，各自绑定订单。
  - 邀请卡片 7 天有效，只能被一个讲述者账号接受；过期或已被接受后点开提示"邀请已失效，请联系家人"。子女可重新生成。
  - 接受邀请的账号已是某份档案的讲述者时，不新建档案，订单并入该老人，邀请人加入该档案。
  - 子女的语音转写后与称呼一起过内容安全审核。
  - 子女可在档案页选填老人生日，用于生日话题（建议，待确认）。
  - 子女在订单页看到邀请状态：已发送、已打开、已授权；7 天未授权时提醒子女。
- **验收**：一张邀请卡片被第二个账号接受的成功次数为 0；同一老人重复受邀时档案数为 1；邀请打开和授权完成事件 100% 上报。

### P0-04 故事包购买与退款

对应：MEM-821

- **档位**：价格和段数按 [商业模式 定价](切入点/商业模式.md#定价)，由运营在后台配置，下单时锁定价格。

  | 档位 | 价格 | 段数 | 有效期（建议值） |
  |------|------|------|---------------|
  | 尝鲜包 | 9.9 元 | 3 段 | 生效后 90 天 |
  | 月度包 | 29.9 元 | 最多 20 段 | 生效后 30 天 |
  | 年度故事包 | 首年 99 元 | 不限段数 | 生效后 365 天；次年按记忆托管订阅价（299 元起）续费 |

- **购买**：
  - 微信支付；购买页写明段数、有效期、退款条件；年度故事包写明"首年价"和次年续费价。
  - 一期只有发起邀请的子女能为该老人续费；其他成员通过"给自家长辈也开一个"为自己的长辈购买。兄弟姐妹共同续费后置。
  - 不做自动续费。到期提醒：月度包到期前 3 天，年度故事包到期前 30 天（月度为建议值）；段数用完时提醒。提醒对象是付费子女。
  - 订单状态按上文订单状态机流转，每日与微信支付对账。
- **扣段数与透支**：
  - 按订单状态机中的扣段数规则执行。
  - 老人没有可用段数时，仍可开始并讲完一段、正常出片，记为透支 1 段，下次购买时先抵扣；同一时间最多透支 1 段（建议值）。
  - 透支已用且没有可用段数时，老人首页显示"等家人续费后再讲"，同时提醒付费子女续费。老人正在录音时不因段数打断。
- **退款**（首段不满意可退款，以下为建议值）：
  - 适用于付款子女在该老人名下的首笔订单。
  - 条件：老人尚未生成任何一段；或已生成不超过 1 段，且距首段生成不超过 7 天。
  - 符合条件时系统自动原路全额退款；不符合条件的退款诉求走投诉，由运营人工处理。
  - 退款时选填原因，用于退款率复盘。退款后订单剩余段数作废，已生成的故事保留在老人档案中，老人端无任何提示。
  - 用户协议的退款条款与本规则一致。
- **验收**：重复支付回调不产生重复订单；符合条件的退款 100% 自动发起；退款后不再扣该订单段数；老人端在任何状态下都不显示价格、余额和段数；对账差异为 0。

### P0-05 每周话题与出题

对应：MEM-820

- **输入**：话题库（52 个，运营维护）；子女或家人出的题；老人生日（选填）；节日日历。
- **输出**：老人首页的本周话题大卡片，文字加语音朗读。
- **规则**：
  - 话题库首发 52 个，按童年、求学、工作、成家、子女、老家、节日排序，见 [产品方案 话题库](切入点/产品方案.md#话题库)；话题文案和朗读音频在 W1 定稿。
  - 每周一推新话题。选题优先级：子女和家人出的题 > 节日与生日话题（节日或生日前 7 天内，建议值）> 话题库顺序。
  - 出题为一句话，不超过 50 字，过内容安全后用语音合成朗读；多道题按出题时间排队，每周取一道。
  - 老人点"不讲这个"时换下一个话题或自由讲；跳过的出题保留在出题人的列表中，标为"暂时没讲"。
  - 本周话题讲完后，首页提供"再讲一个"，进入下一个话题或自由讲（受段数约束）。
  - 每周提醒老人看新话题，渠道受微信订阅消息限制，见 [风险与待确认事项](#风险与待确认事项)。
- **验收**：出题优先于话题库的比例为 100%；跳过后同一周内不再推同一话题；话题查看事件 100% 上报。

### P0-06 一图一事讲述

对应：MEM-818

- **输入**：本周话题；相册照片或相机翻拍；老人的语音。
- **输出**：一张故事卡片的素材：1 到 9 张照片（原图保留，按选择顺序）、录音、话题。
- **规则**：
  - 照片：从相册选或用相机翻拍，每段 1 到 9 张，可删除、调整顺序；不选照片时用话题卡片作为画面。照片上传时压缩一份用于合成，原图另存，不覆盖。
  - 按住说话：最长 3 分钟，到 3 分钟自动结束；松开暂停，再按继续；显示已讲时长，不显示文字；可整段重录。
  - 少于 10 秒不能提交，提示"多讲几句吧"；10 秒到 1 分钟可以提交，提示"还可以多讲一点"（建议值）。
  - 录音分片上传，弱网时本机缓存并自动重传；来电或切出小程序时已录部分保存，返回后可继续。
  - 转写只保证普通话，方言讲述只显示识别结果；一期不做方言优化。
- **验收**：3 分钟录音在弱网下断开重连后不丢失；1 到 9 张照片的顺序与老人选择一致；原图 100% 保留；讲述开始、讲述完成事件 100% 上报。

### P0-07 短片生成与内容规则

对应：MEM-819

- **输入**：录音、照片、话题、老人称呼、讲述日期。
- **输出**：竖屏 9:16 短片（MP4），时长等于讲述时长；转写（逐字，带时间戳）；标题；高风险标记。
- **生成规则**：以 [产品方案 短片生成](切入点/产品方案.md#短片生成) 为准，要点如下。

  | 项 | 规则 |
  |----|------|
  | 画面 | 每张照片缓慢推拉，按讲述时长平均分配，照片之间淡入淡出；一张照片时全程推拉 |
  | 声音 | 老人原声，只做降噪和音量均衡；配乐默认开启、音量压低，老人可在预览页关闭 |
  | 字幕 | 逐句显示转写原文，只去掉口头语（"嗯""啊""那个"等，词表由运营维护），不改写、不补字 |
  | 标题 | 从原话中摘取一句，不概括、不新增人名、年份、地点和评价；摘不出时用话题名 |
  | 片尾 | 老人称呼、讲述日期、"AI 整理，内容经本人确认，未经人工事实核对" |

- **原文校验**：字幕去掉标点后必须与"转写去掉口头语后"的文本逐字一致；标题必须是转写原文中的连续片段。校验不通过时字幕回退为未断句的转写原文，标题回退为话题名。
- **高风险规则**：命中 [事实核对模块](../../design/memoir/fact-check-engine.md) 中的 R02（在世他人负面评价）、R03（逝者评价）、R04（政治与历史争议）、R09（医疗）、R10（他人隐私）任一条时，标题改用话题名，故事标记为高风险，预览页提示老人"这段提到了别人"，由老人决定是否发给家人；高风险故事不能用于案例展示。规则命中优先于模型判断，模型不能把规则命中的判定调低。
- **失败处理**：任一环节失败自动重试 3 次；仍失败时进入 FAILED，录音和照片保留，服务恢复后自动补生成并通知老人。
- **用量记录**：每次 AI 调用（识别、文本模型、语音合成、内容安全、合成）按档案和故事记录用量和成本，复用 AAF 的 AI 用量记录，用于单段成本统计。
- **验收**：不润色护栏为 0；高风险命中的故事标题 100% 为话题名且停在 PENDING；出片时间达到护栏线；单段成本按账单统计不超过 0.5 元。

### P0-08 预览与发布

对应：MEM-818、MEM-802

- **输入**：PENDING 状态的故事。
- **输出**：已发布的故事、新故事通知、可转发的分享卡片。
- **规则**：
  - 预览页完整播放短片，播放到结尾前"发给家人"按钮不可点；"发给家人"和"重讲"两个大按钮；不点则只有老人自己可见。
  - 高风险故事在预览页先语音提示"这段提到了别人，要不要发给家人"，按钮相同。
  - 发布后通知付费子女和档案成员（服务通知，需对方已订阅；否则只在小程序内显示红点）。
  - 可见范围只有两档：仅自己（未发布）和家人（已发布）；不提供公开链接，不生成网页地址。
  - **分享卡片**：老人或成员可把已发布的单条短片以小程序卡片转发到微信。打开卡片需微信登录；未加入档案的人只能看这一条短片和"加入家族档案""给自家长辈也开一个"入口，看不到档案中的其他内容。故事撤回或删除后卡片立即失效。卡片外传的边界待人类确认，见 [风险与待确认事项](#风险与待确认事项)。
  - **我的故事**：老人按时间查看全部故事，可撤回、删除；撤回后可重新完整预览再发布。
- **验收**：未播放到结尾时调用发布接口被拒绝；未发布故事被他人访问成功的次数为 0；撤回后分享卡片打开失败率 100%；发布、撤回、重讲、预览事件 100% 上报。

### P0-09 家族档案与家人加入

对应：MEM-805、MEM-813、MEM-802

- **输入**：老人或成员生成的加入邀请；分享卡片上的"加入家族档案"。
- **输出**：档案成员关系；成员可见的故事列表。
- **规则**：
  - 每位老人一份家族档案，汇集全部故事、留言和成员。成员按时间查看全部已发布故事；付费子女和成员可看剩余段数和到期时间。
  - 老人接受邀请并完成授权后，发起邀请的子女自动成为成员。
  - **加入邀请**：老人和成员都可以生成，7 天有效，最多使用 10 次。老人发出的邀请（含老人转发的分享卡片）点"加入"即加入；成员发出的邀请（含成员转发的分享卡片）需老人在老人模式中点"同意"后才加入，期间显示"等待老人同意"。
  - 老人可以在老人模式中移除成员，移除后立即失去访问权限。
  - 片尾和档案页提供"给自家长辈也开一个"入口，跳转购买页并记录来源档案，用于自然扩散统计。
  - 档案页提供"想把故事做成相册或书"意向入口，只记录意向、不下单，用于成书询问统计（建议，待确认）。
  - 档案页提供"导出"和"删除档案"请求入口：老人可申请注销档案（删除全部数据），老人或付费子女可申请导出；一期由运营在 5 个工作日内处理（建议值），完整自动导出后推。
- **验收**：未受邀用户访问档案的成功次数为 0；过期或用满的邀请无法加入；成员发出的邀请未经老人同意时不能加入；被移除的成员访问成功次数为 0；家人加入事件 100% 上报并带来源。

### P0-10 家人留言与播报

对应：MEM-822

- **输入**：成员对某段已发布故事的文字留言（不超过 200 字）或语音留言（不超过 60 秒）。
- **输出**：老人端的留言提醒和播报。
- **规则**：
  - 只有档案成员能留言；未加入的分享卡片观看者需先加入。
  - 文字和语音转写过内容安全后才推送给老人；命中时不推送，进入复核。
  - 老人首页显示"有新留言"，点开后文字留言用语音读出（带留言人称呼），语音留言直接播放；播报完成记为已听。
  - 留言对老人和全部成员可见；老人可删除任一留言。
  - 有新留言时提醒老人（服务通知受订阅限制，同 P0-05）。
- **验收**：内容安全命中的留言推送给老人的次数为 0；每条留言 100% 标注留言人；留言和播放事件 100% 上报。

### P0-11 AI 内容标识

对应：MEM-706

- **规则**：按《人工智能生成合成内容标识办法》执行，标识位置以法务确认为准。
  - **显式标识**：片尾文字"AI 整理，内容经本人确认，未经人工事实核对"；播放页和分享卡片显示"AI 整理"标签；建议起始画面加角标（待法务确认是否必需）。
  - **隐式标识**：短片文件元数据写入生成合成标识、服务提供者名称和内容编号；下载和转发的文件保留元数据。
  - 小程序显著位置公示所用模型名称和备案号或上线编号，见 [伦理合规 上线前合规清单](伦理合规.md#上线前合规清单)。
- **验收**：抽检 100 段短片，显式和隐式标识覆盖率 100%。

### P0-12 内容安全审核

对应：无单独 MEM 编号（MEM-819 生成链路的一环，依据 [伦理合规 上线前合规清单](伦理合规.md#上线前合规清单)）

- **审核对象**：照片（逐张）、讲述转写、标题、子女的称呼与邀请语音转写、出题、留言（文字与语音转写）。
- **审核范围**：违法违规、涉政敏感、色情暴力、他人隐私信息；使用阿里云内容安全和百炼模型自带安全审核，拦截词库在服务商词库基础上按业务配置，配套安全测试题用于回归。
- **规则**：
  - 审核在展示给他人之前完成。讲述命中时故事进入 IN_REVIEW；出题、留言、邀请语音命中时不展示，进入复核队列。
  - 运营复核时限 24 小时（建议值）；复核通过后恢复流程，不通过时故事转 BLOCKED，老人可重讲。
  - 内容安全与高风险规则是两件事：内容安全命中进入复核，高风险规则命中由老人决定是否发给家人。
  - 审核结果、拦截记录、复核结论留存不少于 6 个月。
  - **投诉举报**：每个故事播放页和"我的"页提供投诉举报入口，公示处理时限（建议 3 个工作日）；处理结果留痕并通知投诉人。
- **验收**：安全测试题回归通过率达到 W3 设定的基线；命中内容复核前对他人展示的次数为 0；投诉入口在 W4 发布前可用。

### P0-13 运营后台

对应：无 P0（一期）MEM 编号（运营后台范围见 [产品方案 运营后台](切入点/产品方案.md#运营后台)）

管理后台按 AAF 约定由 EntityDef 声明，列表、表单与运维动作写入 `actions`，不手写页面，见 [页面结构规范](../../reference/dev/apps/webui/page-structure-standard.md#管理后台页面)。

| 实体 | 内容 | 动作 |
|------|------|------|
| 故事包档位 | 档位、价格、段数、有效期、是否在售 | 上架、下架 |
| 订单 | 付款人、绑定老人、档位、状态、已扣段数、支付与退款流水 | 发起退款、查看对账结果 |
| 退款申请 | 申请人、订单、原因、是否符合自动退款条件 | 同意、驳回（填原因） |
| 话题库 | 话题文案、分类、排序、节日标记、朗读音频 | 新增、编辑、停用、重新生成朗读 |
| 内容复核 | 命中对象、命中类别、关联故事或留言 | 通过、不通过（填原因） |
| 投诉举报 | 投诉人、对象、类型、状态、处理结果 | 受理、下架故事、解除下架、结案 |
| 导出与删除请求 | 申请人、档案、类型、状态 | 处理完成（上传导出包或记录删除结果） |
| 案例展示授权 | 已授权案例展示且非高风险的已发布故事（只读） | 标记已用于官方账号、下架 |

- 运营只能查看复核队列、投诉和案例展示授权中涉及的故事，不能浏览全部档案；每次查看原声、照片、转写记审计日志。
- 验证指标由埋点导出统计，一期不建指标看板。
- **验收**：上表实体全部由 EntityDef 声明；运营访问未涉及复核、投诉、案例展示的档案成功次数为 0；后台操作 100% 写入审计日志。

### P0-14 埋点

对应：无单独 MEM 编号（数据来源见 [验证计划 数据来源](切入点/验证计划.md#数据来源)）

- 事件清单和派生指标见下节 [埋点与指标](#埋点与指标)。
- 事件只上报 ID、状态和数值，不上报转写、留言等文本，不上报照片和录音。
- 每个事件带公共属性：事件时间、账号 ID、当前身份、档案 ID；涉及订单和故事的带订单 ID、故事 ID；购买和加入事件带来源（邀请卡片、分享卡片、给自家长辈也开一个、渠道码）。
- AI 用量和成本按 P0-07 记录，单段成本与模型服务商账单每周核对。
- **验收**：W4 发布前事件清单 100% 可在测试环境查到；派生指标能按下节口径算出。

## 里程碑

W1 到 W4 研发、W4 发布；W5 到 W10 真实付费验证；W6 中期检查；W10 出验证报告。合规节点与 [伦理合规 上线前合规清单](伦理合规.md#上线前合规清单) 对齐，由人类负责的事项 W1 逐条核实。每周任务卡与人日见 [一期任务 迭代排期](一期任务.md#迭代排期)。

| 周次 | 主题 | 出口标准 | 合规节点 |
|------|------|---------|---------|
| W1 | 地基、账号、授权、技术验证 | 数据模型定稿；小程序可登录并切换身份；授权页可签署、撤回、留痕；技术验证有结论：2 分钟短片合成耗时与单价、转写时延、3 分钟录音与上传、微信支付与退款、订阅消息方案；52 个话题文案定稿 | 生成式 AI 服务登记启动；向属地网信部门确认算法备案；核实 iOS 虚拟支付限制和体验版能否收款；开通微信支付商户 |
| W2 | 购买、邀请、讲述 | 购买、支付回调、订单状态机可用；邀请卡片可生成、接受、去重；老人可选 1 到 9 张照片、按住说话 3 分钟并上传；转写可用 | — |
| W3 | 出片、发布、档案、内容安全 | 短片生成全链路可用，原文校验和高风险规则生效，在测试集上出片 P90 不超过 60 秒；预览与发布、撤回、删除可用；家人加入、留言与播报可用；每周话题与出题可用；内容安全接入并可复核；W3 末提审 | 内容安全与拦截词库、安全测试题就绪；用户协议与隐私政策定稿；小程序类目、ICP 备案、支付方案在提审前完成 |
| W4 | 退款、后台、埋点、发布 | 首段退款与对账可用；运营后台实体由 EntityDef 声明；埋点事件可查；投诉入口可用；团队与亲友内测（建议 5 到 10 个家庭）修复后发布 | 取得服务登记并公示模型信息；AI 标识上线；投诉举报入口上线；日志留存生效。未取得登记或类目未过审时改用体验版，只向受邀种子家庭开放 |
| W5 | 种子家庭 | 30 到 50 个种子家庭真实付费，不投放；每个家庭配联络人；每日查看授权卡点、出片时间、退款原因 | — |
| W6 | 中期检查 | 输出中期数据：老人激活率、第二段留存（口径见待确认事项）；两项都达标即启动二期研发，规格基线见 [后续需求规格](后续需求规格.md)；不达标时研发继续迭代一期 | — |
| W7 到 W9 | 扩大 | 只走零成本或低成本渠道，累计约 200 个家庭；按数据决定加入哪些后置项，或进入二期研发 | 后置项涉及新授权（如老照片修复）时，先补用户协议和授权文本 |

## 风险与待确认事项

| 风险 | 应对 |
|------|------|
| iOS 小程序虚拟支付受限 | W1 核实；备选是子女在安卓端、公众号 H5 或企业微信内付款。iOS 不能付款时购买页引导到备选渠道，验证期按安卓与 iOS 分开统计首单转化 |
| 体验版能否收款 | W1 核实；不能收款且正式版未过审时，验证期改为线下收款或延后公开售卖，验证计划同步调整 |
| 短片合成服务单价与耗时 | W1 技术验证给出 2 分钟竖屏的单价和耗时；单价使单段成本超过 0.5 元，或耗时达不到出片护栏时，评估降级为静态照片加转场，或换合成方案 |
| 订阅消息限制 | 微信小程序的订阅消息需要用户每次授权，长期订阅受类目限制，每周话题提醒、新故事通知、留言提醒可能触达不到。W1 确定方案，备选是邀请子女在家庭群提醒老人 |
| 子女代老人操作 | 本人授权和发布在技术上无法区分是否本人点击；一期靠语音说明、逐项确认和联络人回访观察 |
| 年度故事包不限段数 | 单段成本低，正常使用风险小；验证期监测单档案段数分布，异常时再评估合理使用上限 |
| 出片 1 分钟目标 | 识别、审核、合成串行可能超过 1 分钟；W1 技术验证后由 architect 确定并行方案 |
| 新鲜感衰减 | 每周话题、子女出题、家人留言播报；按 [商业模式 风险与关键假设](切入点/商业模式.md#风险与关键假设) 观察 |
| 研发容量 | 产品方案估 2 名全栈 3 到 4 周；原方案 A 按 3 名全栈（1 名人类开发者加 2 个 AI agent）排期。由 architect 在技术设计后校准，燃尽落后时按降级原则处理 |

待人类确认的建议值（本文已按建议值编写，确认后更新）：

- 订单有效期从老人完成授权起算；尝鲜包有效期 90 天；月度包到期前 3 天提醒。
- 首段退款条件：首笔订单、未生成或只生成 1 段且距首段生成不超过 7 天、自动原路全额退款。
- 透支规则：没有可用段数时允许透支 1 段，下次购买先抵扣。
- 年度故事包"首年价"的资格按老人计（每位老人限一次）还是按付款子女计。
- 最短讲述时长 10 秒；出片时间验收口径 P90 不超过 60 秒、P99 不超过 3 分钟。
- 老人生日由子女在档案页选填；节日与生日话题提前 7 天推送。
- 老两口共用一部手机时如何建档：一期按一个讲述者账号一份档案处理，另一位老人需用自己的微信接受邀请。
- 内容安全复核时限 24 小时；投诉处理时限 3 个工作日；导出与删除请求 5 个工作日人工处理；撤回案例展示授权后 3 个工作日内下架。
- 档案页新增"想把故事做成相册或书"意向入口，作为成书询问的埋点来源。
