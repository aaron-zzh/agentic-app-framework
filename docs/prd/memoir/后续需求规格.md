# 后续需求规格（原方案 A）

> **2026-11-11 起本文是后续阶段的规格基线**：经人类确认，一期改为一图一事，规格见 [一期需求规格](一期需求规格.md)。本文保存原方案 A（2026-11-10）的完整规格，按以下对应关系读取：
>
> - 本文的"一期"（自助对话访谈、事实卡片、受约束润色）对应新的二期，在一图一事中期达标后启动研发，进入研发前按当时情况修订。
> - 本文的"二期"（最小人工链路）和"三期"（顾问、机构、运营）后推，在成书订单稳定后研发；W9 机构试点签约、W16 试点交付随之后推。
> - 账号、授权、家族档案、家人邀请、AI 内容标识、内容安全等规格已被一期需求规格吸收，以一期需求规格为准。
> - 文中"W1 到 W12"的周次和"原型验证不做支付"是原方案的安排，不再适用；阶段与进入条件见 [产品定位 阶段路线](产品定位.md#阶段路线)。

本文细化 [PRD](产品功能.md) 中原方案 A 的 P0 范围。功能编号 P0-01 到 P0-18 是规格分组，每组对应 PRD 功能列表中的若干 MEM 编号，并标明所属研发期。数据表与接口见 [P0 数据与接口设计](../../design/memoir/p0-data-api.md)，任务卡与估点见 [后续任务](后续任务.md)。

## 范围

P0 按 3 名全栈（1 名人类开发者加 2 个 AI agent）、80% 利用率排期，分三期，各 4 周。AAF 已有初始框架（账号与小程序登录、权限与机构隔离、审计日志、对象存储、异步任务、模型网关、实时语音、EntityDef 管理后台、支付与通知），各期在其上构建，不重复建设平台能力。容量测算见 [P0 研发任务卡 团队与容量](后续任务.md#团队与容量)。

**模型选型**：语音识别、语音合成、对话、抽取、润色、图像、视频和内容安全等 AI 能力全部使用在线模型和云服务，优先阿里云百炼，通过 AAF 模型网关调用，可按配置切换；前期不自建、不自部署模型。短片的模板合成同样使用云端媒体服务（阿里云智能媒体服务），不自建合成服务。

| 研发期 | 时间 | 目标 | 面向用户 |
|-------|------|------|---------|
| 一期：基础引擎，自助闭环 | 第 1 个月（W1 到 W4） | 跑通自助闭环，W4 发布后启动 2 到 4 周原型验证 | 讲述者、家属 |
| 二期：最小人工链路 | 第 2 个月（W5 到 W8） | 交付人员承接自助升级订单，走到家属签署《事实核对报告》；工作台半手动，事实核对门禁完整 | 交付人员；平台运营确认升级订单 |
| 三期：全用户类型 | 第 3 个月（W9 到 W12） | 补齐顾问、机构、运营侧能力和排版交付，完成家庭标准交付全链路，支撑首家机构试点 | 顾问、机构人员、平台运营 |

**一期包含**：统一账号与身份切换；老人模式、家属模式（交付模式只有入口）；分项授权；自助对话访谈与转写；事实确认卡片；受约束润色与原声短片；家族档案、家人邀请与补充；AI 内容标识；自助埋点；方言与抽取回归评测。

**二期包含**：项目状态机与升级接单；升级人工；录音上传与长音频转写；结构化与时间线（半手动）；家属确认与通知；大纲与初稿（半手动）；事实核对、讲述者确认、报告签署与交付门禁。

**三期包含**：客户档案、预问卷与接单评估；订单与分段付款；进度看板与运营订单项目管理；工时记录；访谈提纲生成；访谈时长提醒；监护人代为授权；排版、二维码、质检与完整导出；电子小传；机构端最小控制台（租户隔离、名单导入、排期、照护档案、回顾过程记录、导出限制）；真实项目演练与工时校准。

**不包含**：积分充值与消耗、记忆托管订阅、按需印刷（P1，第 3 到 6 个月）；多租户白标、OPC 开放与派单（P2）；出版对接自动化；评测平台（P0 只建评测集，不建平台）；AI 方言电话访谈。双模型矛盾检测、EPUB 电子版、拍照自动裁边移到 P1。

**积分计量**：自助端付费方式为充值积分、用到 AI 的地方按实际用量 × 倍率扣积分，规则见 [产品定位 自助积分](产品定位.md#自助积分)。P0 不扣积分，但一期起每次 AI 调用（对话、智能体、生成、图像、视频）都按档案和用户记录用量和成本，复用 AAF 的 AI 用量记录，供 P1 上线扣减和定倍率使用。

**优先级原则**：核心功能优先实现、保证可用。各期发布标准是本期主链路端到端可用，而不是功能数量齐全；燃尽落后时先降级界面和自动化程度，授权校验、自助护栏（本人确认、反向溯源、AI 标识）和事实核对门禁不降级。

原型验证在一期 W4 发布后启动，与二期开发并行，不做支付，试用者不扣积分。首家机构试点在 W9 签约，机构端在三期逐周就绪，8 周试点在 W16 前后交付，对齐见 [P0 研发任务卡 与试点排期对齐](后续任务.md#与试点排期对齐)。

## 目标与验收指标

**自助目标**：会用手机的老人自己完成"开通授权 → 讲述 → 确认事实 → 生成短片 → 分享给家人"，内容只来自本人确认过的事实和原话。

**人工目标**：1 名交付人员在 14 天内完成 3 万字级回忆录交付（不含等待家属确认的时间），事实错误为 0。最少 1 次访谈即可跑通闭环；标准 SKU 按 2 到 3 次访谈交付，自助升级的客户按档案空缺补采。

| 类型 | 指标 | 验收线 | 研发期 |
|------|------|-------|-------|
| 北极星（自助） | 周活跃家族档案数：本周有新讲述或家人新补充的档案数 | 原型验证期只记录基线；公开上线后按周增长考核 | 一期 |
| 自助 | 首次完成率、连续完成率、关键实体召回率、成片转发意愿、家人加入率 | 原型验证达标线，见 [C 端业务地图 自助版原型验证](C端业务.md#自助版原型验证) | 一期 |
| 护栏 | 自助文字无来源句子数 | 0，生成后逐句反向溯源 | 一期 |
| 护栏 | 方言转写关键实体召回率 | 不低于 90%，用评测集回归；一期用 5 小时子集，二期 W7 起用全量 | 一期起 |
| 护栏 | 每万字事实错误数 | 0，以家属签字版为准 | 二期 |
| 质量 | 初稿人工改动比例 | 不超过 35%；二期初稿半手动，三期演练时开始统计 | 三期 |
| 北极星（人工） | 单项目编辑有效工时（3 万字） | 不超过 15 小时，基线 60 小时 | 三期开始统计 |
| 交付 | 签约到成书周期 | 不超过 14 天，超时率不超过 10%；等待家属确认的时间不计入 | 三期开始统计 |
| 商业 | 家属自费升级率 | 目标 25%；商业模式测算按 10% 作为盈亏判断线 | 机构试点 |

## 角色与权限

| 角色 | 说明 | 关键权限 | 研发期 |
|------|------|---------|-------|
| 讲述者 | 老人本人 | 分项授权，自助讲述，确认事实卡片，预览作品，设置分享范围；人工流程中确认作品（由交付人员协助） | 一期 |
| 家属 | 子女和家人；人工流程中的委托人、付费方 | 加入档案，补充记忆和照片，陪同讲述，发起升级；时间线确认，《事实核对报告》签署，终稿确认 | 一期（人工流程中的确认与签署在二期） |
| 交付人员 | 访谈、整理、编辑、事实核对；自营阶段访谈师和编辑可由同一人兼任 | 创建访谈会话，上传录音，校对转写，编辑章节，事实核对裁决 | 二期（一期只有入口） |
| 顾问 | 线索、报价、签约、接单评估 | 客户与项目增删改，报价单生成，复核可行性评分 | 三期（二期由运营手工确认升级订单） |
| 机构管理员 | 养老机构侧 | 本机构老人档案、排期、进度看板；不可导出原始录音和完整文稿 | 三期 |
| 运营与质检 | 平台侧 | 全库只读，抽检打分，SLA 监控，订单与项目管理 | 三期（二期提供升级确认与只读抽检） |

交付人员在 [用户旅程](用户体验地图.md) 中统称，包含访谈师和编辑。

## 主链路

### 链路 S：自助（一期）

```text
开通与本人授权 → 对话讲述（每次 10 到 15 分钟，可多次）→ 确认事实卡片 → 受约束润色
→ 完整预览 → 生成短片 → 分享给家人 → 家人加入、补充 → 长期档案 → 需要时发起升级
```

电子小传在三期补上。内容规则见 [产品定位 内容规则](产品定位.md#内容规则先确认事实再润色)，判定规则见 [事实核对模块 自助模式](../../design/memoir/fact-check-engine.md#自助模式)。一期档案页已有升级入口，升级请求在二期由运营接单。

### 链路 U：自助升级人工（二期）

```text
档案页发起升级 → 运营确认接单 → 沿用已有授权、补新增用途授权 → 已确认卡片、录音、照片带入项目
→ 按档案空缺补采访谈 → 进入链路 A 的"转写与结构化"及之后的环节
```

### 链路 A：家庭标准交付（二期最小版，三期补齐）

```text
线索建档 → 预问卷与健康禁忌确认 → 签约与授权 → 访谈（单次不超过 2.5 小时）
→ 转写与结构化 → 家属确认时间线 → 大纲确认 → 初稿 → 事实核对 → 讲述者确认
→ 家属签署核对报告 → 排版与短片交付 → 满意度与转介绍
```

二期从"签约与授权"走到"家属签署核对报告"，线索与签约由运营手工处理，时间线和初稿由交付人员在工作台半手动完成。三期补上预问卷、接单评估、提纲生成、访谈时长提醒和排版交付。

### 链路 B：机构驻点（三期）

```text
机构合同 → 批量导入老人名单（脱敏）→ 家属知情同意 → 排期与驻点访谈
→ 照护档案与电子小传 → 机构看板汇总 → 家属自费升级 → 进入链路 A 交付精装与影像
```

### 链路 C：认知友好回顾（三期）

```text
回顾计划 → 结构化人生回顾会话（8 到 12 次）→ 过程记录 → 照护者摘要 → 阶段报告
```

P0 只做记录与摘要。阶段报告是描述性的，不出现疗效、诊断或治疗结论。

## 状态机

### 事实卡片（一期）

```text
EXTRACTED → CONFIRMED | EDITED | DELETED
CONFIRMED | EDITED → DELETED（讲述者事后删除）
```

| 状态 | 含义 | 能否用于润色 |
|------|------|------------|
| EXTRACTED | 系统从对话或家人补充中抽取，待本人确认 | 否 |
| CONFIRMED | 本人确认无误 | 是 |
| EDITED | 本人修改后确认 | 是，使用修改后的内容 |
| DELETED | 本人删除 | 否，不进入任何生成文字 |

讲述者可以随时删除已确认的卡片，引用它的已发布作品自动下架；已确认卡片不能改回待确认，要改内容就删除后重新讲述。升级人工时，CONFIRMED 和 EDITED 的卡片按中等强度证据带入人工项目。

### 自助作品（一期）

```text
GENERATING → PREVIEW → PUBLISHED → WITHDRAWN
                ↓
            DISCARDED
```

| 状态转换 | 放行条件 |
|---------|---------|
| GENERATING → PREVIEW | 每句文字都能回溯到已确认卡片或原话；找不到来源的句子已自动删除；通过内容安全审核（P0-16）。生成失败时停在 GENERATING 自动重试，超过上限提示重新生成 |
| PREVIEW → PUBLISHED | 发布人完整预览（短片播放到结尾、小传滚动到末尾）；作品带"AI 整理、内容经本人确认、未经人工事实核对"标识。发布人为讲述者，或讲述者指定的代管家属 |
| PUBLISHED → WITHDRAWN | 讲述者或代管家属主动下架；撤回相关授权；作品引用的卡片被讲述者删除。下架后分享链接立即失效，需重新生成后再发布 |

只有 PUBLISHED 的作品能生成正式文件和分享链接。

### 人工项目（二期）

```text
LEAD → SIGNED → INTERVIEWING → STRUCTURING → OUTLINE_APPROVED → DRAFTING
     → FACT_CHECKING → FAMILY_APPROVED → DELIVERED → CLOSED

任意进行中状态 → PAUSED → 原状态
任意进行中状态 → TERMINATED
```

| 状态转换 | 放行条件 |
|---------|---------|
| LEAD → SIGNED | 二期：自助升级订单由运营确认后进入 SIGNED。三期：可行性评分不低于 60 且无高风险健康项，否则须顾问复核通过 |
| SIGNED → INTERVIEWING | 存在有效的内容采集授权（P0-12）；自助升级沿用已有授权 |
| STRUCTURING → OUTLINE_APPROVED | 家属已确认时间线，且无未处理的冲突项（P0-06） |
| DRAFTING → FACT_CHECKING | 所有章节的每一节都绑定了来源（P0-07） |
| FACT_CHECKING → FAMILY_APPROVED | 高风险陈述 100% 闭环；讲述者已确认；家属已签署核对报告（P0-09） |
| FAMILY_APPROVED → DELIVERED | 交付前质检清单全部通过（P0-10，三期） |
| 任意 → TERMINATED | 必须填写原因，自动生成结算快照（按已完成付款节点） |

每次状态变更记录操作人、时间和原因。

## P0 功能规格

### P0-01 客户与项目管理

阶段：项目状态机与运营确认升级在二期；客户档案、订单与分段付款、进度看板、工时记录在三期。对应：MEM-103、MEM-104、MEM-105、MEM-901、MEM-902

- 客户档案包含基础信息、健康禁忌、方言、授权状态、项目阶段。
- 人工项目挂在讲述者的家族档案下；自助升级时自动创建项目，带入档案中的成员。
- 项目按上文状态机流转，状态变更留痕。
- 交付人员的每项任务自动记录工时，按流水线层级汇总，用于北极星指标。
- **验收**：状态变更 100% 留痕；`TERMINATED` 未填原因时无法提交，提交后生成结算快照。

### P0-02 预问卷与访谈可行性评估

阶段：三期。对应：MEM-101、MEM-102

- **输入**：家属或老人填写的结构化问卷，包括生平节点、重大经历、敏感话题、不愿提及项、健康状况。
- **输出**：可行性评分（0 到 100）、禁忌话题清单、建议访谈时长与次数。
- **规则**：评分低于 60 或存在高风险健康项时，必须由顾问复核才能签约。
- **验收**：高风险健康项 100% 触发复核。

### P0-03 访谈提纲生成

阶段：三期。对应：MEM-301

- **输入**：预问卷、年代事件库、已有素材；自助升级项目额外使用家族档案的空缺阶段。
- **输出**：分段提纲（开场、主线、深挖、收尾），每段 3 到 5 个记忆锚点提问，关联老照片、老物件、年代歌曲或地标。
- **规则**：不生成诱导性、暗示性提问（如"您当时是不是很勇敢"）；敏感话题带"可跳过"标记；预问卷中的不愿提及项不出现在提纲中。
- **验收**：访谈师对提纲的采纳率不低于 70%。

### P0-04 录音上传与转写

阶段：录音上传、长音频转写、低置信复核在二期；访谈时长提醒在三期。对应：MEM-302、MEM-303、MEM-401、MEM-402、MEM-403

- **支持格式**：mp3、wav、m4a；单文件不超过 2GB；断点续传；本地缓存。
- **能力**：说话人分离、方言口音适配、时间戳对齐、口语顺滑（保留原意，原文另存）。自助对话在一期按 10 到 15 分钟分段转写（P0-14）。
- **输出**：转写片段列表，每段含说话人、起止时间、文本、置信度。
- **时长**：人工访谈进行到 60 分钟提醒，150 分钟强提醒并标记超时。二期系统提醒尚未上线，由交付人员人工计时，遵守 [伦理与合规 访谈健康与安全](伦理合规.md#访谈健康与安全)。
- **规则**：置信度低于 0.75 的片段自动进入人工复核队列，未复核的片段不得进入成稿；另按 10% 比例随机抽审。自助对话中的低置信片段不进入事实卡片，改为请老人复述确认。
- **验收**：低置信片段 100% 进入复核队列；关键实体召回率达到目标线。

### P0-05 记忆结构化

阶段：二期（半手动），AI 抽取与自动冲突检测为降级回补项。对应：MEM-404、MEM-405、MEM-406

- **抽取**：时间线事件、人物关系、地点、职业与身份、"事件-时间-地点"三元组，每条附来源片段。二期由交付人员在工作台手工录入，每条绑定来源片段；升级带入的已确认卡片自动合并。
- **冲突检测**：同一事件出现矛盾的时间、地点或人物时标记为冲突，附双方原文出处。二期由交付人员手工标记。
- **输出**：时间线和人物关系图数据。
- **验收**：全量版抽检 100 条时间线条目准确率不低于 95%；冲突项 100% 被标记。

### P0-06 家属确认时间线

阶段：二期。对应：MEM-407

- 家属在家庭端编辑时间线，批量确认或驳回，补充材料和照片。
- 驳回项回到 `STRUCTURING` 并生成补采任务。
- **确认时限**：7 个工作日，第 5 天提醒。逾期视为通过，并记录为"逾期默认通过"；标记为冲突的条目不适用默认通过。
- **验收**：时间线未确认（含默认通过）时，系统禁止生成大纲。

### P0-07 大纲与章节生成

阶段：二期（半手动，来源绑定校验不降级）。对应：MEM-501

- **输入**：已确认的时间线、风格偏好（朴实、文学、口述实录）、字数目标。
- **输出**：章节树（章、节、要点、引用素材），支持拖拽调序和锁定章节。二期由交付人员手工建章节树，不提供 AI 候选。
- **规则**：每节至少绑定 1 个素材来源，无来源的节点标红且无法提交。
- **验收**：无来源节点 100% 被拦截。

### P0-08 初稿生成与风格控制

阶段：二期（半手动，无来源拦截不降级）。对应：MEM-502、MEM-503、MEM-504、MEM-505

- 二期按绑定素材单章生成，原话优先、改写段落标记；章节级重新生成和风格控制为回补项。
- 段落可插入老人原话，带音频锚点；AI 改写段落有标记，可对照原文并恢复原话。
- 编辑补充的背景说明以编者注形式与原话分开。
- **验收**：无来源段落被阻断；编辑改动比例不超过 35%、套话命中每万字不超过 3 处（三期演练时统计）。

### P0-09 事实核对

阶段：抽取器与自助规则在一期（服务 P0-15、P0-16）；人工核对、讲述者确认、报告签署与交付门禁在二期。对应：MEM-601、MEM-602、MEM-603、MEM-704。详细设计见 [事实核对模块](../../design/memoir/fact-check-engine.md)，规则以该文档为准。

- 从成稿中抽取 8 类可核查陈述：时间、地点、人物、机构、事件、数量、关系、评价。
- 每条陈述绑定证据并按 R01 到 R10 规则分级；规则判定优先于模型判断。
- **处置**：维持、修正、软化、删除、驳回误报五种；无依据时可发起外部核实，最多 2 轮。
- **高风险项**：必须编辑裁决并经家属确认，不适用默认通过；中风险抽 20% 送家属确认，低风险抽检 10%。
- 讲述者能自主表达时，高风险项先朗读给讲述者确认，再交家属确认；裁决优先级为讲述者本人、签约委托人、其他家属。
- **输出**：《事实核对报告》PDF，家属版含逐条明细与修改对照，机构版只含统计与摘要。
- **验收**：高风险项闭环率 100%；存在未关闭的高风险陈述时无法进入 `FAMILY_APPROVED`；3 万字项目核对工时约 6.7 小时。

### P0-10 交付物生成

阶段：人生短片与 AI 内容标识在一期；排版、二维码、质检清单、完整导出在三期。对应：MEM-701、MEM-702、MEM-703、MEM-705、MEM-706、MEM-802

- 精装书排版：模板化，支持章节页、插图；P0 输出印刷文件，印刷下单线下处理。电子版用 PDF。
- 原声音频包、书页到音频锚点的二维码。
- 人生短片：按模板组合照片、已核实的原声片段和字幕，3 到 5 分钟；自助与人工共用同一模板能力。
- 家属分享页：默认仅受邀家人可见，按讲述者（或其指定的代管家属）设置的范围分享，禁止公开链接（随 P0-17 在一期上线）。
- 所有作品添加 AI 生成标识；完整导出覆盖录音、照片、转写、作品和报告。
- **验收**：交付前质检清单（错别字、图注、页码、敏感词）全部通过才能生成印刷文件。

### P0-11 机构端最小控制台

阶段：三期。对应：MEM-851、MEM-852、MEM-853、MEM-854

- 老人档案（脱敏）、照护档案、访谈排期日历、进度看板（按状态、楼层、护理等级）、回顾会话过程记录导出。
- **权限隔离**：机构只能看到授权范围内的档案和进度，不能导出原始录音和完整文稿。
- **验收**：跨机构数据访问测试 0 越权。

### P0-12 授权与合规记录

阶段：分项授权、撤回、留痕在一期；监护人代为授权在三期。对应：MEM-201、MEM-202、MEM-203、MEM-204

- 分项授权：内容采集、声音使用、肖像使用、案例展示，默认只勾选内容采集；语音朗读说明。
- 电子签署：知情同意、录音录像授权、版权归属、删改权；提供数据删除请求通道。
- 老人本人签署优先；自助场景必须由老人本人确认，子女不能代替。无法签署时记录监护人或委托人及关系证明，经顾问审核后生效。
- **验收**：无有效授权的项目无法进入 `INTERVIEWING`；未授权内容采集时无法开始自助对话；未授权声音使用时无法生成含原声的作品。

### P0-13 统一账号与多身份

阶段：一期。对应：MEM-001、MEM-002、MEM-004、MEM-005、MEM-003

- 微信或手机号登录；一个人可同时拥有讲述者、家属、交付人员等身份，登录后选择进入老人模式、家属模式或交付模式，可随时切换。
- 权限按身份和项目分配；切换和敏感数据访问记审计日志。
- 老人模式首页只有"开始讲故事"、本周提问和"我的短片"，大字、语音为主、一屏一件事。
- **验收**：以家属身份看不到其他家庭的档案；以交付人员身份只看到分配给自己的项目；切换记录 100% 写入审计日志。

### P0-14 自助对话访谈

阶段：一期。对应：MEM-809、MEM-401

- **输入**：开通时填写的方言和不想谈的话题；已上传的老照片；子女设置的每周提问。
- **过程**：每次 10 到 15 分钟，AI 按人生阶段和老照片提问并追问；老人可随时停下、跳过问题；不想谈的话题不会被问到。
- **输出**：分段录音、转写、本次对话的事实卡片（P0-15）和一段小短片（P0-16）。
- **规则**：首批只支持普通话和 1 种方言；追问不得诱导或暗示，与 P0-03 使用同一套提问约束；AI 的每句提问和回应在播报前经内容安全过滤（见 P0-16）。
- **验收**：不想谈的话题出现在提问中的次数为 0；一次对话结束后 5 分钟内生成事实卡片。

### P0-15 事实确认卡片

阶段：一期。对应：MEM-811

- **抽取**：从对话中抽取时间、地点、人物、机构、事件、数量，按 [事实核对模块](../../design/memoir/fact-check-engine.md#陈述抽取) 的陈述抽取规则。
- **展示**：大字卡片加语音朗读，选项为"对""要改""删掉"；子女可协助，但确认动作由老人本人完成。
- **规则**：按上文事实卡片状态机流转；只有 CONFIRMED 和 EDITED 的卡片能用于润色；命中 R01 的模糊年份使用"大约……前后"的软化表述；转写置信度低于 0.75 的片段不出卡片，改为请老人复述。家人补充的内容同样抽取为卡片，由讲述者确认后才能用于润色。
- **确认人校验**：服务端校验当前账号以讲述者身份登录，并记录确认渠道和设备。子女用老人手机代为点击在技术上无法区分，一期通过语音朗读和老人模式的单步确认降低风险，原型验证中观察。
- **验收**：未确认卡片进入生成文字的次数为 0；以家属身份调用确认接口被拒绝；修改率按原型验证口径记录。

### P0-16 受约束润色、原声短片与电子小传

阶段：润色与原声短片在一期；电子小传在三期。对应：MEM-812、MEM-706

- **输入**：已确认卡片、原话片段、老照片。
- **输出**：标题、字幕、旁白、3 到 5 分钟原声短片；连续讲完一个人生阶段后生成该阶段的电子小传章节。
- **规则**：只使用已确认卡片和原话，不新增年份、人名、机构、数字和评价；命中 R02、R03、R04、R09、R10 时不润色、不生成旁白，默认不进入成片，用户可选择保留原声；生成后逐句反向溯源，找不到来源的句子自动删除；按自助作品状态机流转。
- **内容安全**：生成文字和保留的原声转写在进入预览前经内容安全审核（违法违规、涉政敏感、色情暴力、他人隐私信息），命中的段落不进入作品，并进入运营复核队列；审核结果和拦截记录留存。审核能力使用阿里云内容安全服务和百炼模型自带的安全审核，拦截词表在服务商词库基础上按业务配置。
- **肖像**：未授权"肖像使用"时，短片不使用照片，只用原声加字幕。
- **验收**：与 [PRD MEM-812](产品功能.md#mem-812-自助润色与原声短片) 的验收标准一致；无来源句子数为 0；内容安全命中的段落进入作品的次数为 0。

### P0-17 家族档案、家人邀请与补充

阶段：一期。对应：MEM-805、MEM-813、MEM-804、MEM-802、MEM-801

- 每次讲述、照片、家人补充、人物关系都合并到讲述者的同一份家族档案。
- **邀请**：讲述者和已加入的家属都可以生成邀请（二维码或链接），有效期 7 天，最多使用 10 次。讲述者发出的邀请扫码即加入；家属发出的邀请需讲述者在老人模式中点"同意"后才加入。
- **分享范围**：档案设默认范围，单个作品可以覆盖；取值为"全部成员"或"指定成员"；默认仅受邀家人可见，没有公开链接。分享范围由讲述者设置；讲述者可以在老人模式中指定一位代管家属，代为设置分享范围和发布作品。
- 家人可补充照片、记忆和提问，标注来源人；涉及老人的事实按 P0-15 抽成卡片，经老人确认后才能用于润色。
- 档案页提供"升级人工成书"入口，一期记录升级请求，二期起由运营接单（P0-18）；同一档案同时只能有一个待处理的升级请求。
- **验收**：未受邀用户访问档案和分享页的成功次数为 0；过期或用尽的邀请无法加入；家属发出的邀请未经讲述者同意时不能加入；家人补充的内容 100% 标注来源人。

### P0-18 升级人工

阶段：二期。对应：MEM-814

- 运营确认接单后创建人工项目（二期手工确认，三期接入顾问报价与订单）。
- 已确认卡片、录音、照片直接带入项目，交付人员从档案空缺处补采，不重新开始。
- 自助阶段的授权沿用；新增用途（如案例展示、印刷出版）补授权。
- **验收**：升级后项目中可见全部已确认卡片及其来源；带入的卡片在证据模型中标记为中等强度。

## 埋点与指标

关键事件：

- 自助（一期）：`elder_onboarded`、`consent_signed`、`story_session_completed`、`card_confirmed`、`card_edited`、`card_deleted`、`work_published`、`work_withdrawn`、`work_shared`、`family_joined`、`family_contributed`、`content_blocked`、`upgrade_requested`
- 人工（三期接入）：`project_created`、`session_completed`、`transcript_reviewed`、`timeline_confirmed`、`outline_approved`、`draft_generated`、`fact_resolved`、`elder_confirmed`、`report_signed`、`artifact_delivered`
- 机构与商业（三期）：`upgrade_purchased`

派生指标：

| 指标 | 计算方式 |
|------|---------|
| 周活跃家族档案数 | 本周有 `story_session_completed` 或 `family_contributed` 事件的档案数（去重） |
| 首次完成率 | 首次对话讲满 10 分钟的讲述者数 ÷ 完成开通的讲述者数 |
| 连续完成率 | 完成 5 次以上对话的讲述者数 ÷ 完成开通的讲述者数 |
| 家人加入率 | 至少 1 位家人加入的档案数 ÷ 档案总数 |
| 卡片修改率 | （`card_edited` + `card_deleted`）÷ 抽取的卡片总数 |
| 编辑有效工时 | 按流水线层级聚合工时记录 |
| 返工轮次 | 家属驳回和讲述者修改的轮次 |
| 家属升级率 | `upgrade_purchased` 家庭数 ÷ 机构项目家庭数 |
| 转介绍来源占比 | 线索来源中"转介绍"的比例 |

原型验证在 W5 到 W8 进行，与二期并行；W8 前后出达标判断。首家机构试点 W9 到 W16。

## 风险与开放问题

| 风险 | 应对 |
|------|------|
| 周期紧、人力少 | 人工线已按工作台半手动排期，每周第 3 天做燃尽检查，落后超过 15% 即触发降级；事实核对门禁和授权校验不降级。规则见 [P0 研发任务卡 降级规则](后续任务.md#降级规则) |
| 小程序资质与审核 | 调用百炼已备案模型，只办应用登记，不自行做算法备案；W1 向属地网信部门确认并取得阿里云合作协议，申请"深度合成"类目；W3 末提审；未过审时用体验版启动原型验证 |
| 二期没有系统时长提醒 | 交付人员人工计时，单次不超过 2.5 小时；三期 W9 上线系统提醒 |

| 3 万字与访谈次数不匹配 | 1 次 2.5 小时访谈约产生 2 万字转写，标准 SKU 3 万字需要 2 到 3 次访谈；自助升级可用已有档案减少补采；P0 闭环验证可用 1 次访谈做短篇 |
