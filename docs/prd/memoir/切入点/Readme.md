# 一图一事：一期切入点

**一句话**：子女付费，把小程序分享给爸妈；老人选几张老照片（1 到 9 张）、按住说一件事（1 到 3 分钟），一分钟左右拿到一段带原声和字幕的短片，发到家庭群。

原方案要同时搭需求侧（自助访谈）和供给侧（访谈者工具、OPC 派单），起步重。一图一事只做需求侧闭环的第一环，用真实付费验证三件事：老人愿不愿意讲、子女愿不愿意付、家人会不会转发。讲得多了，再走向 AI 对话访谈、人工成书和派单。

2026-11-11 经人类确认：一期做一图一事；切入期用固定价，年度故事包首年 99 元；每段讲述 1 到 3 分钟，可配多张照片；人工访谈后推。决定内容和已同步修改的上级文档见 [定位 与原方案的差异](定位.md#与原方案的差异)。
