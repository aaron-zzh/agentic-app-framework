# 老人回忆录平台

本目录记录"老人回忆录平台"的产品需求。平台定位为**智能化的长者记忆档案平台**，2026 年 11 月起自助优先：老人用手机和 AI 对话讲故事，本人确认的内容由 AI 整理成短片和小传，沉淀为长期家族档案并与家人共享；需要深度服务时升级为人工成书，由高效运营工具支撑的自营团队或众包 OPC 交付，养老机构是服务高龄老人的渠道。

当前处于需求探索阶段，所有文档状态为 `draft`，结论需经人类评审后才能进入 backlog。
