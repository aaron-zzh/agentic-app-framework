# 路线图

版本里程碑计划。详细任务见 [backlog.md](../task/backlog.md)。

> 规划版本时请先参考 [产品概述](../explanation/product-overview.md)，确保版本目标与产品方向一致。

## 代码库构成

| 代码库 | 技术栈 | 定位 | 启动版本 |
|--------|--------|------|---------|
| `apps/service` | Spring Boot 4 + Java 25 | 后端核心，AI 原生框架引擎 | v0.1.0 |
| `apps/webui` | Next.js 16 + React 19 + TypeScript | Web 前端，对话式交互主入口 | v0.1.0 |
| `apps/uniapp` | UniApp + Vue 3 | 跨端移动应用（小程序/APP） | v0.1.0 结构，v0.3+ 功能迭代 |
| `apps/actormesh` | C++20/23，io_uring，无共享 Actor 模型 | 高性能异步引擎开发框架，AAF 各专项引擎（调度/工作流/知识/沙箱等）的 C++ 实现底座 | v2.0 按需引入 |

**迭代策略**：
- `service` / `webui` / `uniapp` 每个版本同步迭代，功能对齐
- `uniapp` 优先级低于 `webui`，同版本内 webui 先行，uniapp 跟进核心功能
- `actormesh` v2.0 前不启动；v0.x 各引擎用 Java 实现，待 actormesh 稳定后按需迁移到 C++ 高性能实现

## v0.x — 逐步完善（v0.2 ~ v0.9）

> 目标：在传统 MVC 基础上逐步引入元引擎核心能力，**v0.9 前完成**：
> - 一切皆文档的元引擎基础实现（实体运行时 + 工作流运行时 + DSL 解释器）
> - 对话式交互基本框架（意图理解 → DSL → 元引擎执行 → 语义组件渲染）
> - 知识库 + 记忆系统基础能力
> - 五层智能架构基础实现（Core → Cognition → Agent → Assistant）
>
> 预计周期：2026-06 ~ 2026-12

| 版本 | 方向 |
|------|------|
| v0.2 | 元引擎实体运行时（DSL 动态建表 + 自动 CRUD），新业务模块走无代码 |
| v0.3 | 工作流运行时（DSL → Flowable），审批/流程类模块迁移 |
| v0.4 | 规则引擎 + 权限运行时（DSL 动态鉴权），促销/通知规则迁移 |
| v0.5 | 知识库引擎（PgVector 语义检索 + Neo4j 图谱），RAG 基础能力 |
| v0.6 | 记忆系统（短期 Redis + 长期 PostgreSQL），Cognition 层基础实现 |
| v0.7 | Agent 编排基础（SequentialAgent + ToolCalling + MCP），Assistant 层 |
| v0.8 | 对话式交互框架（意图理解 → DSL → 元引擎执行 → 语义组件动态渲染） |
| v0.9 | 整合验收：元引擎 + 对话式交互 + 五层智能基础框架联调，发布 Beta |

## v1.0 — 完整 AI 原生框架（正式版）

> 目标：在 v0.9 Beta 基础上，完善各项核心能力，达到生产可用标准。
>
> 预计周期：2027-Q1（v0.9 发布后规划）

候选方向：

| 方向 | 说明 |
|------|------|
| 智能体系统完善 | Team 层多智能体协作、置信度门控、主导权切换 |
| 专项引擎完善 | 调度引擎、自进化引擎、积分结算引擎、监控引擎 |
| 自运维 | 性能异常检测 → 自动优化方案 → 沙箱验证 → 热部署 |
| 自开发 | 意图 → 规范 → 代码生成 → 审查 → 测试全流程自动化 |
| 语义组件完善 | 多端统一组件库（Web/移动/微信/CLI），DSL 驱动动态组装 |
| 自进化闭环 | 用户行为 → 效果评估 → 规范更新 → 代码重生成 → 热部署 |
| 人类计算 | 众包协作、积分系统、集体智慧接入 |
| 生产化 | CI/CD 自动化、安全加固、性能优化、发布文档 |

## v3.0+ — 元引擎 / 无代码（愿景）

> 目标：转向纯元引擎架构——DSL 驱动执行、意图直接转为执行、普通用户可视化搭建工作流/技能/知识库，无需写代码。
>
> 前置：v2.0 引擎化完成，各专项引擎稳定；Polymorphic Actor 贯穿业务实体；协作控制台完成 Skill 晋升与 Autopilot。
>
> 规划时机：v2.0 中期启动 v3.0 规划。

候选方向：

- DSL 多范式 / 分层 / 分域完整落地，成为面向用户的意图表达层
- 元引擎执行调度器、状态管理器、置信度门控器、自进化引擎上线
- 协作控制台 Phase 4（多 agent 并行，Worktree + 共享 PostgreSQL P3.1 方案）可选
- 无代码可视化编排（工作流 / 技能 / 知识库 / 组件）
