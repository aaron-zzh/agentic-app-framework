## 需求详情

### 单据识别入库工作流（2026-05-06）

**背景**：分销企业用户，有 3-10 月积压的大量送货单、对账单需要处理，数据安全要求高。

**核心诉求**：

| 能力 | 描述 |
|------|------|
| 私有化部署 | 本地部署（5090 D 显卡），完全断网运行，账目数据严禁上传云端 |
| 多模态单据识别 | OCR 识别复杂单据（手写涂改、反光、褶皱），提取品名、单价、数量、金额 |
| 自动化审计工作流 | ① OCR 提取 → ② AI 逻辑校验（单价×数量=总额）→ ③ API/DB 写入进销存 |
| 领域微调 | 支持 Llama 3 / DeepSeek 本地 LoRA 微调，识别行业简写（如"雀2"→"雀巢200g"） |
| 可维护性 | Docker 镜像交付，开源可自维护 |

**用户关注点**：

- 是否有类似案例和演示？
- 交付物是否包含 Docker 镜像？
- 针对 5090 D 硬件的调优程度？

**评估意见**（对照 [产品概述 #需求评估原则](../explanation/product-overview.md#需求评估原则)）：

| 评估维度 | 分析 |
|---------|------|
| **产品定位** | ✅ 符合。多模态识别（OCR）+ 工作流编排 + 外部系统集成，是 AI 原生应用的典型场景 |
| **框架层 vs 业务层** | 框架层：OCR 能力（通过在线 API）、工作流引擎、API 集成接口；业务层：具体单据模板、领域术语映射、进销存对接 |
| **核心能力依赖** | 多模态识别（v0.2 工具系统）、工作流引擎（v2.0）、外部系统集成（v0.2） |
| **部署模式** | 引导用户采用在线部署，通过数据安全措施解决顾虑 |
| **数据安全** | 通过脱敏、分片调用、审计日志等措施保障，详见下方安全方案 |

**核心流程识别**：

```
拍照/上传单据
    ↓
[OCR 识别] — 框架核心能力，调用在线多模态 API（GPT-4o Vision / Claude 3.5）
    ↓
结构化提取（品名、单价、数量、金额）
    ↓
[AI 逻辑校验] — 框架工作流节点，规则引擎校验（单价×数量=总额）
    ↓
[领域术语映射] — 知识库能力，"雀2"→"雀巢200g"（可通过 RAG 或微调）
    ↓
人工确认（可选，置信度低时触发）
    ↓
[API/DB 写入] — 框架集成能力，对接进销存系统
```

**框架实现方案**：

| 环节 | 框架能力 | 实现方式 |
|------|---------|---------|
| OCR 识别 | 多模态工具 | Spring AI 调用 GPT-4o Vision / Claude 3.5 Sonnet，提取结构化数据 |
| 逻辑校验 | 工作流节点 | Flowable 规则任务，配置校验表达式 |
| 术语映射 | 知识库 | 向量检索行业术语表，或 Few-shot Prompt 注入领域知识 |
| 置信度门控 | Agent 协作 | 识别置信度 < 阈值时，自动转人工确认 |
| 系统集成 | MCP/API 工具 | 标准化接口对接进销存，支持 REST/数据库直连 |

**场景示例规划**：

作为 v2.0 工作流引擎的示例应用，展示：

1. **多模态输入**：图片上传 → OCR 结构化
2. **工作流编排**：识别 → 校验 → 映射 → 确认 → 入库
3. **人机协作**：低置信度自动转人工
4. **外部集成**：对接示例进销存系统

**数据安全方案**（针对用户"账目数据严禁上云"顾虑）：

| 措施 | 说明 |
|------|------|
| **敏感字段脱敏** | 金额、客户名等字段在调用 LLM 前替换为占位符，返回后还原 |
| **多 LLM 分片** | 单据图片发送给 OCR 模型，提取的文字分片发送给不同 LLM 校验，单个模型无法还原完整业务 |
| **企业版 API** | 使用 OpenAI/Anthropic 企业版，明确数据不用于训练 |
| **本地预处理** | 图片压缩、格式转换在本地完成，减少上传数据量 |
| **完整审计** | 记录每次 LLM 调用的输入输出，支持合规审查 |
| **可选本地 OCR** | 对于极敏感场景，支持切换到本地 PaddleOCR（能力降级但数据不出域） |

**引导话术**：

> 我们理解您对数据安全的顾虑。AAF 采用"数据脱敏 + 多模型分片"机制，确保单个云端模型无法还原您的完整业务数据。同时提供完整审计日志，满足合规要求。
>
> 相比完全离线部署（需要 5090 级显卡、本地模型能力有限、运维成本高），在线部署 + 安全措施是更经济高效的选择。如果您的行业有强制离线要求，我们也支持本地部署模式。
