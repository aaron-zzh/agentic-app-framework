## 任务列表

### 知识库管理

1. [ ] #5701 知识库列表与详情
   - 知识库卡片列表（名称、描述、文档数、向量数、最后更新时间）
   - 搜索与筛选（按名称搜索、按状态筛选）
   - 知识库详情页（基本信息、文档列表、处理状态统计）
   - 知识库创建/编辑表单（名称、描述、模型选择、策略配置）
   - verify: 知识库 CRUD 全流程前端交互正常

2. [ ] #5702 文档上传与预览
   - 拖拽上传（支持 PDF/Word/Markdown/HTML，多文件批量）
   - 上传进度条（单文件进度 + 总体进度）
   - 文档在线预览（PDF 渲染、Markdown 渲染、纯文本高亮）
   - 文档状态展示（待处理/处理中/已完成/失败 + 错误信息）
   - verify: 拖拽上传→进度展示→预览查看全流程通过

### 图谱与检索

3. [ ] #5703 知识图谱可视化
   - 基于 @xyflow/react 或 D3-force 的图谱展示
   - 节点交互（点击展开详情、双击聚焦、拖拽布局）
   - 关系浏览（边标签、关系类型筛选、路径高亮）
   - 图谱缩放/平移/小地图、大图谱性能优化（虚拟化）
   - verify: 100+ 节点图谱流畅渲染，交互响应 < 100ms

4. [ ] #5704 检索测试面板
   - 输入问题→展示检索结果（来源文档、相似度分数、高亮片段）
   - 展示生成答案（Markdown 渲染、引用标注可点击）
   - 调参面板（Top-K、相似度阈值、检索模式切换、模型选择）
   - 检索耗时与 Token 消耗统计
   - verify: 输入问题→返回检索结果+生成答案，参数调整生效

### 配置管理

5. [ ] #5705 知识库设置
   - 分块策略配置（策略类型、块大小、重叠窗口、自定义规则）
   - Embedding 模型选择（模型列表、维度信息、费用估算）
   - 同步计划配置（手动/定时、Cron 表达式、同步状态监控）

   - verify: 配置修改后生效，新文档按新配置处理
