# AAF v0.2~v0.11 迭代计划

> **总体目标**：在 v0.1.0 配置驱动视图引擎基础上，逐步构建完整的 AI 原生多智能体应用框架——对话交互、五层智能、知识库、工作流、Auto Dev、AIGC、商业化，最终以 Beta 发布。
>
> **迭代策略**：按模块完整交付，不拆分同一功能到多个版本。`service`/`webui` 每版本同步迭代，`uniapp` v0.3+ 跟进核心功能。
>
> **路线图**：[roadmap.md](../prd/roadmap.md) | **Backlog**：[backlog.md](backlog.md)
