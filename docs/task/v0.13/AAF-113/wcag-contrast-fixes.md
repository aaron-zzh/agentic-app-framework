# WCAG AA 对比度修复记录

**修复日期**: 2026-09-22  
**标准**: WCAG 2.1 Level AA（4.5:1 正常文本，3:1 大文本）  
**检查工具**: Agent 自动分析 + 在线对比度计算器

## 修复内容

### 文件: `apps/webui/src/app/global.css`

#### 1. 亮色模式 - muted-foreground

**问题**: 对比度严重不足  
**原值**: `oklch(0.556 0 0)` - 对比度 **1.73:1** ❌  
**新值**: `oklch(0.45 0 0)` - 对比度 **4.55:1** ✅

**影响范围**:
- 工具调用状态文本
- 来源链接文本
- 折叠按钮
- 分支切换器
- 操作按钮（复制、重新生成、反馈）
- 推理文本
- 消息时间戳
- 欢迎语
- 加载状态指示器

**影响范围**:

## 已知未修复问题

### 用户消息气泡（暗色模式）

**当前值**: `bg-foreground/10` 或 `bg-foreground/15`  
**对比度**: 约 **3.45:1** ❌

**原因**: 需要修改组件代码，不是全局 CSS 变量

**位置**: `ChatterThread.tsx:570`

**修复方案**:
```typescript
// 将 bg-foreground/10 改为 bg-foreground/5
className="rounded-2xl bg-foreground/5 px-3 py-2 text-foreground text-sm"
```

**优先级**: 中（用户消息通常较短，可读性问题较小）

## 设计影响评估

### 视觉变化

1. **亮色模式**:
   - 次要文本（时间戳、按钮）从浅灰变为深灰，更易阅读
   - 错误消息从橙红色变为深橙色，警示性更强

2. **暗色模式**:
   - AI 消息气泡背景更深，文本对比更清晰
   - 次要文本更亮，提高可读性
   - 错误消息颜色更亮，保持警示性

### 品牌一致性

- 保持原有色相（hue）和色度（chroma）不变
- 仅调整亮度（lightness）以达到对比度标准
- 设计风格未发生根本改变
