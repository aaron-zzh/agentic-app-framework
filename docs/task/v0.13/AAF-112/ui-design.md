# AAF-112 交互设计

## 双视图入口

- 结构视图行操作：`详情 → 生成/生成新版本 → 画布或标注`。
- 图谱对象节点：保留 `详情` 与 `生成/生成新版本` 主操作。
- 入口仅传 objectId；只读、blocked 或无适用动作时禁用并给出说明。

## 对象生成弹窗

使用 shadcn/Base UI `Dialog`，必须包含可见 `DialogTitle` 和 `DialogDescription`。标题为 `生成「对象标题」`；描述显示对象类型和 objectKey。内容嵌入现有媒体创作工作区，项目模式不执行路由跳转，只在弹窗内切换服务端允许的模式。

提交成功以“执行已进入队列”为完成点，关闭弹窗并保留后台任务；失败时保留输入。桌面最大宽度 5xl、内容区可滚动；移动端单栏。

## 添加参考图

`添加参考图` 使用 `DropdownMenuTrigger render={<Button />}`，不使用 `asChild`。菜单：

- `本地上传`：打开 image 文件选择器。
- `选择项目素材`：打开统一选择器，默认素材网格。
- `从项目图谱选择`：打开同一选择器并定位图谱 Tab。

## 项目素材选择器

使用 `Dialog + Tabs + ScrollArea`：

- `项目素材`：显示当前项目采用媒体引用的图片网格。
- `项目图谱`：复用 ProjectGraph 投影，只选对象，不修改图谱；不可选节点降低视觉权重。
- 卡片/节点展示对象标题、类型、采用版本、缩略图和来源。
- 选择器内部暂存选择，点击 `添加 N 张` 才写回生成弹窗。
- 空、加载、错误分别使用 `Empty`、`Skeleton` 和带重试的内联状态。

## 已选参考图

- 显示顺序号、缩略图、名称与来源 Badge：`本地上传`、`项目素材`、`项目图谱`。
- 支持移除；视频多图支持前移/后移，键盘操作不依赖拖拽。
- 数量显示 `n/max`；达到上限后添加入口禁用。
- 相同 MediaVersion 再次选择时提示“该图片已添加”。

## 可访问性

- 关闭选择器后焦点返回来源菜单触发器，关闭生成弹窗后返回原视图按钮。
- 图片使用对象/媒体名称作为 alt；图标按钮提供 aria-label。
- 选中态同时使用勾选、边框和文字，不只依赖颜色。
- 超限、上传结果和选择数量使用可读文本反馈。
