# AAF-125 技术任务

风险等级：🟡 中（只改前端，不新增接口；涉及首页、项目列表页、积分中心三个页面），派发 developer-webui + tester。

## 背景

`/studio` 首页按 AAF-100 [首页四行改版](../../v0.1.1/AAF-100/design.md#studio-首页四行改版) 排列：统计卡、最近项目、蓝图、快速创作。整体偏 AIGC 项目生产，没有个人资源与消耗的展示。

本故事是首页通用化的第一步，范围刻意收窄：

- 最近项目和项目模板移到项目主页 `/studio/projects`。
- 首页只保留工作概况和快速创作，并把"我的 → 积分"里的积分消耗分类图放到首页。

本故事修订 AAF-100 的"首页严格四个区块"约束，首页结构以本文为准。

## 布局设计

### Studio 首页 `/studio`

```text
┌──────────────────────────────────────────────────────────────┐
│ 工作概况：5 个数据胶囊（HomeDataCapsules，不变）                │
├──────────────────────────────────────┬───────────────────────┤
│ 快速创作                              │ 积分消耗分类   积分中心 › │
│ ┌────────┐ ┌────────┐ ┌────────┐     │ ┌───────────────────┐ │
│ │ 图像   │ │ 视频   │ │ 文案   │     │ │ 玫瑰饼图 + 分类列表 │ │
│ └────────┘ └────────┘ └────────┘     │ ├───────────────────┤ │
│ ┌────────┐ ┌────────┐ ┌────────┐     │ │ 分类数 │ 30 天消耗 │ │
│ │ 配音   │ │ 音乐   │ │ 数字人 │     │ └───────────────────┘ │
│ └────────┘ └────────┘ └────────┘     │                       │
└──────────────────────────────────────┴───────────────────────┘
```

- 顶层只有两个区块：工作概况一行，快速创作与积分消耗分类并排一行。
- 并排行在 `xl`（≥1280px）用 5 栏网格：快速创作占 3 栏、卡片 3×2 排列，积分消耗分类占 2 栏。左右两列等高，快速创作卡片按行高拉伸，图标放大。
- 低于 `xl` 改为单列：快速创作在上（`grid-cols-2`，`md` 起 `grid-cols-3`），积分消耗分类在下并占满宽度。
- 快速创作的入口、路由和"尚未开放"标记沿用 `QUICK_CREATE_ENTRIES`，不变。
- 积分消耗分类复用 `ExpensesCategoryWidget`，标题右侧加"积分中心"链接，跳 `/studio/me/credits`。卡片内只出现一个标题。
- 首页不再渲染 `RecentProjectGrid` 和 `HomeBlueprintSection`。

### 项目主页 `/studio/projects`

```text
┌──────────────────────────────────────────────────────────────┐
│ 我的项目                                         [新建项目]   │
├──────────────────────────────────────────────────────────────┤
│ 最近项目：新建项目卡 + 4 个最近项目（RecentProjectGrid）        │  ← 仅未筛选时
├──────────────────────────────────────────────────────────────┤
│ 项目模板：类型 Tabs + 已发布蓝图卡（HomeBlueprintSection）      │  ← 仅未筛选时
├──────────────────────────────────────────────────────────────┤
│ 全部项目：类型筛选 + 状态 Tabs + 项目网格（现有内容，不变）      │
└──────────────────────────────────────────────────────────────┘
```

- 只有在没有任何筛选时（`status` 为 all 且没有 `type`），才在列表上方显示最近项目和项目模板。侧栏的"进行中""已完成"会带筛选参数，这两个入口直接显示列表。
- 列表区上方加一个"全部项目"小标题，和上面两个区块的标题层级一致。
- `RecentProjectGrid` 在项目主页上不显示"查看全部"链接，因为它会链回当前页。

## 数据口径

积分消耗分类没有用户级统计接口。`/api/stats/credits/by-category` 只对 `ADMIN/SUPER_ADMIN` 开放。现在 `/studio/me/credits` 的做法是取最近 100 条流水（`useCreditTransactions(0, 100)`），前端按 `category` 汇总 `SPEND`。本故事沿用这个数据源，并统一口径：

- 只统计近 30 天的 `SPEND` 流水，和卡片底部"30 天总消耗"的文案一致。现状没有按时间过滤，文案与数据不符，借本故事修正。
- 仍以最近 100 条为上限。消耗频繁的用户 30 天内超过 100 条时，统计会偏小。这是已知限制，全量统计留给后续的用户级接口。
- 首页和积分中心用同一个派生 hook，不复制聚合代码。hook 与积分中心的趋势图共用同一个 Query 缓存（同一 queryKey，用 `select` 派生），首页和积分中心之间切换不重复请求。
- 积分图不受 AIGC License 限制。工作概况胶囊的 `home-summary` 仍然受 AIGC 限制，本故事不改。

## 非目标

- 用户级积分统计接口和全量分类统计。
- 把首页接入 `DashboardView` 的 widget 与预设机制，也不做可拖拽或可配置布局。
- 角色、技能、知识库统计卡，运行中智能体，大屏或座舱主题。这些按首页通用化路线另立用户故事。
- 把积分中心的"近 14 天消耗趋势"搬到首页。
