# AAF-125 技术任务

风险等级：🟡 中，派发 developer-webui + tester。

改动文件会超过 5 个，协调者评估如下：只改 `apps/webui` 一个项目，不新增或修改后端接口，不改 `common/` 与共享接口签名，布局由人类在对话中确认，所以维持 🟡。

## 背景

`/studio` 首页按 AAF-100 [首页四行改版](../../v0.1.1/AAF-100/design.md#studio-首页四行改版) 排列：统计卡、最近项目、蓝图、快速创作。整体偏 AIGC 项目生产，看不到用户自己的角色、技能、知识库、积分和正在运行的智能体。

本故事把首页改成通用智能体框架的座舱大屏：

- 最近项目和项目模板移到项目主页 `/studio/projects`。
- 首页中央是多智能体协作画布，展示助理、角色、技能、工具、知识库的静态关系，以及任务的动态运行状态（含审批）。
- 四周浮层展示我的资源、积分、运行统计、创作输入和最近生成。
- 首页面板有内置默认布局，用户可以显示或隐藏；预留以后自行添加图表的入口。
- 没有接口的数据先用示例数据（mock）实现界面，明确标注"示例数据"，后续逐步替换。

本故事修订 AAF-100 的"首页严格四个区块"约束，首页结构以本文为准。

## 布局设计

### Studio 首页 `/studio`（大屏模式，视口 ≥ 1280px 或全屏）

参考风格：智慧工厂类可视化大屏，中央三维/拓扑场景作背景，四周数据浮层；画布内容参考多智能体协作拓扑图与任务流程图。

│┌ 左栏 ──────┐                                              ┌ 右栏 ────────┐│
││ 我的资源    │                                              │ ▍积分      ˄ ││
││ 🧑 我的角色 12│         中央画布（铺满首页作背景层）          │ ◯ 可用 1,280 ││

#### 分层与尺寸

| 层 | 面板 key | 位置与尺寸 | 说明 |
|----|---------|-----------|------|
| 背景 | `canvas`（不可隐藏） | 铺满首页容器 `absolute inset-0` | 中央画布，图内容通过视口内边距落在中间 70%～80% |
| 页头 | 无（固定） | 顶部浮层，高 48px | 左：问候、昵称、日期时间；中：画布标签页；右：自定义、全屏 |
| 左栏 | `resources` | 左侧浮层，宽 12%（最小 160px，最大 190px），页头与底部区之间 | 我的资源列表 |
| 右栏 | `credits`、`agent-runs` | 右侧浮层，宽 22%（最小 260px，最大 340px），页头与底部区之间，内部纵向滚动 | 可折叠面板，默认展开 |
| 底部区 | `create`（含最近生成，不单独开关） | 浮在画布底部，背景透明，高度随内容（创作输入 + 最近生成 60px），内容 60% 宽居中；画布适应范围延伸到底部，不为它留白 | 可收起；收起后创作输入与最近生成一起隐藏，只留把手；隐藏创作时整块不显示 |

- 大屏模式下首页容器高度等于主内容区高度，不滚动；浮层不遮挡的区域都能直接操作画布（拖动、缩放、点击节点）。
- 浮层统一为半透明底（约 `bg-background/40`）加 `backdrop-blur`，细描边，标题前带强调竖条（不加四角刻线）。
- 左栏或右栏的面板全部被隐藏时，该侧浮层不渲染，画布可视区相应变宽。

#### 窄屏（小于 1280px）

退回纵向堆叠，页面可滚动：页头 → 画布（固定高 480px，手机 360px）→ 我的资源（2～3 列网格）→ 积分 → 运行统计 → 创作 → 最近生成。画布标签页放在画布区块顶部。

### 中央画布

用 `@xyflow/react`（项目已在流程编辑器使用）实现，放在 `features/studio/home/canvas/`。

- 背景：深色底，点阵网格（`Background`）加中心径向光晕和四周暗角，营造大屏场景感。
- 交互：可拖动、可缩放（滚轮缩放）；不显示小地图和缩放控件，右下角留一个"适应画布"按钮。节点不可拖动编辑、不可连线。
- 适应视图：`fitView` 时的内边距按浮层宽度设置（左约 14%、右约 24%、上 64px、下 220px），让图内容落在中间可视区。开工前核实当前 `@xyflow/react` 版本的 `fitViewOptions.padding` 是否支持分边设置；不支持时用统一内边距加初始 `viewport` 偏移。
- 切换标签页时画布内容淡入；每个画布独立创建 React Flow 实例。

| 标签页 | 总览 | 点击节点下钻 | 数据 |
|-------|------|-------------|------|
| 助理 | 助理 → 角色 → 技能 → 系统工具 / 业务工具 / 知识库拓扑 | 点助理或角色，看其运行中的任务流程（含待审批） | 总览真实数据；任务流程示例数据，待 AAF-115 |
| 项目任务 | 左列 AIGC 项目，右列各项目最近的根执行记录 | 点执行记录看执行树；点项目进入项目详情 `/studio/projects/{id}` | 真实数据：`/aigc/execution-runs?rootOnly=true`、`/aigc/execution-runs/{id}/tree`、`/aigc/projects`；没有记录或接口不可用时示例数据 |

#### 助理：总览

按"助理 → 角色 → 技能 → 工具 / 知识库"从左到右排布，参考多智能体协作拓扑图。

| 节点 | 数据来源 | 展示 |
|------|---------|------|
| 助理 | `useAiRoleLibrary()` 的 `assistantId`；名称取 `useAssistants()` 中对应项 | 圆形发光主节点，右上角"N 运行中"呼吸角标（演示阶段为示例任务数） |
| 角色 | `useAiRoleLibrary().items` 中 `bound === true` 的 `role`；按 `categoryId` 分组，分类名与顺序取 `/ai/role-categories`（`useAiRoleCategories()`），不在其中的归"未分类" | 卡片：名称、可见性标签（内置/公开/私有）、启用状态点、默认角色标记、技能/工具/知识库数量。每个分类用虚线框包住，点框标题折叠为一张虚线卡片（显示分类名与角色数，连线汇到卡片上），点卡片展开；只有未分类角色时不画框 |
| 技能 | 角色 `skillBindings[].skillKey`；名称尽量取 `useAiSkills()` 中对应项；紧跟角色一列。系统级技能（`builtin-*` 及 `system.skill.content-project-collaboration`、`system.skill.assistant-blueprint-planning`）收拢为"系统技能 N 个"节点；其余 `builtIn` 为真的标"内置"，其他（含查不到的）标"我的" | 汇总卡片 + 小卡片 |
| 工具 | 角色 `toolWhitelist`（JSON 字符串数组，解析失败按空处理）与技能当前版本的 `toolRequirements`。平台控制类工具（任务控制、执行上报、澄清、`context.load`、`knowledge_search`、`render_ui_block`、`script.execute.javascript`，名单与后端 `BuiltinControlToolProfile` 同步）收拢为"系统工具 N 个"节点；其余为业务工具，逐个显示 | 汇总卡片 + 小卡片 |
| 知识库 | 角色 `knowledgeBaseIds`（stable_id）；名称尽量取 `useKnowledgeBases()` 中匹配项，取不到显示 ID 前 8 位；与工具同列、排在最下方 | 小卡片 |

- 技能声明了所需工具时画"技能 → 工具"连线；角色工具清单中未被其技能声明的工具才从角色直连。
- "系统技能""系统工具"与所有"+N"节点（含角色）可点击就地展开全部条目，再点收起；收起时被收拢条目的连线汇到该节点。
- 同一个技能、工具或知识库被多个角色或技能使用时只画一个节点，多条连线汇入。
- 连线按资源类型着色（技能、工具、知识库三色），助理到角色用粗线。
- 悬停节点停留 500ms 后沿连线向上游、下游各走一遍，高亮整条关联链路（如悬停工具高亮声明它的技能、使用它的角色和助理），其余节点与连线淡化。
- 单列超过 12 个时按比例折叠为"+N"汇总节点。
- 点击助理或角色节点下钻；点击知识库节点跳到 `/studio/knowledge`，点击技能节点跳到 `/studio/assets/skills`。
- 没有默认助理或没有绑定角色时，展示示例拓扑，左上角显示"示例数据"标记。

#### 助理：下钻任务流程（示例数据）

参考任务流程图：触发 → 协调者 → 规划 / 记忆 / 知识检索 → 各执行步骤 → 审批 → 交付。左上角面包屑"助理 / {名称}"。

- 步骤节点：图标、名称、所用角色或工具、状态（已完成 / 运行中 / 待审批 / 等待中 / 失败）与耗时。
- 运行中的连线流动，已完成的连线显示处理条数，未开始的置灰。
- 待审批节点琥珀色高亮，节点内有"批准""驳回"；演示阶段只弹提示"示例数据，暂不提交"，批准后继续推进，驳回后该步失败。
- 顶部居中任务切换条（示例 3 个任务）；状态每 1.5 秒按脚本推进一步，到审批停住。
- 演示阶段不区分点的是助理还是哪个角色，都展示同一组示例任务。将来：点助理看全部任务，点角色只看用该角色执行的任务（AAF-115）。

#### 项目任务

- 总览：项目节点（名称、执行次数、运行中数量）连到其最近的根执行记录节点（复用任务步骤节点：动作、目标类型与角色、状态、耗时）；有运行中记录的项目排前面，最多 6 个项目、每个 4 条记录。
- 执行状态映射：等待绑定 / 排队 → 等待中，运行中 → 运行中（连线流动），成功 / 部分成功 → 已完成，失败 / 取消 → 失败。
- 下钻：执行树按父子层级从左到右排布；面包屑"项目任务 / {动作}"。执行树视图没有起止时间，耗时只在总览显示。
- 接口受 AIGC License 与 `aigc:execution-run:read` 权限约束；失败或没有记录时用示例项目与执行记录，并标"示例数据"。示例下钻不调接口。

#### 工作流（示例数据）

- 展示一个示例 AI 工作流"客户咨询自动答复"：开始 → 意图识别（LLM）→ 知识库检索 / 历史会话 / 订单查询（并行）→ 生成答复（Agent）→ 合规检查 → 人工确认 → 发送答复，运行状态复用任务流程的推进与审批演示。
- 左上角显示工作流名称与"示例数据"标记。
- 后续：用户的 AI 工作流列表来自 `/api/ai/workflows`，节点图直接用 `definition` 中保存的 ReactFlow 节点与连线；运行实例需要后端补"按工作流查询运行实例"接口。Studio 用户侧创建工作流的入口另立用户故事。

### 左栏：我的资源

图标 + 名称 + 数字的竖向列表，不套带标题的面板，平时没有背景和边框，直接浮在画布上；名称尽量两个字，完整含义放在悬停提示里（如"项目"提示"我的全部项目，其中进行中 N 个"）；悬停时出现 20% 不透明背景（`bg-background/20` 加模糊）和细边框，并显示箭头，整行可点击跳转。

| 行 | 数据来源 | 口径 | 点击跳转 |
|----|---------|------|---------|
| 角色 | `useAiRoleLibrary()` 的 `boundCount` | 默认助理已绑定的角色数，与协作画布一致 | `/settings/assistant-roles` |
| 技能 | `useAiRoleLibrary()` 中已绑定角色的 `skillBindings` | 已绑定角色用到的技能数（按 key 去重），与协作画布一致 | `/studio/assets/skills` |
| 知识库 | `useKnowledgeBases({ pageSize: 1 })` 的 `total` | 当前用户可访问的知识库数 | `/studio/knowledge` |
| 项目 | `useAigcProjects({ pageSize: 1 })` 的 `total` | 我的全部项目数；悬停提示附 `activeProjectCount`（创建中 + 执行中） | `/studio/projects` |
| 任务 | `useAigcStudioHomeSummary()` 的 `activeTaskCount` | 沿用现有口径 | `/studio/me/generations` |
| 失败 | `useAigcStudioHomeSummary()` 的 `failedTaskCount` | 沿用现有口径，大于 0 时数字标红 | `/studio/me/generations` |

- 每行独立取数，接口失败时该行数字显示"—"。`home-summary` 受 AIGC License 限制，失败时只影响后三行。
- 角色入口目前在 workspace 的设置页，点击会离开 Studio 外壳。把角色入口搬进 Studio 不在本故事范围内。

### 右栏：可折叠面板

右栏面板都可以折叠，默认展开；折叠状态记入首页布局偏好。

| 面板 | 展开时 | 折叠成一行时 | 数据 |
|------|-------|-------------|------|
| 积分 | 环形图（环心可用积分，悬停分段显示分类、积分、占比）+ 近 14 天消耗趋势折线 + 近 30 天消耗 | 可用积分 · 近 30 天消耗 | 真实数据，见下文"积分数据" |
| 智能体运行统计 | 近 7 天成功与失败堆叠柱状图 | 近 7 天成功 N · 失败 N | 示例数据，标"示例数据" |

- 标题行右侧放折叠箭头和"积分中心 ›"等跳转链接；折叠行整行可点击展开。
- 面板展开、折叠有高度过渡动画。

### 底部区：创作与最近生成

- **创作**：嵌入 `MediaGenerationWorkspace embedded`（AI 生图、AI 视频、配音、音乐、3D），宽度 60% 居中，高度随工作台内容，不出滚动条。提交后进度在右下角任务面板查看，完成后出现在最近生成。
- **最近生成**（60px）：在创作输入正下方，与输入同宽。一行垂直居中：左侧标题"最近生成"，中间最多 15 个 36px 缩略图（或加载、空、失败提示），右侧"查看全部 ›"进入 `/studio/assets/materials`。悬停缩略图放大预览（约 96px 浮层），点击图片、视频在灯箱中预览，点击音频直接播放。数据来自 `useMediaList`，生成完成的实时事件会刷新它。
- **收起**：把手在创作内容右上角。收起后创作输入与最近生成一起隐藏，只留把手，画布可视区下移变大。收起状态记入首页布局偏好。
- 底部区浮在画布上，背景透明，只有内容本身拦截鼠标，两侧空白处可直接拖动画布；画布适应视图的范围延伸到底部。"适应画布"按钮在画布右下角。

### 积分数据

- 可用积分：`useCreditGroups()` 各分组 `remain` 之和，与积分中心"可用余额"一致。
- 分类名称：复用 `ExpensesCategoryWidget.tsx` 导出的 `useBillingCategoryMeta()`（字典优先、本地映射兜底）与 `CATEGORY_COLORS`，与积分中心的分类图同名同色。
- 可用积分与消耗分类各自降级：某一份数据失败，只把对应数字显示为"—"。没有消耗时显示灰色底环。

积分没有用户级统计接口。`/api/stats/credits/*` 只对 `ADMIN/SUPER_ADMIN` 开放。`/studio/me/credits` 取最近 100 条流水（`useCreditTransactions(0, 100)`）聚合趋势和分类；本故事把两份聚合抽成派生 hook，首页与积分中心共用：

- `useCreditSpendTrend(days = 14)`：近 N 天每日 `SPEND` 金额，没有消耗的日期补 0。
- `useCreditSpendCategories(days = 30)`：近 N 天 `SPEND` 按 `category` 汇总，`category` 为空时归入 `other`，按金额降序。
- 两个 hook 复用 `useCreditTransactions(0, 100)` 的 queryKey，用 `select` 派生，共用一份缓存。
- 积分中心分类卡片底部写的是"30 天总消耗"，原来没有按时间过滤，借本故事修正。
- 仍以最近 100 条为上限。消耗频繁的用户统计会偏小，这是已知限制，全量统计留给后续的用户级接口。

### 屏幕模式与顶栏

- **大屏模式**：视口 ≥ 1280px 或处于全屏时启用上文的分层布局；否则使用窄屏堆叠布局。
- **全屏（投屏）**：页头"全屏"按钮对首页容器调用浏览器 Fullscreen API，只投出首页内容，不含 Studio 侧栏和顶栏。按 Esc 或点"退出全屏"退出。浏览器不支持全屏时不显示按钮；请求被拒绝时提示。全屏时隐藏"自定义"按钮（其 Popover 渲染到 `body`，全屏元素之外看不到）。
- **顶栏收起**：只在首页生效，打开首页时 Studio 顶栏默认收起，下沿正中留一个小把手（56×14px），点击展开或收起。收起时把手用主题色描边和光晕提示，不加动画。状态存在 `useStudioShell`（sessionStorage，与侧栏折叠一致），其他页面的顶栏始终展开。收起时顶栏设为 `inert`。
