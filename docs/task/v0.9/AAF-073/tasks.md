# 支付系统（AAF-073）

> 负责人：architect + developer-service | 创建：05-19

## 任务列表

### 支付对接

1. [x] #7301 微信支付对接
   - 微信支付 V3 API 集成（JSAPI/Native/H5/小程序支付）
   - 统一支付抽象层（PaymentService 接口、策略模式）
   - 支付参数签名与验签（SHA256-RSA、证书管理）
   - 支付回调处理（异步通知接收、幂等校验、状态更新）
   - verify: 微信支付下单→支付→回调全流程通过

2. [x] #7302 支付宝对接
   - 支付宝开放平台 API 集成（电脑网站/手机网站/APP 支付）
   - 支付宝适配器实现（复用统一支付抽象层）
   - RSA2 签名与验签、证书模式配置
   - 支付宝回调处理（同步跳转 + 异步通知）
   - verify: 支付宝支付下单→支付→回调全流程通过

### 订单管理

3. [x] #7303 订单管理
   - 订单表设计（订单号生成策略、状态机：待支付/已支付/已退款/已关闭）
   - 订单创建（关联商品/套餐、金额计算、优惠抵扣）
   - 订单查询（按状态/时间/用户筛选、分页）
   - 订单超时关闭（延迟队列、超时自动取消未支付订单）
   - verify: 订单全生命周期状态流转正确，超时关闭生效

4. [x] #7304 退款处理
   - 退款申请（全额/部分退款、退款原因）
   - 退款执行（调用微信/支付宝退款 API、异步结果处理）
   - 退款状态追踪（退款中/成功/失败、失败重试）
   - 退款通知（退款成功→通知用户、更新订单状态）
   - verify: 退款申请→执行→回调→状态更新全流程通过

### 对账

5. [x] #7305 对账系统
   - 每日对账（下载微信/支付宝账单、与本地订单比对）
   - 差异处理（金额不一致/状态不一致/单边账标记）
   - 对账报告生成（日报/月报、差异明细、处理建议）
   - 财务统计（收入/退款/手续费汇总、趋势图表）
   - verify: 对账正确识别差异，报告数据准确
