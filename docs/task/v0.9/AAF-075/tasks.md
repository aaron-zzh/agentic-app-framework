# 渠道集成（AAF-075）

> 负责人：architect + developer-service | 创建：05-19

## 任务列表

### 微信生态

1. [ ] #7501 微信公众号/小程序消息
   - 微信公众号消息接入（文本/图片/语音/事件消息接收与回复）
   - 小程序客服消息接入（会话消息收发）
   - 模板消息/订阅消息推送（事件触发→消息推送）
   - 微信菜单管理（自定义菜单创建/更新）
   - verify: 公众号消息收发正常，模板消息推送成功

2. [ ] #7502 钉钉/飞书机器人
   - 钉钉企业内部机器人（消息接收/回复、卡片消息）
   - 飞书自建应用机器人（事件订阅、消息发送）
   - 机器人指令解析（/命令 格式、参数提取）
   - 富文本消息支持（Markdown、卡片、按钮交互）
   - verify: 钉钉/飞书机器人消息收发正常，指令解析正确

### 通用集成

3. [ ] #7503 Webhook 集成
   - Webhook 注册管理（URL、事件类型、密钥配置）
   - 事件触发推送（HTTP POST、签名验证、重试机制）
   - Webhook 日志（推送记录、响应状态、失败原因）
   - 入站 Webhook（接收外部系统推送、事件转换）
   - verify: 事件触发后 Webhook 正确推送，重试机制生效

4. [ ] #7504 统一消息路由
   - 消息路由引擎（根据渠道类型→路由到对应处理器）
   - 消息格式统一化（各渠道消息→内部统一消息模型）
   - 回复路由（内部回复→转换为对应渠道格式→发送）
   - 渠道优先级与降级（首选渠道不可用→降级到备选渠道）
   - verify: 多渠道消息正确路由，格式转换无丢失

### 渠道管理

5. [ ] #7505 渠道管理后台
   - 渠道配置页面（各渠道 AppID/Secret/Token 配置）
   - 渠道状态监控（连接状态、消息量统计、错误率）
   - 渠道测试（发送测试消息、验证连通性）
   - 消息统计面板（按渠道/时间/类型统计消息量）
   - verify: 渠道配置后连通性测试通过，统计数据准确
