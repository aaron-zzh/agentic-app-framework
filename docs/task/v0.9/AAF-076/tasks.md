# 客服系统（AAF-076）

> 负责人：architect + developer-service + developer-webui | 创建：05-19

## 任务列表

### 智能客服

1. [ ] #7601 智能客服 Agent
   - 客服 Agent 定义（角色 Prompt、知识库绑定、工具绑定）
   - 常见问题自动回答（FAQ 知识库匹配、RAG 增强回答）
   - 意图识别与路由（咨询/投诉/退款/技术支持→不同处理流程）
   - 多轮对话管理（上下文保持、信息收集、确认操作）
   - verify: 常见问题正确回答，复杂问题正确路由

2. [ ] #7602 人工接入
   - 转人工触发条件（用户主动请求/Agent 置信度低/敏感问题）
   - 人工坐席分配（按技能组/空闲度/优先级分配）
   - 会话接管（Agent→人工无缝切换、历史消息同步）
   - 坐席工作台（待接入列表、当前会话、快捷回复、知识库搜索）
   - verify: 转人工流程顺畅，历史消息完整传递

### 会话管理

3. [ ] #7603 会话转接与协作
   - 会话转接（当前坐席→其他坐席/技能组、转接原因记录）
   - 多人协作（邀请其他坐席加入会话、内部讨论不可见用户）
   - 会话标签（标记会话类型/优先级/状态）
   - 会话超时处理（用户无响应→自动关闭、坐席无响应→重新分配）
   - verify: 转接后会话上下文完整，协作消息隔离正确

4. [ ] #7604 满意度评价
   - 会话结束后评价邀请（1-5 星 + 文字评价）
   - 评价统计（平均分、分布、趋势、按坐席统计）
   - 差评预警（低分评价→通知主管、触发回访）
   - 评价与会话关联（查看评价时可回溯完整会话）
   - verify: 评价流程正常，统计数据准确

### 工单系统

5. [ ] #7605 工单管理
   - 工单创建（会话中创建/手动创建、关联用户和会话）
   - 工单流转（待处理→处理中→待确认→已关闭、SLA 时效）
   - 工单分配（按类型/优先级自动分配、手动转派）
   - 工单统计（处理时长、解决率、超时率、分类分布）
   - verify: 工单全生命周期流转正确，SLA 超时告警生效
