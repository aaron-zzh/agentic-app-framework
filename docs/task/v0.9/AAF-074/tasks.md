# 会员与积分（AAF-074）

> 负责人：architect + developer-service + developer-webui | 创建：05-19

## 任务列表

### 会员体系

1. [ ] #7401 会员等级
   - 会员等级定义（免费/基础/专业/企业，权益配置）
   - 等级升降规则（积分累计/消费金额/手动调整）
   - 等级权益（API 调用额度、存储空间、模型选择范围）
   - 会员到期处理（到期提醒、降级策略、续费优惠）
   - verify: 会员等级正确计算，权益限制生效

2. [ ] #7402 积分充值
   - 积分套餐定义（金额→积分映射、赠送规则）
   - 充值接口（对接支付系统、充值成功→积分到账）
   - 充值记录（时间、金额、积分数、支付方式）
   - 充值优惠（首充奖励、满赠活动、限时折扣）
   - verify: 充值→支付→积分到账全流程通过

### 积分消费

3. [ ] #7403 积分消费与 Token 规则
   - Token 额度规则（积分→Token 兑换比例、按模型差异化定价）
   - 消费扣减（API 调用→计算 Token→扣减积分、余额不足拦截）
   - 消费记录（调用时间、模型、Token 数、扣减积分数）
   - 额度预警（余额低于阈值→提醒充值）
   - verify: Token 消费正确扣减积分，余额不足时拦截请求

4. [ ] #7404 消费记录与账单
   - 消费明细查询（按时间/类型/模型筛选、分页）
   - 日/月账单生成（消费汇总、趋势图、Top 消费项）
   - 账单导出（PDF/CSV 格式）
   - 消费分析（使用模式分析、成本优化建议）
   - verify: 账单数据准确，导出格式正确

### 前端展示

5. [ ] #7405 会员中心前端
   - 会员信息页（当前等级、积分余额、到期时间、权益列表）
   - 充值页面（套餐选择、支付方式、充值记录）
   - 消费记录页（明细列表、筛选、图表统计）
   - 升级引导（当前等级 vs 高级等级权益对比、升级按钮）
   - verify: 会员中心各页面数据正确展示，交互流畅
