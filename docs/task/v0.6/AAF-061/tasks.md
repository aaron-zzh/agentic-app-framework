# 工作流 AG-UI（AAF-061）

> 负责人：architect + developer-service + developer-webui | 创建：05-19

## 任务列表

### 协议适配

1. [x] #6101 AG-UI 协议适配
   - 工作流实例包装为 AG-UI Agent 接口（统一会话模型）
   - 会话创建与工作流实例绑定
   - AG-UI 消息类型映射（工作流事件→AG-UI 事件流）
   - 多工作流实例并发会话隔离
   - verify: 通过 AG-UI 协议创建会话并触发工作流执行

2. [x] #6102 流程状态实时推送
   - SSE 推送节点执行进度（开始/完成/失败/跳过）
   - 当前步骤高亮数据（活跃节点ID列表）
   - 等待用户输入事件推送（表单填写、审批操作）
   - 心跳与断线重连机制
   - verify: 前端实时接收流程状态变化，断线后自动恢复

### 对话交互

3. [x] #6103 对话式流程交互
   - 用户通过对话触发流程启动（意图识别→匹配流程定义）
   - 对话中填写表单节点（动态表单渲染为对话卡片）
   - 对话中审批操作（同意/拒绝/加签按钮卡片）
   - 流程执行结果以对话消息形式返回
   - verify: 纯对话方式完成一个完整审批流程

4. [x] #6104 流程可视化面板
   - 运行中流程实时状态图（节点状态着色：灰/蓝/绿/红）
   - 历史执行路径回放（按时间轴回放节点执行顺序）
   - 耗时统计（各节点耗时、总耗时、瓶颈节点标识）
   - 流程实例列表与筛选（按状态/发起人/时间）
   - verify: 流程图实时更新状态，回放功能正确

### 发布管理

5. [x] #6105 工作流发布与版本
   - 编排完成→发布为可对话 Agent（一键发布）
   - 版本管理（发布版本号、历史版本列表、版本对比）
   - 灰度切换（新版本灰度比例配置、流量分配）
   - 下线/归档操作
   - verify: 发布后通过 AG-UI 可正常对话触发新版本流程
