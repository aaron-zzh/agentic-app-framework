# 审批流程（AAF-062）

> 负责人：architect + developer-service + developer-webui | 创建：05-19

## 任务列表

### 审批核心

1. [ ] #6201 审批节点设计
   - 审批人策略（指定人/角色/部门主管/发起人自选/表达式动态计算）
   - 审批表单配置（关联表单定义、必填字段、审批意见）
   - 审批超时处理（自动通过/自动拒绝/转交/提醒）
   - 空审批人处理（自动跳过/转管理员/报错）
   - verify: 各种审批人策略正确解析，超时策略触发正常

2. [ ] #6202 会签与或签
   - 多人会签（全部通过才通过、任一拒绝即拒绝）
   - 或签（任一通过即通过）
   - 比例通过（通过率 ≥ 阈值即通过，可配置）
   - 投票模式（展示投票进度、已投/未投人员列表）
   - verify: 会签/或签/比例通过逻辑正确，边界情况处理

### 审批操作

3. [ ] #6203 加签与转签
   - 前加签（在当前审批人之前插入新审批人）
   - 后加签（在当前审批人之后追加新审批人）
   - 转签（当前审批人转交给他人处理）
   - 审批撤回（发起人撤回、已审批节点撤回条件判断）
   - verify: 加签/转签后流程正确流转，撤回条件校验生效

4. [ ] #6204 审批记录与通知
   - 审批意见记录（审批人、操作、意见内容、时间戳）
   - 审批时间线展示（按时间顺序展示所有审批动作）
   - 多渠道通知（站内信/邮件/钉钉/企业微信，按用户偏好）
   - 催办功能（手动催办 + 自动催办规则）
   - verify: 审批记录完整，通知按配置渠道发送

### 权限集成

5. [ ] #6205 权限体系集成
   - 审批权限与 RBAC 联动（角色→可审批的流程类型）
   - 数据权限控制（审批人只能看到权限范围内的审批单）
   - 审批代理人设置（请假时指定代理人、代理有效期）
   - 审批统计（个人审批效率、平均处理时长、超时率）
   - verify: 权限控制生效，代理人可正常代审
