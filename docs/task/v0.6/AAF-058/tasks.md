# 工作流引擎（AAF-058）

> 负责人：architect + developer-service | 创建：05-19

## 任务列表

### 引擎集成

1. [ ] #5801 Flowable 集成
   - Spring Boot 4 集成 Flowable 7（引擎配置、数据源、事务管理）
   - 流程引擎初始化与数据库表自动创建
   - 自定义 ID 生成器、历史记录级别配置
   - 与现有 aaf-framework 模块集成（包路径、Bean 注册）
   - verify: 应用启动成功，Flowable 表创建完成，引擎可用

2. [ ] #5802 流程定义管理
   - 流程定义 CRUD API（创建/查询/更新/删除）
   - BPMN 2.0 模型解析与校验
   - 版本管理（同名流程自动递增版本号）
   - 部署/挂起/激活操作、流程定义分类与标签
   - verify: 流程定义部署后可查询，版本号正确递增

### 实例与任务

3. [ ] #5803 流程实例管理
   - 流程启动（按定义ID/Key 启动、传入业务变量）
   - 实例状态查询（运行中/已完成/已挂起/已终止）
   - 实例操作（挂起/激活/终止/删除）
   - 流程变量管理（设置/获取/修改运行时变量）
   - 历史实例查询与统计
   - verify: 流程启动→执行→完成全生命周期正常

4. [ ] #5804 任务分配与流转
   - 用户任务分配策略（指定人/角色/部门/抢占式）
   - 任务操作（签收/完成/委派/转办/退回）
   - 催办机制（超时提醒、SLA 配置）
   - 任务查询（我的待办/已办/发起的流程）
   - verify: 任务分配→签收→完成流程通过，催办触发正常

### 高级特性

5. [ ] #5805 条件网关与事件
   - 排他网关（条件表达式、默认分支）
   - 并行网关（Fork/Join、并行任务同步）
   - 包容网关（条件并行、部分分支执行）
   - 定时器事件（延迟/周期/截止日期）
   - 信号/消息事件、错误边界事件
   - verify: 各类网关路由正确，定时器按时触发
