# 可视化编排（AAF-059）

> 负责人：architect + developer-webui | 创建：05-19

## 任务列表

### 画布基础

1. [ ] #5901 XYFlow 流程设计器
   - 基于 @xyflow/react 搭建流程编辑画布
   - 画布操作（缩放/平移/适应屏幕/小地图）
   - 撤销/重做（操作历史栈）
   - 键盘快捷键（Delete 删除、Ctrl+Z 撤销、Ctrl+C/V 复制粘贴）
   - 画布状态持久化（自动保存草稿）
   - verify: 画布基础交互流畅，撤销/重做正确

2. [ ] #5902 节点与连线体系
   - 自定义节点类型（开始/结束/用户任务/服务任务/网关/子流程/注释）
   - 节点样式（图标、颜色、状态指示）
   - 连线规则校验（开始节点只出不入、结束节点只入不出、网关连线数约束）
   - 连线锚点（上下左右四向）、连线标签（条件表达式）
   - verify: 节点拖拽创建、连线规则校验生效

### 属性与模板

3. [ ] #5903 属性面板
   - 节点选中后右侧属性编辑面板
   - 表单动态渲染（根据节点类型展示不同配置项）
   - 条件表达式编辑器（变量选择 + 运算符 + 值，支持 UEL 表达式）
   - 任务分配配置（指定人/角色/表达式）
   - verify: 属性修改实时反映到节点，表达式语法校验

4. [ ] #5904 模板库
   - 流程模板 CRUD（保存当前流程为模板、模板分类管理）
   - 内置模板（请假审批、报销审批、通用多级审批）
   - 一键从模板创建新流程、模板预览缩略图
   - verify: 从模板创建流程后可正常编辑和部署

### 数据互转

5. [ ] #5905 设计器↔BPMN 互转
   - 画布 JSON → BPMN 2.0 XML 导出（节点坐标→DI 信息）
   - BPMN XML → 画布 JSON 导入（解析 DI 信息→节点坐标）
   - 导入/导出校验与错误提示（缺失必填项、无效连线）
   - 与后端流程定义部署 API 对接
   - verify: 导出的 BPMN XML 可被 Flowable 正确解析部署
