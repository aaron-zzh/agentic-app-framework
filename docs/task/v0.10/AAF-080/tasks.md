# 画板视图（AAF-080）

> 负责人：architect + developer-webui | 创建：05-19

## 任务列表

### 画板核心

1. [x] #8001 画板引擎集成
   - 基于 tldraw 或 excalidraw 集成画板引擎
   - 基础绘制工具（矩形/圆形/箭头/文本/自由画笔/便签）
   - 画布操作（无限画布、缩放/平移、网格对齐、标尺）
   - 选择与变换（多选、对齐、分布、分组/取消分组）
   - verify: 基础绘制工具可用，画布操作流畅

2. [x] #8002 协作白板
   - 实时协作（Yjs CRDT 同步、多人光标显示）
   - 协作者列表（在线用户头像、正在编辑区域高亮）
   - 冲突处理（同时编辑同一元素时的合并策略）
   - 协作历史（操作时间线、按用户筛选变更）
   - verify: 多用户同时编辑不冲突，实时同步延迟 < 200ms

### 高级功能

3. [x] #8003 智能元素
   - 便签（富文本内容、颜色分类、连线关联）
   - 嵌入卡片（嵌入实体数据卡片、实时数据更新）
   - 思维导图模式（自动布局、节点展开/折叠、拖拽调整）
   - 流程图模式（连接线自动路由、节点对齐辅助线）
   - verify: 智能元素正确渲染，嵌入数据实时更新

4. [x] #8004 AI 辅助
   - AI 生成图表（描述→自动生成流程图/思维导图/架构图）
   - AI 整理布局（选中元素→AI 自动排列对齐）
   - AI 内容建议（根据画板内容建议补充节点/关系）
   - 手绘→规范图转换（手绘草图→规范化矢量图形）
   - verify: AI 生成图表结构合理，布局整理效果良好

### 视图集成

5. [x] #8005 嵌入实体视图
   - 画板视图作为 ViewEngine 视图类型注册
   - 实体关联（画板关联到具体实体记录、作为附件存储）
   - 画板模板（预设模板：头脑风暴/项目规划/用户旅程地图）
   - 导出（PNG/SVG/PDF 导出、分享链接）
   - verify: 画板视图在实体详情中正确嵌入，导出格式正确
