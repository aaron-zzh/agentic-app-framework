## 任务列表

### 拖拽与泳道

1. [ ] #7901 拖拽排序
   - 列内拖拽排序（卡片上下拖拽调整顺序、持久化排序值）
   - 跨列拖拽（拖拽到其他列→状态变更 + 排序更新）
   - 批量拖拽（多选卡片→批量移动到目标列）
   - 拖拽动画（平滑过渡、占位符指示、拖拽预览）
   - verify: 拖拽排序正确持久化，刷新后顺序不变

2. [ ] #7902 泳道
   - 泳道配置（按指定字段分组：优先级/负责人/标签/自定义）
   - 泳道折叠/展开（折叠后显示摘要计数）
   - 泳道内独立排序（每个泳道内卡片独立排序）
   - 泳道统计（每个泳道的卡片数、完成率）
   - verify: 泳道按配置字段正确分组，折叠/展开正常

### 限制与统计

3. [ ] #7903 WIP 限制
   - 每列 WIP 上限配置（超限时列标题变红警告）
   - WIP 策略（硬限制：禁止拖入 / 软限制：允许但警告）
   - WIP 历史（超限次数统计、超限时长记录）
   - 全局 WIP 仪表盘（各列当前数/上限、健康度指示）
   - verify: WIP 超限时正确警告或拦截，统计数据准确

4. [ ] #7904 看板统计
   - 累积流图（各状态卡片数量随时间变化）
   - 周期时间分布（卡片从创建到完成的时间分布）
   - 吞吐量统计（每日/周完成卡片数）
   - 阻塞分析（标记为阻塞的卡片、阻塞时长排行）
   - verify: 统计图表数据正确反映看板实际状态

   - 卡片快捷操作（悬浮显示操作按钮：编辑/删除/标签/指派）
