# 日历视图（AAF-078）

> 负责人：architect + developer-webui | 创建：05-19

## 任务列表

### 日历核心

1. [x] #7801 日历组件
   - 基于 FullCalendar 或自研日历组件（月/周/日三种视图）
   - 事件渲染（标题、时间、颜色标记、全天/时段事件）
   - 日历导航（前进/后退/今天、日期选择器跳转）
   - 响应式布局（桌面端完整视图、移动端列表视图降级）
   - verify: 三种视图正确渲染事件，导航切换流畅

2. [x] #7802 事件 CRUD
   - 事件创建（点击空白时段→弹出创建表单、快速创建）
   - 事件编辑（点击事件→编辑弹窗、字段：标题/时间/描述/参与人/重复规则）
   - 事件删除（单次删除/删除所有重复事件）
   - 重复事件（每日/每周/每月/自定义 RRULE、例外日期）
   - verify: 事件 CRUD 全流程正常，重复事件正确展开

### 交互增强

3. [x] #7803 拖拽调整
   - 事件拖拽移动（拖拽到其他日期/时段、乐观更新）
   - 事件拖拽调整时长（拖拽底边调整结束时间）
   - 跨视图拖拽（周视图拖到日视图）
   - 拖拽冲突检测（时间重叠提示）
   - verify: 拖拽操作正确更新事件时间，冲突提示生效

4. [x] #7804 多视图切换
   - 日视图（时间轴 + 事件块、当前时间线指示）
   - 周视图（7 列时间网格、工作日/周末区分）
   - 月视图（日期格子 + 事件摘要、溢出"+N 更多"）
   - 议程视图（按时间排序的事件列表、分组展示）
   - verify: 各视图数据一致，切换无闪烁

### 数据联动

5. [x] #7805 实体数据联动
   - 日历视图作为 ViewEngine 视图类型注册
   - EntityDef 日期字段→日历事件映射（开始/结束字段配置）
   - 实体数据变更→日历自动刷新
   - 日历事件操作→触发实体数据更新
   - 与任务/项目实体联动（任务截止日期在日历展示）
   - verify: 实体数据变更后日历正确更新，双向联动生效
