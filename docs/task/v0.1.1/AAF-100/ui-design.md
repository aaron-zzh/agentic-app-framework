# Studio 首页 UI 设计

> 本文是 [AAF-100 需求](./requirement.md) 的界面交付物。设计采用 Reduction MVP：首页聚焦“了解概况、从蓝图开始、继续项目、快速创作”，不重构既有创作页面。

## 设计目标

- **严格四区**：页面内容只包含统计卡、最近项目、蓝图、快速创作四个顶层 `section`，顺序不可交换。
- **蓝图优先**：用深色横向封面卡呈现蓝图，点击卡片直接建项，不增加蓝图详情中转页。
- **信息可信**：仅展示接口已有的蓝图名称、项目类型、生产模式等字段，不展示作者、使用人数、热度等无数据依据的信息。
- **独立可恢复**：四个区块独立加载、独立失败；单一区块异常不阻塞其他区块。
- **多端同构**：响应式只改变区块内部网格和 Dialog 形态，不改变四区数量、顺序或业务语义。

## 设计基线

所有颜色、字体、间距、圆角和状态组件均复用 [AAF Design System](../../../design/ui/design-system.md)，不创建页面私有色值。

| 用途 | 现有语义 token |
|------|----------------|
| 页面背景 | `surface` |
| 普通卡片 | `surface-container-low`、`on-surface` |
| 卡片悬停 | `surface-container` |
| 分隔线 | `outline-variant` |
| 次级文字 | `on-surface-variant` |
| 主操作与焦点 | `primary`、`on-primary` |
| 蓝图深色封面 | `surface-dark`、`surface-dark-container`、`on-surface-dark` |
| 信息提示 | `info` |
| 成功状态 | `success` |
| 警告状态 | `warning` |
| 错误状态 | `danger`、`exception-card` |
| 标题与正文 | `h2`、`h3`、`body-md`、`label-md`、`label-sm` |
| 组件形状 | `rounded.md`、`rounded.lg`、`rounded.xl`、`rounded.full` |
| 间距 | `spacing.xs`、`spacing.sm`、`spacing.md`、`spacing.lg`、`spacing.xl` |

页面沿用现有 Studio 外壳、导航、内容最大宽度和页面标题。全局导航、面包屑、页面标题及消息提示不计入四个内容区块。

## 严格四区布局

页面主体使用一个纵向容器，区块间距为 `spacing.xl`。每个顶层区块均有稳定的 `section` 容器和可访问标题；区块内部允许卡片换行，但不得拆成新的顶层区块。

```text
┌──────────────────────────────────────────────────────────────┐
│ Studio 页面标题（页面外壳，不计入内容区）                    │
├──────────────────────────────────────────────────────────────┤
│ 统计卡                                        第一内容区      │
│ [现有统计] [现有统计] [现有统计] [现有统计]                  │
├──────────────────────────────────────────────────────────────┤
│ 最近项目                                      第二内容区      │
│ [项目卡] [项目卡] [项目卡] [项目卡]                          │
├──────────────────────────────────────────────────────────────┤
│ 蓝图                                          第三内容区      │
│ [类型 Tab] [类型 Tab] [类型 Tab] ...                         │
│ [深色横向蓝图卡] [深色横向蓝图卡] [深色横向蓝图卡]          │
├──────────────────────────────────────────────────────────────┤
│ 快速创作                                      第四内容区      │
│ [图像] [视频] [文案] [配音] [音乐] [数字人]                  │
└──────────────────────────────────────────────────────────────┘
```

| 顺序 | 区块标识 | 固定标题 | 内容布局 |
|------|----------|----------|----------|
| 第一 | `studio-stats` | 沿用现有统计标题 | 沿用现有统计卡及其口径；只调整为响应式网格 |
| 第二 | `studio-recent-projects` | 最近项目 | 现有最近排序结果或本区状态反馈 |
| 第三 | `studio-blueprints` | 蓝图 | 标题、项目类型 Tabs、当前 Tab 面板 |
| 第四 | `studio-quick-create` | 快速创作 | 六个必备入口及既有有效入口 |

禁止项：不渲染“最近生成”；不在四区之间插入 Banner、推荐流或独立 CTA 区；空态和错误态必须留在所属 `section` 内。

## 统计卡

第一内容区仅复用现有统计项、显示格式、数据口径与权限规则，不新增指标，也不重新命名已有指标。

- 卡片使用 `semantic-card`，数值为第一视觉层级，指标名为第二层级，辅助说明仅在现有数据已提供时显示。
- 加载时每张统计卡显示与最终卡片等高的骨架，不用 `0` 代替未知数据。
- 查询失败时在本区显示紧凑错误反馈与“重试”按钮，不隐藏本区，不影响蓝图、最近项目和快速创作。
- 响应式下统计卡可从多列变为两列或单列；它始终是一个顶层内容区。

## 蓝图区

### Tabs

项目类型 Tabs 位于区块标题下方、蓝图卡网格上方，数据来源为系统当前有效项目类型定义。

- 默认激活系统返回的第一个有效类型；恢复状态时可回到用户当前会话内最近选择的有效 Tab。
- 一个 Tab 面板只渲染该类型且状态为 `PUBLISHED` 的蓝图。
- 无已发布蓝图的类型仍保留 Tab，激活后在当前面板显示该类型空态，不借用其他类型内容填充。
- 类型较多时横向滚动 Tabs；左右边缘提供非阻塞的溢出提示，不换成下拉框，不挤压标签文字。
- 激活项使用 `primary` 文本和下边指示线；未激活项使用 `on-surface-variant`；焦点环使用 `primary`。
- 切换 Tab 只替换面板内容，不改变页面滚动锚点，不自动打开任何蓝图。

### 蓝图卡视觉

蓝图卡参考深色横向封面卡的视觉语言：卡片为宽大于高的 `16:9` 横向比例，整张封面承载信息，局部深色不扩散为整页深色主题。

```text
┌──────────────────────────────────────────┐
│ [项目类型]                    [生产模式] │
│                                          │
│              封面图 / 类型渐变           │
│                                          │
│ 蓝图名称                                 │
│ 使用此蓝图创建项目                    →  │
└──────────────────────────────────────────┘
```

- 容器使用 `rounded.lg` 并裁切溢出，底色为 `surface-dark-container`。
- 封面铺满卡片，采用等比裁切；其上叠加由 `surface-dark` 低透明度到高透明度的纵向遮罩，保证底部文字稳定可读。
- 顶部左侧展示项目类型，顶部右侧展示生产模式；两者使用 `label-sm`、`on-surface-dark` 和 `surface-dark-container` 半透明底。
- 底部第一层为蓝图名称，使用 `h3` 与 `on-surface-dark`，最多两行，超出截断但完整名称保留在可访问名称中。
- 底部第二层为固定动作提示“使用此蓝图创建项目”和方向图标，使用 `body-md` 与 `on-surface-dark`。
- 不展示作者、头像、使用人数、点赞数、热度、虚构更新时间或任何需求未定义的统计信息。
- 卡片网格在桌面、平板、移动端分别为三列、两列、一列；同一行卡片等高。

### 封面与渐变回退

封面底层始终先渲染稳定的类型渐变，再异步覆盖有效图片，因此图片加载期间、加载失败时都不会出现空白或破图图标。

| 项目类型语义 | 回退渐变使用的现有 token | 辅助识别 |
|--------------|--------------------------|----------|
| 图像 | `secondary` → `surface-dark-container` | 类型标签“图像” |
| 视频 | `primary` → `surface-dark-container` | 类型标签“视频” |
| 文案 | `tertiary` → `surface-dark-container` | 类型标签“文案” |
| 其他系统有效类型 | 按类型 ID 通过固定表现映射选择 `primary`、`secondary`、`info` 与 `surface-dark-container` 的组合 | 必须显示真实类型标签，不以颜色单独传义 |

渐变映射属于表现层配置，不创建新的业务类型枚举。相同类型 ID 必须始终得到同一组合；新增类型未配置时使用 `primary` → `surface-dark-container` 的默认组合，并以类型文字完成消歧。

- `coverUrl` 为 `null`、空白或非法地址：不发起图片展示，直接保留类型渐变。
- 图片加载成功：在渐变底层上显示图片及深色遮罩。
- 图片加载失败：移除失败图片节点并立即露出既有渐变，不显示浏览器破图图标。
- 封面图作为装饰背景时使用空替代文本；卡片的可访问名称由蓝图名称、项目类型和生产模式组成，避免重复朗读。

### 卡片交互

- 整张蓝图卡是一个按钮，点击任意主要区域打开建项 Dialog；卡内不得嵌套第二个按钮或链接。
- 鼠标悬停时使用 `semantic-card-hover` 层级、增强遮罩对比并显示方向图标；不使用与点击无关的装饰动画。
- 键盘焦点显示清晰的 `primary` 外轮廓；`Enter` 或 `Space` 与点击行为一致。
- 触屏按下态只调整表面层级，不依赖 hover 才显示必要信息。
- 打开 Dialog 前保存所选蓝图 ID；Dialog 每次从本次选择构造上下文，不复用上一张蓝图的表单状态。

## 蓝图建项 Dialog

### 桌面结构

桌面和平板使用居中 Dialog，最大宽度 `640px`，最大高度不超过视口可用高度；内容区可滚动，标题栏与底部操作区保持可见。容器使用 `surface-container-high`、`rounded.xl` 和设计系统浮层阴影。

```text
┌────────────────────────────────────────────┐
│ 从蓝图创建项目                         ×  │
│ 使用所选蓝图初始化项目                     │
├────────────────────────────────────────────┤
│ 建项上下文（只读）                         │
│ [项目类型]  [蓝图名称]  [生产模式]         │
│                                            │
│ 项目名称 *                                 │
│ [输入项目名称___________________________]  │
│                                            │
│ IP（可选）                                 │
│ [选择 IP________________________________]  │
│                                            │
│ 渠道（可选）                               │
│ [选择渠道_______________________________]  │
│                                            │
│ ▸ 高级设置                                 │
│   补充说明（可选，展开后显示）              │
├────────────────────────────────────────────┤
│                         [取消] [创建项目]   │
└────────────────────────────────────────────┘
```

### 字段和层级

| 顺序 | 字段 | 控件与表现 | 交互规则 |
|------|------|------------|----------|
| 顶部 | 项目类型 | 只读语义标签 | 展示所选蓝图真实类型，不可编辑、不提交可篡改控件 |
| 顶部 | 蓝图 | 只读文本 | 展示完整蓝图名称；提交蓝图 ID |
| 顶部 | 生产模式 | 只读语义标签 | 展示蓝图真实模式，不可编辑 |
| 第一 | 项目名称 | 单行文本输入，带必填标记 | 去除首尾空白后校验；沿用既有长度与字符规则 |
| 第二 | IP | 可搜索单选选择器 | 可选；只展示有权使用的 IP；无数据时显示“暂无可用 IP，不影响创建” |
| 第三 | 渠道 | 沿用既有渠道选择器的选择模式 | 可选；只展示有权使用且有效的渠道；无数据时显示“暂无可用渠道，不影响创建” |
| 高级 | 补充说明 | 多行文本域 | 可选；沿用既有描述长度规则；折叠不清空内容 |

只读上下文使用 `surface-container-low` 面板集中呈现，视觉优先级低于项目名称但高于可选字段，帮助用户确认“基于哪个蓝图创建”。只读值可选择复制，但不可获得编辑外观。

### 操作与反馈

- 初始焦点落在“项目名称”；关闭按钮、取消按钮和 `Escape` 均可关闭 Dialog。
- 关闭后清理未提交表单及蓝图上下文；下一次点击其他蓝图必须创建全新状态。
- “创建项目”是唯一主按钮；“取消”为次按钮。项目名称无效时阻止提交，并在字段下显示具体错误。
- 提交后主按钮显示进行中状态和“正在创建”，同时禁用主按钮；请求完成前不产生第二次提交。
- 创建成功：宣布“项目创建成功”，关闭 Dialog，使用返回的项目 ID 直接进入新项目。
- 创建失败：Dialog 保持打开，所有输入保持不变；在操作区上方显示 `exception-card` 风格的内联错误和“重试”。
- 蓝图已下线、删除或不可访问：错误文案明确为“此蓝图已不可用，请关闭后刷新并重新选择”，不自动替换蓝图。
- 会话失效：按统一认证流程处理；不得保留一个看似可继续创建的匿名表单。

### 移动端 Dialog

小于 `768px` 时仍保持 `dialog` 语义，但视觉改为全屏面板，不缩放桌面弹窗。

- 面板占满可用视口，使用 `surface`，不使用圆角；适配安全区。
- 顶部固定标题栏包含返回/关闭按钮与标题；底部固定操作区纵向安全留白，内容区独立滚动。
- 只读上下文改为纵向三行键值，不把三个值压缩在同一行。
- 项目名称、IP、渠道均为单列全宽控件；高级设置在原位置展开。
- 底部按钮顺序保持“取消、创建项目”，主按钮宽度优先；触控目标最小 `44px`。
- 软键盘打开时保证当前输入和字段错误可见；底部操作区不得遮挡项目名称或补充说明。
- 返回键等同于关闭 Dialog；请求进行中时禁止重复提交，但不隐藏当前进度反馈。

## 最近项目

第三内容区延续既有“最近”排序口径和数量上限，不引入新的推荐算法。

### 项目卡

项目卡使用浅色 `semantic-card`，与深色蓝图卡形成“开始新项目 / 继续已有项目”的视觉分工。

```text
┌──────────────────────────────┐
│ [项目类型]                   │
│ 项目名称                     │
│ 既有状态或既有最近时间信息 → │
└──────────────────────────────┘
```

- 项目名称是第一层级，使用 `h3`；项目类型为 `label-sm`。
- 仅当既有接口提供并已在当前产品中定义时，才显示项目状态或用于最近排序的时间信息。
- 不显示项目作者、成员数、生成数量或其他未定义数据。
- 整张卡为进入项目的链接，保留标准链接语义；不得在卡内放置无需求依据的更多菜单。
- hover 使用 `semantic-card-hover`；键盘焦点使用 `primary` 外轮廓；方向图标只作进入提示。
- 桌面、平板、移动端分别采用四列、两列、一列；卡片换行不形成新的顶层区块。

### 最近项目状态

- **加载**：渲染与项目卡同尺寸的骨架，不卡住其他区块。
- **空态**：在本区显示“暂无最近项目”和“可从上方蓝图创建项目”的说明；不复制一个额外建项按钮，避免出现与蓝图卡平行的入口。
- **错误**：显示“最近项目加载失败”、原因摘要（可用时）和“重试”；蓝图和快速创作仍可操作。
- **单卡失效**：无权访问、已删除或失效项目不渲染，不用禁用卡占位。

## 快速创作

第四内容区用紧凑入口卡承载即时创作能力。六个必备入口顺序固定为：图像、视频、文案、配音、音乐、数字人；其他既有有效入口追加在其后，但仍留在同一 `section`。

### 入口卡规格

```text
┌──────────────────────┐
│ [语义图标]        →  │
│ 图像                 │
│ 进入图像创作         │
└──────────────────────┘
```

- 卡片使用 `semantic-card`；图标、标题、简短动作说明构成三级信息层级。
- 图标沿用现有图标库和 `primary` 语义，不使用临时插画或类型私有色值。
- 标题使用 `h3`，动作说明使用 `body-md` 与 `on-surface-variant`。
- 整张卡为链接；hover、focus、按下态与最近项目卡一致。
- 桌面为六列，平板为三列，移动端为两列；若追加既有入口则自动换行，不拆出第五区。

| 入口 | 卡片说明 | 点击结果 |
|------|----------|----------|
| 图像 | 进入图像创作 | 跳转现有图像创作页面 |
| 视频 | 进入视频创作 | 跳转现有视频创作页面 |
| 文案 | 进入文案创作 | 跳转现有文案创作页面 |
| 配音 | 进入配音创作 | 跳转现有配音创作页面 |
| 音乐 | 进入音乐创作 | 跳转现有音乐创作页面 |
| 数字人 | 查看数字人创作 | 进入统一创作入口并携带 `digital-human` 模式 |

数字人卡显示 `badge-warning` 风格的“尚未开放”标记。点击后仍进入统一创作容器的 `digital-human` 占位模式；占位页明确说明能力未开放，生成提交控件保持不可用，不展示模拟进度或伪造结果。

路由失败时显示可感知的错误消息“暂时无法打开，请重试”，提供“重试”操作并保留当前首页状态；不得静默、刷新整页或让卡片永久进入加载态。

## 状态设计

各区块状态独立维护。除全局认证失效外，不使用覆盖整个首页的统一加载或错误遮罩。

| 区块 | 加载态 | 空态 | 错误态 | 恢复操作 |
|------|--------|------|--------|----------|
| 统计卡 | 等高统计骨架，不显示假数值 | 沿用现有统计的无数据表达 | 本区内联错误 | 重试统计查询 |
| 蓝图 | Tabs 骨架与 `16:9` 卡片骨架 | 当前 Tab 内显示“此类型暂无可用蓝图” | 保留区块标题，显示蓝图加载错误 | 重试当前类型查询 |
| 最近项目 | 等高项目卡骨架 | “暂无最近项目” | “最近项目加载失败” | 重试最近项目查询 |
| 快速创作 | 路由配置尚未就绪时显示入口骨架 | 六个必备入口不得因业务空数据消失 | 点击路由失败使用消息反馈 | 重试同一入口 |

通用规则：

- 骨架使用 `surface-container` 与 `surface-container-high` 的明暗变化，不放置可被误读为真实内容的文本。
- 空态使用 `semantic-card`，包含标题和一行行动指引；不使用大面积插画挤压首页信息密度。
- 错误态使用 `exception-card` 结构、`danger` 状态语义和明确重试按钮；错误不能只靠颜色表达。
- 重试只请求所属区块，不重置其他区块的内容、Tab 选择或页面滚动位置。
- 数据刷新时保留已有内容并显示局部进行中反馈，避免四区整体闪烁。

## 响应式规则

断点沿用设计系统：桌面 `≥1280px`，平板 `768–1279px`，移动 `<768px`。

| 项目 | 桌面 | 平板 | 移动 |
|------|------|------|------|
| 主体 | 沿用 Studio 内容宽度，区块间距 `spacing.xl` | 全宽工作区，保留区块间距 | 单列主体，页面内边距使用 `spacing.md` |
| 统计卡 | 沿用现有多列 | 两列优先 | 一列或两列，按现有卡最小宽度决定 |
| 蓝图卡 | 三列 `16:9` | 两列 `16:9` | 一列 `16:9` |
| 最近项目 | 四列 | 两列 | 一列 |
| 快速创作 | 六列 | 三列 | 两列 |
| Tabs | 单行，溢出时横向滚动 | 横向滚动 | 横向滚动并保持当前项可见 |
| 建项 Dialog | 居中，最大宽 `640px` | 居中，最大宽 `640px` | 全屏 Dialog，固定标题与操作区 |

移动端结构示意：

```text
[统计卡区]
  [统计卡]
  [统计卡]

[蓝图区]
  < 类型 Tabs 横向滚动 >
  [16:9 蓝图卡]
  [16:9 蓝图卡]

[最近项目区]
  [项目卡]
  [项目卡]

[快速创作区]
  [图像] [视频]
  [文案] [配音]
  [音乐] [数字人]
```

页面不得通过移动端折叠、轮播分页或“查看更多”把四个区块改成不同顺序；卡片数量较多时正常纵向延展。

## 无障碍

### 页面语义

- 主体四区使用四个同级 `section`，分别通过可见标题建立 `aria-labelledby`；DOM 顺序与视觉顺序一致。
- 标题层级连续：页面标题为 `h1`，四区标题为 `h2`，卡片标题为 `h3`。
- “最近生成”不应以可见、隐藏或仅屏幕阅读器可见形式残留在首页 DOM 中。

### Tabs

- 使用 `tablist`、`tab`、`tabpanel` 语义，并正确维护 `aria-selected`、`aria-controls` 和 `tabindex`。
- 左右方向键移动 Tab 焦点，`Home`/`End` 到首尾项，`Enter`/`Space` 激活；激活后焦点不被强制移入卡片。
- 每个 Tab 的可访问名称使用真实项目类型名称；空 Tab 仍可聚焦和激活。

### 卡片与键盘

- 蓝图卡使用按钮语义；最近项目和快速创作卡使用链接语义，不用可点击 `div`。
- 所有卡片具有可见焦点环，操作不依赖鼠标 hover；触控目标不小于 `44px`。
- 蓝图背景图不重复朗读；卡片可访问名称包含蓝图名称、项目类型、生产模式和“创建项目”。
- 类型渐变不是唯一识别手段，项目类型始终以文字显示。

### Dialog 与表单

- Dialog 打开后焦点进入项目名称，背景内容不可交互；焦点限制在 Dialog 内。
- 关闭后焦点返回触发该 Dialog 的蓝图卡。
- 每个字段有可见 `label`；必填状态通过文字与 `aria-required` 表达，不只显示星号。
- 字段错误与输入通过 `aria-describedby` 关联；提交失败摘要使用 `role="alert"`，进行中反馈使用 `aria-live="polite"`。
- 高级设置使用具有 `aria-expanded` 和 `aria-controls` 的按钮；折叠不销毁已输入值。
- 选择器空态可被读出，并明确说明 IP、渠道均为可选，不阻止创建。

### 视觉与动效

- 正文、标签、焦点和错误信息满足 WCAG AA 对比度；封面文字始终位于深色遮罩之上。
- 状态同时使用文字、图标和颜色，不能只用 `success`、`warning`、`danger` 色区分。
- 骨架和状态过渡遵循 `prefers-reduced-motion`；减少动效时取消闪烁、位移和缩放，只保留即时状态切换。
- 图片加载完成不得引发卡片尺寸变化；渐变底层与固定比例预留空间以避免布局偏移。

## 交互流程

### 从蓝图创建项目

```text
进入首页
  → 蓝图区独立加载已发布蓝图
  → 切换项目类型 Tab
  → 点击蓝图卡
  → Dialog 展示只读蓝图上下文
  → 填写项目名称，可选 IP / 渠道 / 补充说明
  → 提交并锁定重复操作
     ├─ 成功：关闭 Dialog → 使用项目 ID 进入项目
     └─ 失败：保留 Dialog 与输入 → 展示错误 → 修改或重试
```

### 继续最近项目

```text
进入首页
  → 最近项目区独立加载
  → 点击有权访问的项目卡
  → 进入对应项目
```

### 快速创作

```text
点击图像 / 视频 / 文案 / 配音 / 音乐
  → 进入对应既有创作页面

点击数字人
  → 进入统一创作入口（mode=digital-human）
  → 展示“能力尚未开放”占位状态
  → 不允许提交生成任务
```

## 组件清单

| 组件 | 职责 | 关键变体 |
|------|------|----------|
| `StudioHomeSections` | 固定组织四个顶层区块 | 桌面、平板、移动布局 |
| `StatsSection` | 承载现有统计卡 | loading、ready、error |
| `BlueprintSection` | 类型 Tabs 与当前面板 | loading、ready、empty、error |
| `BlueprintTabs` | 按系统项目类型切换 | overflow、keyboard-focus |
| `BlueprintCard` | 展示蓝图并触发建项 | image、gradient-fallback、hover、focus |
| `CreateProjectDialog` | 从蓝图创建项目 | idle、validating、submitting、error、success-navigation |
| `ReadonlyBlueprintContext` | 展示类型、蓝图、生产模式 | desktop-inline、mobile-stacked |
| `RecentProjectsSection` | 最近项目列表 | loading、ready、empty、error |
| `RecentProjectCard` | 进入已有项目 | default、hover、focus |
| `QuickCreateSection` | 快速创作入口集合 | ready、route-error |
| `QuickCreateCard` | 进入既有创作或数字人占位 | standard、coming-soon |
| `SectionState` | 区块内加载、空、错误反馈 | skeleton、empty、exception |

组件命名仅用于明确职责，不要求新建与现有组件重复的实现；开发时应先复用当前 Studio 的卡片、Dialog、Tabs、选择器和消息反馈组件。

## 验收检查

- [ ] 首页内容 DOM 中只有四个同级顶层 `section`，顺序为统计卡、最近项目、蓝图、快速创作。
- [ ] 页面不存在“最近生成”区块或隐藏残留。
- [ ] 蓝图按项目类型 Tabs 组织，只显示当前类型的已发布蓝图。
- [ ] 蓝图卡为深色 `16:9` 横向视觉，并展示真实名称、类型和生产模式。
- [ ] 封面为空、非法或加载失败时显示稳定类型渐变，不显示破图。
- [ ] 蓝图卡未展示作者、使用人数或其他虚构指标。
- [ ] 点击整张蓝图卡可打开 Dialog，键盘 `Enter`/`Space` 行为一致。
- [ ] Dialog 的类型、蓝图、生产模式只读；项目名称必填；IP、渠道、补充说明可选。
- [ ] 提交中不能重复创建；失败保留输入；成功直接进入返回 ID 对应项目。
- [ ] 移动端 Dialog 为可滚动的全屏形态，固定标题和操作区不遮挡输入。
- [ ] 最近项目只展示已有真实字段，空态和错误态留在第二内容区。
- [ ] 快速创作包含图像、视频、文案、配音、音乐、数字人；前五项复用既有页面。
- [ ] 数字人进入 `digital-human` 占位模式，不能提交生成任务。
- [ ] 四区各自加载和失败，重试不影响其他区块。
- [ ] 响应式只改变区块内部列数，不改变四区数量与顺序。
- [ ] Tabs、卡片、Dialog、表单错误和动态状态可由键盘及屏幕阅读器完整操作。
