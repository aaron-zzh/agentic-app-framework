# 对话增强（AAF-047）

> 负责人：developer-service + developer-webui | 创建：05-19

## 任务列表

1. [ ] #4701 意图识别
   - 用户输入意图分类（查询/创建/编辑/导航/闲聊）
   - 意图→动作映射规则
   - 意图置信度评分
   - verify: 常见意图正确分类

2. [ ] #4702 Slash 命令
   - /命令解析器（/create /search /help /settings 等）
   - 命令自动补全（输入 / 后弹出命令列表）
   - 自定义命令注册机制
   - verify: Slash 命令触发对应动作

3. [ ] #4703 @提及实体
   - @用户、@文档、@任务 等实体引用
   - 输入 @ 后弹出搜索面板
   - 提及实体可点击跳转
   - verify: @提及正确解析并可跳转

4. [ ] #4704 内联操作
   - 对话中直接创建实体（"帮我创建一个文档"→表单弹窗）
   - 对话中编辑实体（"把标题改为 xxx"→直接修改）
   - 对话中查询（"最近的文档"→内联展示列表）
   - verify: 对话中触发 CRUD 操作成功

5. [ ] #4705 上下文感知
   - 当前页面上下文注入（用户在哪个模块/实体）
   - 选中内容作为上下文（选中文本→发送到对话）
   - 对话结果反向操作当前页面
   - verify: AI 感知当前页面上下文并正确响应
