1. [ ] #7001 素材库 CRUD

   - verify: 自动打标准确率 > 70%，筛选结果正确

### 素材复用

3. [ ] #7003 素材重复生成

   - verify: 重复生成保留原始参数，变体关联关系正确

4. [ ] #7004 快捷引用与拖拽参考

   - 拖拽引用到生成面板（拖拽素材到参考区，显示素材名称+缩略图+描述角色）
