# 图像生成（AAF-068）

> 负责人：architect + developer-service + developer-webui | 创建：05-19

## 任务列表

### 生成接口

1. [ ] #6801 文生图接口
   - 统一图像生成抽象层（ImageGenerationService 接口）
   - DALL-E 3 适配器（OpenAI API 集成、参数映射）
   - Stable Diffusion 适配器（本地/云端 API、ControlNet 支持）
   - 多模型切换策略（按质量/速度/成本自动选择或手动指定）
   - verify: 文生图请求正确路由到指定模型并返回图片

2. [ ] #6802 图生图与编辑
   - 图片→图片风格转换（参考图 + 风格 Prompt）
   - 局部编辑 Inpainting（蒙版区域 + 编辑 Prompt）
   - 图片扩展 Outpainting（指定方向扩展、保持风格一致）
   - 图片变体生成（基于原图生成相似但不同的变体）
   - verify: 图生图保持原图结构，局部编辑只修改蒙版区域

### 批量与模板

3. [ ] #6803 批量生成
   - 批量任务队列（Redis 队列、优先级排序）
   - 并发控制（按模型 API 限流、令牌桶算法）
   - 进度追踪（总数/完成数/失败数、预计剩余时间）
   - 失败重试（自动重试 3 次、失败原因记录）
   - verify: 批量 20 张图片生成任务正确执行，进度实时更新

4. [ ] #6804 参数模板
   - 预设参数模板（写实风格/动漫风格/水彩风格/像素风格）
   - 自定义模板保存（Prompt + 负面 Prompt + 尺寸 + 步数 + 种子）
   - 模板分类与搜索
   - 模板市场（公开分享、收藏、使用统计）
   - verify: 选择模板后参数正确填充，生成结果符合风格
