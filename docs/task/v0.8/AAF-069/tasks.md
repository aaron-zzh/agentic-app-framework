# 视频生成（AAF-069）

> 负责人：architect + developer-service + developer-webui | 创建：05-19

## 任务列表

### 生成接口

1. [ ] #6901 文生视频接口
   - 统一视频生成抽象层（VideoGenerationService 接口）
   - Sora / Runway / Pika API 适配器
   - 异步任务管理（提交→轮询→完成回调）
   - 视频参数配置（时长、分辨率、帧率、风格）
   - verify: 文生视频请求提交成功，异步回调正确返回视频

2. [ ] #6902 图生视频
   - 静态图→动态视频（首帧/末帧指定、运动方向控制）
   - 关键帧控制（多关键帧插值、过渡效果）
   - 运动参数配置（镜头运动：推/拉/摇/移、速度曲线）
   - 多图拼接视频（图片序列→视频、转场效果）
   - verify: 图生视频保持原图内容，运动效果符合配置

### 编辑与模板

3. [ ] #6903 视频编辑
   - 视频裁剪（时间轴裁剪、区域裁剪）
   - 视频拼接（多段视频合并、转场效果选择）
   - 字幕叠加（SRT 导入、样式配置、时间轴对齐）
   - 导出格式选择（MP4/WebM/GIF、分辨率、码率）
   - verify: 编辑操作正确执行，导出视频可正常播放

4. [ ] #6904 视频模板
   - 预设视频模板（片头/片尾/转场/字幕条）
   - 模板参数化（可替换文字、图片、颜色、时长）
   - 一键套用模板（选择模板→填充内容→生成）
   - 模板预览（缩略图 + 3 秒预览动画）
   - verify: 模板套用后生成视频内容正确，格式规范

### 前端面板

5. [ ] #6905 视频生成前端
   - UI 参考：[tmp/ui/aigc-1.jpg](../../../../tmp/ui/aigc-1.jpg)（故事板+分幕+对话生成）
   - 故事板面板（左侧）：关键元素列表（名称+描述+缩略图+标签）、元素排序拖拽、元素 CRUD
   - 分幕生成（右侧对话）：AI 对话驱动分幕生成、每幕描述+时间段、Media Assets 状态展示
   - 预览播放器：视频播放、进度条、全屏、分幕跳转
   - 时间线编辑器：可视化时间轴、片段拖拽、分幕标记
   - 生成进度展示（排队中/生成中/完成、按幕展示进度）
   - verify: 故事板→分幕→生成→预览全流程通过
