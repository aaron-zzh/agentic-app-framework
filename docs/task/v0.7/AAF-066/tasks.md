# 文档协作（AAF-066）

> 负责人：architect + developer-service + developer-webui | 创建：05-19

## 任务列表

### 自动生成

1. [ ] #6601 文档自动生成
   - 代码→API 文档（从 Controller 注解提取接口信息生成 OpenAPI）
   - EntityDef→数据字典（字段名/类型/约束/描述自动生成表格）
   - 变更→更新日志（Git commit 分析→生成 CHANGELOG 条目）
   - 模板引擎（FreeMarker 文档模板、变量注入、条件段落）
   - verify: 代码变更后自动生成的文档内容正确完整

2. [ ] #6602 规范文档看板
   - 规范文档列表（按类型分组：需求/设计/编码/测试）
   - 文档状态管理（草稿→评审→发布→归档）
   - 关联任务展示（文档关联的用户故事/技术任务）
   - 覆盖率统计（已有规范 vs 应有规范、缺失项标记）
   - verify: 文档状态流转正确，覆盖率统计准确

### 变更管理

3. [ ] #6603 变更追踪
   - 文档变更历史（每次修改记录：时间、作者、摘要）
   - diff 对比（行级 diff、新增/删除/修改高亮）
   - 变更原因记录（关联 commit hash 或任务编号）
   - 变更通知（订阅者收到变更摘要推送）
   - verify: 文档修改后历史记录完整，diff 展示正确

4. [ ] #6604 版本对比
   - 多版本并排对比（左右分栏、同步滚动）
   - 行级 diff 高亮（新增绿色、删除红色、修改黄色）
   - 评审批注（在 diff 行上添加评论、标记已解决）
   - 合并冲突解决（多人同时编辑时冲突检测与手动合并）
   - verify: 版本对比展示正确，批注功能可用

### 代码联动

5. [ ] #6605 文档与代码联动
   - 双向链接（文档中引用代码位置、代码注释引用文档）
   - 代码变更触发文档过期提醒（接口签名变更→设计文档标记过期）
   - 一致性报告（定期扫描代码 vs 文档差异、生成不一致列表）
   - 自动修复建议（检测到不一致时 AI 生成文档更新建议）
   - verify: 代码变更后关联文档正确标记过期
