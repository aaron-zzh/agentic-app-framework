# CI/CD 集成（AAF-067）

> 负责人：architect + developer-service | 创建：05-19

## 任务列表

### Git 操作

1. [ ] #6701 Git 操作封装
   - JGit 集成（仓库克隆/拉取/推送）
   - 分支管理（创建/切换/合并、分支命名规范校验）
   - Commit 生成（符合提交规范、自动填充 Task 脚注）
   - 冲突检测与报告（合并前预检、冲突文件列表）
   - verify: 程序化 Git 操作正确执行，提交格式合规

2. [ ] #6702 PR 自动创建
   - GitHub API 集成（创建 PR、更新描述、添加标签）
   - PR 模板自动填充（变更摘要、测试说明、关联任务编号）
   - 审查人自动分配（按代码路径→负责人映射）
   - PR 状态同步（开发看板任务状态与 PR 状态联动）
   - verify: 任务完成后自动创建 PR，模板内容正确

### CI 监控

3. [ ] #6703 CI 状态监控
   - GitHub Actions 状态轮询（workflow run 状态、job 详情）
   - 构建日志展示（实时日志流、错误行高亮）
   - 失败告警（构建失败→通知负责人、自动创建修复任务）
   - CI 历史统计（成功率、平均耗时、失败原因分布）
   - verify: CI 状态实时同步，失败告警正确触发

4. [ ] #6704 自动化测试触发
   - PR 创建→自动触发 check:affected
   - 测试结果回写 PR 评论（通过/失败摘要、覆盖率变化）
   - 质量门控（blocker=0 且 major≤2 才允许合并）
   - 测试失败→自动分析原因→建议修复方案
   - verify: PR 创建后自动跑测试，结果正确回写

### 部署流水线

5. [ ] #6705 部署流水线
   - 测试环境自动部署（PR 合并→自动部署到 staging）
   - 生产环境人工确认（部署审批→确认后执行）
   - 部署状态追踪（部署中/成功/失败/回滚中）
   - 回滚机制（一键回滚到上一版本、回滚原因记录）
   - verify: 测试环境自动部署成功，生产环境需人工确认
