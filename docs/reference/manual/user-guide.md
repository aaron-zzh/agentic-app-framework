# AAF 用户使用手册

> 面向使用 AAF 构建的应用的最终用户。

## 工作区概览

登录后进入工作区，左侧导航栏包含：

- **首页**：仪表盘，展示关键指标和快捷入口
- **数据模块**：各业务实体的列表/表单/看板视图
- **对话**：AI 助手对话入口
- **知识库**：文档管理与语义检索
- **流程**：工作流设计与审批
- **开发**：Auto Dev 开发控制台（开发者可见）

## AI 对话

### 基本对话

点击右下角对话图标或导航栏"对话"，打开 AI 助手面板。支持：

- 文字输入 + 语音输入（点击麦克风）
- 流式输出（AI 逐字回复）
- 多轮对话（自动记忆上下文）

### 拖放上下文

将界面中的内容拖放到对话输入框，AI 可感知完整上下文：

| 可拖放内容 | 操作方式 | AI 获得的信息 |
|-----------|---------|-------------|
| 文档 | 从文档树拖拽 | 文档标题 + 内容 |
| 图片/视频 | 从素材库拖拽 | 文件 URL + 缩略图 |
| 数据行 | 从列表行的 ⋮⋮ 拖拽 | 记录标题 + 实体信息 |
| 看板卡片 | 从卡片的 💬 拖拽 | 卡片标题 + 状态 |
| 表单字段 | 从字段的 💬 拖拽 | 字段名 = 当前值 |

拖入后显示为标签（如 `📄 文档标题`），可点击 × 移除。

### 语音交互

- 点击麦克风开始语音输入
- 支持浏览器端识别和服务端识别两种模式
- AI 回复支持语音播放（TTS）

## 数据视图

### 列表视图

- 排序：点击列头
- 筛选：点击筛选图标，构建条件
- 搜索：顶部搜索框全文检索
- 批量操作：勾选行后出现操作栏
- 列配置：点击齿轮图标调整可见列

### 看板视图

- 拖拽卡片改变状态
- 支持泳道分组
- WIP 限制（列满时高亮提示）

### 日历视图

- 月/周/日/议程四种模式
- 拖拽事件调整时间
- 点击空白创建新事件

### 画板视图

- 无限画布，自由布局
- 支持多人实时协作
- AI 辅助面板（智能元素生成）

## 知识库

### 创建知识库

1. 进入"知识库"页面
2. 点击"新建知识库"
3. 填写名称和描述
4. 上传文档（支持 PDF/Word/Markdown/HTML）

### 语义检索

在知识库详情页的"检索测试"面板中输入问题，系统返回最相关的文档片段。

### 知识图谱

可视化展示文档间的实体关系网络，支持点击节点查看详情。

## 工作流

### 发起审批

在数据详情页点击"提交审批"，选择审批流程，填写说明后提交。

### 审批操作

在"我的待办"中查看待审批事项，支持：同意、拒绝、转交、加签。

### 流程设计（管理员）

进入"流程"页面，使用可视化设计器拖拽节点编排流程。

## 个人设置

- **通知偏好**：选择接收通知的渠道（站内信/邮件/短信）
- **语音设置**：切换 STT/TTS 模式和语音
- **主题**：亮色/暗色/跟随系统
