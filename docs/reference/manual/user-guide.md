# AAF 用户使用手册

> 面向使用 AAF 构建的应用的最终用户。

## 工作区概览

登录后进入工作区，左侧导航栏包含：

- **首页**：仪表盘，展示关键指标和快捷入口
- **数据模块**：各业务实体的列表/表单/看板视图
- **对话**：AI 助手对话入口
- **知识库**：文档管理与语义检索
- **流程**：工作流设计与审批
- **开发**：Auto Dev 开发控制台（开发者可见）

## AI 对话

### 基本对话

点击右下角对话图标或导航栏"对话"，打开 AI 助手面板。支持：

- 文字输入 + 语音输入（点击麦克风）
- 流式输出（AI 逐字回复）
- 多轮对话（自动记忆上下文）

### 拖放上下文

将界面中的内容拖放到对话输入框，AI 可感知完整上下文：

| 可拖放内容 | 操作方式 | AI 获得的信息 |
|-----------|---------|-------------|
| 文档 | 从文档树拖拽 | 文档标题 + 内容 |
| 图片/视频 | 从素材库拖拽 | 文件 URL + 缩略图 |
| 数据行 | 从列表行的 ⋮⋮ 拖拽 | 记录标题 + 实体信息 |
| 看板卡片 | 从卡片的 💬 拖拽 | 卡片标题 + 状态 |
| 表单字段 | 从字段的 💬 拖拽 | 字段名 = 当前值 |

拖入后显示为标签（如 `📄 文档标题`），可点击 × 移除。

### 语音交互

- 点击麦克风开始语音输入
- 支持浏览器端识别和服务端识别两种模式
- AI 回复支持语音播放（TTS）

## 数据视图

### 列表视图

- 排序：点击列头
- 筛选：点击筛选图标，构建条件
- 搜索：顶部搜索框全文检索
- 批量操作：勾选行后出现操作栏
- 列配置：点击齿轮图标调整可见列

### 看板视图

- 拖拽卡片改变状态
- 支持泳道分组
- WIP 限制（列满时高亮提示）

### 日历视图

- 月/周/日/议程四种模式
- 拖拽事件调整时间
- 点击空白创建新事件

### 画板视图

- 无限画布，自由布局
- 支持多人实时协作
- AI 辅助面板（智能元素生成）

## 知识库

### 创建知识库

1. 进入"知识库"页面
2. 点击"新建知识库"
3. 填写名称和描述
4. 上传文档（支持 PDF/Word/Markdown/HTML）

### 语义检索

在知识库详情页的"检索测试"面板中输入问题，系统返回最相关的文档片段。

### 知识图谱

可视化展示文档间的实体关系网络，支持点击节点查看详情。

## 工作流

### 发起审批

在数据详情页点击"提交审批"，选择审批流程，填写说明后提交。

### 审批操作

在"我的待办"中查看待审批事项，支持：同意、拒绝、转交、加签。

### 流程设计（管理员）

进入"流程"页面，使用可视化设计器拖拽节点编排流程。

## 权限配置

AAF 的权限分为两类使用视角：普通业务用户只需要理解自己能看见什么、能执行什么，以及 AI 需要确认时如何处理；管理员负责配置角色、菜单、业务权限、AI 工具权限和额度策略。

### 普通业务用户

普通业务用户的权限来自所属角色。用户登录后，系统会根据角色自动决定左侧菜单、列表按钮、详情操作和 AI 可代办能力。

常见权限表现：

- 看不到某个菜单：当前角色没有绑定该菜单。
- 看得到菜单但不能新增、编辑、删除：当前角色缺少对应业务权限码。
- AI 提示"权限不足"：当前用户本人没有该业务操作或工具调用权限，需要管理员授权。
- AI 提示"需要确认"：这是当前用户可即时处理的临时授权，确认后 AI 会用相同参数继续执行。
- AI 提示"积分或额度不足"：需要充值、升级套餐，或等待额度恢复后再让 AI 重试。
- AI 代表用户调用模型或工具时，积分默认从被代表的用户账户扣减。每次模型调用都会记录 token 用量，并能和对应积分流水对账。

普通用户可处理的授权：

| 场景 | 用户能否自己处理 | 处理方式 |
|------|------------------|----------|
| 中高风险 AI 工具确认 | 可以 | 在弹出的确认/审批消息中选择同意或拒绝 |
| 同一会话内重复调用同一工具 | 可以 | 首次确认后，同会话可按授权范围自动通过 |
| 无业务权限，如删除角色 | 不可以 | 联系管理员授予对应角色权限 |
| 无工具权限，如视频生成 | 不可以 | 联系管理员授予工具权限或开通套餐 |
| 积分/额度不足 | 可以 | 充值、升级套餐或等待额度刷新 |

### 管理员

管理员通过"系统管理"配置角色、菜单和权限。推荐按"先权限码、再菜单、再角色授权、最后验证"的顺序配置。

配置步骤：

1. 进入"系统管理 / 权限码"，确认业务权限码存在，例如 `system:role:read`、`system:role:update`。
2. 进入"系统管理 / 菜单"，为菜单绑定对应权限码。菜单决定用户是否看见入口，权限码决定是否能执行操作。
3. 进入"系统管理 / 角色"，创建或选择角色，如"销售"。
4. 在角色中绑定菜单，控制左侧导航和页面入口。
5. 在角色中绑定权限码，控制按钮、接口、AI 业务动作和工具调用。
6. 使用该角色账号登录验证菜单、列表按钮、详情操作和 AI 调用结果。

常用授权示例：

| 目标 | 需要配置 |
|------|----------|
| 允许查看角色列表 | 菜单绑定角色管理入口，角色授予 `system:role:read` |
| 允许编辑角色 | 角色授予 `system:role:update` |
| 允许 AI 查询业务实体 | 授予对应实体的 `*:read` 权限，并开放 `tool:business-action:execute` |
| 允许 AI 执行业务变更 | 授予对应实体的 `*:create`、`*:update` 或 `*:delete` 权限 |
| 允许 AI 生图 | 授予 `tool:image-generate:execute`，并配置可用额度 |
| 允许 AI 生视频 | 授予 `tool:video-generate:execute`，并配置更高风险确认与额度 |

AI 工具权限建议：

- `tool:default:execute` 只给低风险通用工具使用。
- `tool:business-action:execute` 是 AI 业务动作总入口，但真正能做什么仍取决于用户自己的业务权限码。
- 生图、生视频、音乐、3D 等生成式能力应使用独立工具权限码，并在工具目录中配置风险等级、是否需要确认、额度编码和消耗成本。
- 高风险工具不要只依赖 `tool:default:execute`，应配置专属权限码和强制确认。

管理员处理 AI 返回码：

| 返回码 | 含义 | 管理员动作 |
|--------|------|------------|
| `FORBIDDEN` | 用户缺少永久权限 | 给用户角色补充业务权限码或工具权限码 |
| `PENDING_APPROVAL` | 等待用户即时确认 | 通常无需管理员处理；用户通过后 AI 可用相同参数重试 |
| `INSUFFICIENT_CREDITS` | 积分或权益不足 | 调整套餐、额度或引导用户充值；额度恢复后可重试 |
| `PENDING_CONTENT_REVIEW` | 等待内容安全审查 | 由内容审查流程处理，通过后相同 prompt 可重试 |
| `TOOL_DISABLED` | 工具未开放或被禁用 | 在 AI 工具目录中启用工具并配置权限 |

## 个人设置

- **通知偏好**：选择接收通知的渠道（站内信/邮件/短信）
- **语音设置**：切换 STT/TTS 模式和语音
- **主题**：亮色/暗色/跟随系统
