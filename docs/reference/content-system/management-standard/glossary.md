# 内容体系术语表

## 概述

AAF 文档管理系统的核心概念定义，帮助 AI 和人类理解并使用文档架构。

## 知识框架定位术语

### 知识框架定位
**定义**：通过 level × layer 两个维度确定文档认知坐标，结合 type 决定呈现方式
**作用**：让每篇文档有精确坐标，AI 可通过元数据快速检索
**参见**：[文档元数据规范](../doc-meta-standard.md)

### level（认知维度）
**定义**：描述文档的认知角度，从客观到主观的五个维度
**包含**：Reality（现实）、Thought（思想）、Theory（理论）、Practice（实践）、Meaning（意义）
**作用**：回答"从什么角度看这个问题"

### layer（抽象层级）
**定义**：描述文档的抽象程度，从普适到具体的五个层级
**包含**：Principle（原理）、Paradigm（范式）、Pattern（模式）、Model（模型）、Product（实例）
**作用**：回答"这个知识有多抽象"

### type（文档形态）
**定义**：描述文档的写作目的和阅读方式
**包含**：Tutorial（教程）、Explanation（原理）、Guide（指南）、Reference（手册）、Map（地图）
**作用**：回答"这篇文档要怎么写、怎么读"
**来源**：基于 [Diátaxis](https://diataxis.fr) 框架扩展

## layer 层级术语

### Principle（原理层）
**定义**：跨领域普适的底层规律
**关注**：第一性原理是什么？
**示例**：DRY 原则、SOLID 原则

### Paradigm（范式层）
**定义**：某领域主流的思维方式与世界观
**关注**：用什么框架思考？
**示例**：DDD 领域驱动设计、响应式编程

### Pattern（模式层）
**定义**：可跨场景复用的解决方案模板
**关注**：有什么可复用的解法？
**示例**：单例模式、观察者模式

### Model（模型层）
**定义**：特定领域可直接套用的操作模型
**关注**：具体规范是什么？
**示例**：Git 提交规范、文档元数据规范

### Product（实例层）
**定义**：单一场景下的具体实现与产出物
**关注**：实际产出是什么？
**示例**：API 文档、用户手册、项目 README

## type 类型术语

### Tutorial（教程）
**定义**：学习导向的文档，通过引导练习帮助新手入门
**特征**：零基础、循序渐进、即时反馈

### Guide（指南）
**定义**：任务导向的文档，指导完成特定任务
**特征**：步骤明确、直达目标、前置条件清晰

### Explanation（原理）
**定义**：理解导向的文档，解释概念、原理和背景
**特征**：概念解释、通俗易懂、有深度

### Reference（手册）
**定义**：查询导向的文档，提供精确的结构化信息
**特征**：结构化、可检索、技术精确

### Map（地图）
**定义**：全局导向的文档，呈现知识体系全貌与关联
**特征**：全景视图、关联关系、导航索引

## 组织规则术语

### 五度空间原则
**定义**：任何目录 = 1 个 README（索引）+ ≤ 5 个内容项（文件或子目录）
**依据**：人类工作记忆容量 ≈ 5±2
**作用**：防止认知过载，保持目录结构清晰
**参见**：[文档路由规范](../doc-route-standard.md)

### 元数据
**定义**：文档头部的 YAML Front Matter 结构化信息
**必需字段**：category、level、layer、type、status、version、date、author
**作用**：文档的"身份证"，AI 靠它定位和检索

### purpose / scope / gains
**定义**：文档目标定义的三要素
**purpose**：一句话说明目的（为什么需要这个文档）
**scope**：内容边界（包含什么、不包含什么）
**gains**：预期收获（读者能获得什么，可验证）

## 易混淆术语

### level vs layer
**level**（维度）：认知角度，回答"从什么视角看"
**layer**（层级）：抽象程度，回答"有多抽象"
**区别**：level 是横向的视角切换，layer 是纵向的深度递进

### Guide vs Tutorial
**Guide**：假设读者有背景，直接给步骤解决问题
**Tutorial**：假设读者零基础，循序渐进建立信心
**区别**：Guide 是"我要完成任务"，Tutorial 是"我要学会技能"

### Reference vs Explanation
**Reference**：跳跃查找，速查信息
**Explanation**：顺序阅读，理解原理
**区别**：Reference 回答"是什么"，Explanation 回答"为什么"
