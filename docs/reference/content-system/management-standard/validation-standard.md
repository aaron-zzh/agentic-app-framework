# 文档校验规范

## 概述

基于一致性、逻辑性、完整性三维度和结构、内容、体系三层次的 3×3 校验模型。

## 校验模型

### 3×3 矩阵

| 维度＼层次 | 结构层 | 内容层 | 体系层 |
| --- | --- | --- | --- |
| **一致性** | 格式统一性 | 术语表达一致性 | 定位体系一致性 |
| **逻辑性** | 结构合理性 | 内容逻辑自洽性 | 关联逻辑合理性 |
| **完整性** | 要素完整性 | 信息充分性 | 价值闭环完整性 |

## 校验维度

### 一致性（Consistency）

文档在格式、术语、风格、定位等方面保持统一。

- **内部一致** — 文档内的格式、术语、风格统一
- **体系一致** — 与内容体系的标准和规范对齐
- **价值导向** — 降低认知负担，让读者专注内容

### 逻辑性（Logic）

文档在结构安排、内容表达、关联建立等方面符合逻辑。

- **结构逻辑** — 章节安排、层级关系合理
- **内容逻辑** — 论证过程、因果关系自洽
- **引用逻辑** — 链接关系、依赖关系有效
- **价值导向** — 增强可信度，让读者理解和接受

### 完整性（Completeness）

文档在信息覆盖、结构要素、价值提供等方面形成闭环。

- **信息完整** — 必要信息无遗漏
- **结构完整** — 必需要素齐全
- **功能完整** — 预期价值实现
- **价值导向** — 确保可用性，让读者完成目标

## 校验层次

### 结构层

| 项目 | 说明 |
| --- | --- |
| 校验对象 | 元数据、格式规范、文件命名、版本状态 |
| 特点 | 客观可量化，易于自动化 |
| 典型问题 | 元数据缺失、格式不规范、命名不一致、链接失效 |

### 内容层

| 项目 | 说明 |
| --- | --- |
| 校验对象 | 语言风格、信息准确性、逻辑结构、示例有效性 |
| 特点 | 需要主观判断和专业知识 |
| 典型问题 | 术语不一致、信息过时、逻辑跳跃、示例失效 |

### 体系层

| 项目 | 说明 |
| --- | --- |
| 校验对象 | 知识框架定位、文档关联、架构贡献、演进合理性 |
| 特点 | 需要系统性视角和长期考虑 |
| 典型问题 | 定位不准、关联混乱、价值不明、layer 选择错误 |

## 校验矩阵详细标准

### 结构层

| 维度 | 判断原则 |
| --- | --- |
| 一致性 | 符合文件命名规范、元数据规范、格式规范 |
| 逻辑性 | 层级关系清晰、章节顺序逻辑化、导航便利 |
| 完整性 | 必需元数据完整、结构要素不缺失、状态信息明确 |

### 内容层

| 维度 | 判断原则 |
| --- | --- |
| 一致性 | 术语使用一致、语言风格统一、文档类型特征明确 |
| 逻辑性 | 论证过程合理、因果关系清晰、无逻辑错误 |
| 完整性 | 承诺信息完整、关键概念定义、示例适当有效 |

### 体系层

| 维度 | 判断原则 |
| --- | --- |
| 一致性 | level/layer/type 选择正确、分类标准一致 |
| 逻辑性 | 依赖关系有效、引用链接正确、版本演进合理 |
| 完整性 | 预期价值实现、目标读者满足、后续行动明确 |

## 人机协作

| 校验类型 | AI 负责 | 人类负责 |
| --- | --- | --- |
| **结构层** | 格式验证、元数据检查、链接检测 | 标准制定、异常判断 |
| **内容层** | 术语一致性、模式识别 | 准确性判断、价值评估 |
| **体系层** | 关联分析、趋势识别 | 战略判断、价值决策 |

协作流程：AI 初筛 → 人类审核 → 协作优化 → 持续改进

## 实施指导

### 校验优先级

| 优先级 | 校验重点 | 适用场景 |
| --- | --- | --- |
| P0 | 结构层一致性和完整性 | 所有文档 |
| P1 | 内容层逻辑性和准确性 | 面向用户的文档 |
| P2 | 体系层价值性和演进性 | 核心架构文档 |

### 校验节奏

- **实时**：结构层自动化检查
- **发布时**：内容层人工审核
- **定期**：体系层战略评估

### 质量阈值

不追求 100% 完美，确保达到**可用性阈值**：
- 结构层：90% 自动化检查通过
- 内容层：核心问题零容忍，次要问题可接受
- 体系层：战略一致，价值明确
