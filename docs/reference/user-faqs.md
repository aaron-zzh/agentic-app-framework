# 用户常见问题

> 面向产品使用者的问题解答。开发技术问题见 [开发者常见问题](dev-faqs.md)。

## 数据安全

### Q: 我的数据会被上传到云端吗？

**A**: AAF 采用多层数据安全保障：

- **业务数据**：存储在您指定的数据库中（自建或云数据库），框架不收集
- **LLM 调用**：敏感字段自动脱敏后再调用，原始数据不发送给 LLM
- **审计日志**：所有 AI 操作完整记录，可追溯、可审计

详见 [产品概述 #数据安全原则](../explanation/product-overview.md#数据安全原则)

### Q: 支持完全离线部署吗？

**A**: 支持，但有限制：

- 离线部署需要自建 GPU 集群运行本地模型
- 本地模型能力弱于云端大模型（尤其是多模态场景）
- 运维成本显著增加

对于一般企业，建议使用在线部署 + 数据安全措施。详见 [产品概述 #部署模式](../explanation/product-overview.md#部署模式)

### Q: 如何确保 LLM 不泄露我的业务数据？

**A**: AAF 提供多 LLM 分散调用机制：

- 敏感数据分片后调用不同 LLM
- 单个 LLM 只看到部分数据，无法还原完整业务语义
- 可选择企业版 API（明确数据不用于训练）

## 产品功能

### Q: AAF 能做什么？

**A**: AAF 是 AI 原生应用开发框架，核心能力：

- **多智能体协作**：AI Agent 自动执行复杂任务
- **工作流引擎**：可视化编排业务流程
- **知识库管理**：语义检索、知识图谱
- **对话式交互**：自然语言完成业务操作

### Q: 支持哪些 AI 模型？

**A**: 通过 Spring AI 适配，支持主流模型：

- OpenAI（GPT-4o、GPT-4）
- Anthropic（Claude 3.5）
- Google（Gemini 2）
- 本地模型（Ollama、vLLM）

模型可按需切换，框架层模型无关。

## 部署与定价

### Q: 如何部署 AAF？

**A**: 提供多种部署方式：

- **SaaS**：开箱即用，按需付费
- **私有云**：部署到您的云环境
- **本地部署**：完全离线运行（需自建基础设施）
