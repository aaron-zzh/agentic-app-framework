# 部署规范

> 定义测试环境和生产环境的部署流程与验证要求。

## 环境

| 环境 | 用途 | 部署方式 |
|------|------|----------|
| 测试环境 | 功能验证、集成测试、用户验收 | CI/CD 自动部署 |
| 生产环境 | 正式服务 | 🔴 人类确认后部署 |

## 部署流程

### 测试环境

1. CI 构建部署包
2. 自动部署到测试环境
3. 执行冒烟测试（核心接口可用性）
4. 冒烟失败则阻断，通知开发者

### 生产环境

1. 测试环境验证通过
2. 编写发布说明（见 [发布规范](git/release-standard.md)）
3. 🔴 人类确认发布
4. 部署到生产环境
5. 生产冒烟验证
6. 打 Git Tag

## 回滚

- 部署失败或冒烟不通过时，立即回滚到上一版本
- 回滚操作记录到 dev-log.md
