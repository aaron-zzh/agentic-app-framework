# 度量标准

迭代总结阶段使用以下指标评估过程质量：

| 指标 | 计算方式 |
|------|---------|
| 需求完成率 | 已完成 P0/P1 任务数 ÷ 计划任务数 |
| 缺陷密度 | blocker + major 数量 ÷ 交付功能点数 |
| 周期时间 | 任务从创建到完成的日历天数 |
| 回退次数 | 质量门控不通过导致的回退总次数 |

数据来源：backlog 任务状态、质量门控记录、architect `review.md`、tester `test-report.md`、qa `process-audit.md`。

## 禁用指标

| 禁用指标 | 原因 |
|---------|------|
| LOC（代码行数）速率 | 追求行数违反"价值驱动/最小可行实现"原则，激励膨胀代码 |
| 提交次数 | 激励碎片化提交，无法反映质量 |
| 文件修改数 | 与任务复杂度无关，大改动不等于高价值 |

**正确指标**：质量门控通过率、规范合规率、测试覆盖增量、回退次数（越少越好）。
