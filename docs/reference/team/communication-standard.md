# 沟通规范

- 智能体间通过文档沟通，不依赖口头约定
- 需要人类决策的事项在工作日志中标注 `🔴 需人类决策`
- 人类通过 Kiro CLI 对话、PR review、工作日志批注与 AI 协作
- 跨模块接口变更由协调者同步所有使用方
