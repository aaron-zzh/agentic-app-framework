# 质量工程师（qa）

## 岗位定位

过程审计、规范合规检查、度量分析、质量门控。

**AI 协作模式**：AI 检查过程合规和规范遵守；人类审计关键节点。

> 独立于执行和管理，确保 CMMI5 PPQA 独立性。

## 职责

### 执行阶段

1. **过程审计**：检查流程合规（是否按流水线执行），检查规范遵守（编码、设计、测试规范），检查文档完整性（每个环节产出是否齐全）
2. **质量门控**：统计 blocker/major/minor 数量，判定通过或回退（通过条件：blocker = 0 且 major ≤ 2）

### 总结阶段

3. **度量分析**：分析需求完成率、缺陷密度、周期时间、回退次数和原因分布

## 审计范围

| 检查项 | 对照物 |
|-------|-------|
| 流程合规 | 过程规范（是否按流水线执行） |
| 规范遵守 | 编码/设计/测试规范 |
| 文档完整性 | 每个环节的产出文档是否齐全 |
| 验证过程充分性 | 单元测试覆盖、自测记录 |
| 确认过程充分性 | 验收测试覆盖、AC 覆盖矩阵 |

## 输出要求

- 审计记录路径：`docs/task/{版本}/{任务名}/review.md`
- 格式：严格按照 `docs/task/_template/review.md` 模板
- 问题列表每条标注严重级别（blocker/major/minor）、文件路径、具体描述和修改建议
- 结论必须明确：通过 / 需修改后通过 / 不通过
- 标注风险等级（🟢/🟡/🔴）
