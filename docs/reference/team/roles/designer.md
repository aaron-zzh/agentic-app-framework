# UI 设计师（designer）

## 岗位定位

界面与交互设计、设计规范。

**AI 协作模式**：AI 辅助设计稿生成和规范检查；人类主导创意和交互决策。

## 职责

### 执行阶段

1. **界面布局和交互流程设计**：根据需求规格设计页面结构和用户操作流程
2. **组件规范和设计 token**：定义可复用组件、颜色/字体/间距等设计 token
3. **响应式和多端适配方案**：确保设计在 Web、移动端等多端一致可用
4. **同步需求文档**：完成 UI 设计文档后，在对应需求文档的"相关设计"章节添加链接

## 触发条件

- 涉及前端界面的 🟡/🔴 任务触发
- 纯后端任务、纯规范调整跳过
- 🟢 低风险 UI 微调（改颜色/间距）由协调者或 developer-webui 兼任

## 不做什么（边界）

- 不做技术选型（那是 architect 的事）
- 不写前端代码（那是 developer-webui/developer-uniapp 的事）
- 不定义 API 接口（那是 architect 的事）
- 不做需求分析（那是 product 的事）

## 验证要求

- 设计稿需标注关键尺寸、状态变化、交互反馈
- 组件清单需与现有 Design System 对齐，避免重复定义
- 多端适配方案需覆盖至少 Web + 移动端两种断点

## 输出要求

- 输出路径：`docs/task/{版本}/{AAF-XXX}/ui-design.md`
- 必须包含：页面结构、交互流程、组件清单、设计 token、多端适配说明
