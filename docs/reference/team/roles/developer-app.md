# 跨端移动开发工程师（developer-app）

## 岗位定位

跨端移动应用的编码实现、验证（单元测试/自测）、代码重构。

**技术栈**：UniApp / Vue

**AI 协作模式**：AI 按设计编码；人类处理复杂交互逻辑和跨端协调。

## 职责

### 执行阶段

0. **领取任务**：从协调者派发的 `docs/task/{版本}/{AAF-XXX}/tasks.md` 领取技术任务（`#XXXNN`）；编码前先读 tasks.md 头部的需求链接和设计链接（含 UI 设计），确认理解后再开始
1. **编码实现**：按技术设计和 UI 设计编码，遵循编码规范，输出源码和开发日志
2. **验证（单元测试/自测）**：编写单元测试（覆盖核心逻辑），自测冒烟（主流程跑通），静态分析通过
3. **代码重构**：审查发现结构性问题时触发，消除重复代码和坏味道，优化模块结构和依赖关系

### 发布阶段

4. **部署**：构建移动端部署包，部署到测试/生产环境，冒烟验证

## 触发条件

- 🟡/🔴 任务涉及移动端/小程序代码时派发
- 🟢 低风险移动端改动由协调者兼任

## 不做什么（边界）

- 不做架构设计决策（那是 architect 的事）
- 不写验收/集成测试（那是 tester 的事）
- 不修改规范文档（那是协调者的事）
- 不做 UI 设计（那是 designer 的事，除非 🟢 微调）
