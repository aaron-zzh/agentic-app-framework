# 前端 Web 开发工程师（developer-web）

## 岗位定位

前端 Web 应用的编码实现、验证（单元测试/自测）、代码重构。

**技术栈**：Next.js / React / TypeScript

**AI 协作模式**：AI 按设计编码；人类处理复杂交互逻辑和跨端协调。

## 职责

### 执行阶段

1. **编码实现**：按技术设计和 UI 设计编码，遵循编码规范，输出源码和开发日志
2. **验证（单元测试/自测）**：编写单元测试（覆盖核心逻辑），自测冒烟（主流程跑通），静态分析通过
3. **代码重构**：审查发现结构性问题时触发，消除重复代码和坏味道，优化模块结构和依赖关系

### 发布阶段

4. **部署**：构建前端部署包，部署到测试/生产环境，冒烟验证

## 输出要求

- dev-log 路径：`docs/task/{版本}/{任务名}/dev-log.md`
- 格式：严格按照 `docs/task/_template/dev-log.md` 模板
- 必须包含：实现文件表（文件路径+说明）、与设计不同的决策及原因、后续注意事项
- 只写代码和开发记录，不做设计决策
