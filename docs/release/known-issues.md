## 功能限制

| 功能 | 限制说明 | 计划版本 |
|------|---------|---------|
| 离线编辑 | 不支持离线数据编辑，需网络连接 | v2.0+ |
| 实时协同编辑 | Yjs WebSocket Provider 未接入 | v1.0 |
| 多语言 | 仅支持中文/英文，其他语言需自行添加 | v1.0 |
| 移动端适配 | 响应式基础布局已实现，部分复杂组件未优化 | 持续改进 |
| 导入/导出 | 仅支持 CSV 格式，XLSX/PDF 待实现 | v1.0 |
| 审批委托 | 前端 UI 已实现，后端流程引擎待对接 | v1.0 |

## 性能限制

| 场景 | 限制 | 建议 |
|------|------|------|
| 实体列表 | 超过 1000 条未启用虚拟滚动 | 使用分页，每页 ≤ 50 条 |
| 富文本编辑器 | 超长文档（>10 万字）可能卡顿 | 拆分为多个文档 |
| 知识库检索 | 向量维度 1536，大规模数据需索引优化 | 控制单知识库 < 10 万条 |
| 仪表盘 Widget | 超过 20 个 Widget 首次加载较慢 | 控制单页 Widget 数量 |
| 流程图编辑器 | 超过 200 个节点性能下降 | 使用子流程拆分 |

## 安全注意事项

| 项目 | 说明 | 建议 |
|------|------|------|
| Beta 阶段 | API 接口可能存在未发现的安全漏洞 | 不建议暴露到公网 |
| JWT 密钥 | 默认使用开发密钥 | 生产环境必须更换为强随机密钥 |
| 文件上传 | 服务端校验已实现，但未做病毒扫描 | 生产环境建议接入杀毒服务 |
| CSP 策略 | 当前使用宽松策略（`unsafe-inline`） | 生产环境收紧 CSP |
| 依赖安全 | Beta 阶段未做全量依赖审计 | 定期执行 `pnpm audit` |
| 数据加密 | 敏感字段（密码）已加密，其他字段明文存储 | 按需启用字段级加密 |
