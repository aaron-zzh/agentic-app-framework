# Release Notes — v0.11.0-beta.1

发布日期：2026-05-29

## 概述

AAF（Agentic App Framework）v0.11.0-beta.1 是首个公开 Beta 版本。本版本实现了基于结构化视图的元引擎完整体系——从配置驱动的 CRUD 应用到 AI 原生多智能体协作，覆盖企业级应用开发的全链路能力。

## 功能清单

### 核心框架（v0.1）

- **配置驱动视图引擎**：EntityDef 注册即生成完整 CRUD 应用（列表/表单/看板）
- **组件注册表**：字段类型 → UI 组件自动映射，支持自定义覆盖
- **Mixin 继承体系**：EntityDef 支持 Mixin + 继承，公共字段一处定义多处复用
- **分层错误边界**：应用级/视图级/字段级三层错误隔离与优雅降级
- **表单引擎**：条件可见性、公式字段、子表明细行、自动保存、离开确认
- **数据交互层**：通用 CRUD Hooks、搜索筛选、批量操作异步化

### 用户体系与基础设施（v0.2）

- **认证授权**：邮箱注册、微信/企业微信/钉钉 OAuth、JWT + Refresh Token
- **存储服务**：本地存储 + 阿里云 OSS + MinIO 统一抽象
- **消息基础设施**：短信、邮件、站内信、消息模板
- **任务调度**：定时任务、异步队列、任务监控与重试
- **日志与监控**：操作日志、审计日志、Prometheus 指标

### AI 对话与 LiveChatter（v0.3）

- **对话引擎**：Spring AI 多模型适配、流式 SSE 输出、上下文管理
- **AG-UI 协议**：assistant-ui 前端集成、Tool Call 渲染、人工审批
- **LiveChatter**：实时对话面板、Markdown 渲染、代码高亮、文件预览
- **语音交互**：语音输入/输出、实时语音对话模式

### 智能体与五层智能架构（v0.4）

- **五层架构**：Core → Cognition → Agent → Assistant → Team
- **记忆引擎**：AtomMemory、读写管道分离、长期记忆
- **Agent 系统**：AgentScope 薄门面、工具/MCP、Agent 池化
- **用户画像**：UserProfileService + 定期画像更新

### 知识库与 RAG（v0.5）

- **语义检索**：PgVector 向量存储、Embedding 生成、相似度搜索
- **知识图谱**：Neo4j 图谱构建、实体关系抽取、多跳推理
- **RAG 增强**：混合检索（向量+关键词+图谱）、引用溯源

### 工作流引擎（v0.6）

- **Flowable 集成**：流程定义 CRUD、任务分配与流转、条件网关
- **可视化编排**：XYFlow 流程设计器、节点拖拽、属性面板
- **审批流程**：会签/或签、加签/转签、审批记录

### Auto Dev（v0.7）

- **协调者引擎**：AI 按流程规范调度执行并同步文档
- **代码生成**：基于 EntityDef 生成后端 CRUD
- **开发看板**：任务 Kanban、状态流转、开发日志

### AIGC 多媒体（v0.8）

- **图像生成**：文生图、图生图、批量生成
- **视频生成**：文生视频、视频编辑、视频模板
- **素材管理**：素材库、标签分类、快捷引用、重复生成
- **3D 可视化**：react-three-fiber 3D 视图、AI 生成 3D 模型

### 支付与运营（v0.9）

- **支付系统**：微信支付/支付宝、订单管理、退款
- **会员积分**：积分充值、Token 额度兑换规则
- **渠道集成**：微信/钉钉/飞书机器人、Webhook
- **运营统计**：ECharts 图表、趋势统计、报表 PDF 导出

### 高级视图与语义化（v0.10）

- **日历视图**：事件 CRUD、拖拽调整、多视图
- **看板优化**：拖拽排序、泳道、WIP 限制
- **画板视图**：自由绘制、协作白板
- **AGUI 语义化**：用户操作感知埋点、组件语义化元数据
- **AIUI 组件生成**：AI 动态生成 UI 组件

### 整合验收（v0.11）

- **全链路联调**：各模块集成测试、端到端流程验证
- **性能优化**：next.config.ts 优化、包导入优化
- **安全加固**：安全响应头、CSP 策略
- **文档完善**：用户文档、API 文档、部署指南

## 破坏性变更

本版本为首个 Beta，无历史版本兼容性约束。后续正式版发布前的 API 变更将在 CHANGELOG 中标注。

**注意事项**：
- Beta 阶段 API 可能发生变更，不建议用于生产环境
- 数据库 Schema 可能在后续版本调整，请做好数据备份
