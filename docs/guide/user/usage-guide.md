# 使用指南

## 对话交互

### 基本对话

在工作区左侧选择 **对话** 模块，即可与 AI 助理交互：

- 直接输入自然语言描述需求
- 支持上下文连续对话，AI 记住历史
- `@` 提及特定 Agent 调用专业能力
- 附件上传（图片/文档/代码）

### 常用指令

| 指令 | 效果 |
|------|------|
| `/new` | 新建对话 |
| `/clear` | 清除当前上下文 |
| `/agent <名称>` | 切换到指定 Agent |
| `/workflow <名称>` | 触发工作流 |

### Tool Call

Agent 执行过程中会调用工具（搜索知识库、查询数据、执行代码等），前端实时展示工具调用过程和结果。用户可在关键操作前审批确认（HITL 人工审批）。

## 知识库管理

### 创建知识库

1. 进入 **知识库** 模块 → 点击 **新建**
2. 填写名称和描述
3. 选择向量化模型（默认即可）

### 上传文档

支持格式：PDF、Word、Markdown、TXT、HTML、CSV

上传后系统自动：
- 文档解析 → 分块 → 向量化 → 存入 PgVector
- 构建知识图谱关系（Neo4j）

### 检索测试

上传完成后可在知识库详情页测试检索效果：
- 输入问题 → 查看召回的文档片段
- 调整分块大小和召回数量优化效果

## 工作流编排

### 创建工作流

1. 进入 **工作流** 模块 → 点击 **新建**
2. 在流程图编辑器中拖拽节点
3. 连接节点定义流转逻辑
4. 配置每个节点的参数

### 节点类型

| 类型 | 用途 |
|------|------|
| 开始/结束 | 流程起止 |
| LLM | 调用大模型生成内容 |
| 知识检索 | 从知识库检索相关文档 |
| 代码执行 | 运行自定义代码逻辑 |
| 条件分支 | 根据条件走不同路径 |
| 人工审批 | 暂停等待人类确认 |
| HTTP 请求 | 调用外部 API |
| 工具调用 | 调用 MCP 工具 |

### 调试与发布

- **调试模式**：逐步执行，查看每个节点的输入输出
- **发布**：发布后可通过 API 或对话触发

## AIGC 内容生成

### 文档生成

对话中直接描述需求，AI 生成结构化文档：

```
用户：帮我写一份 Q2 季度报告大纲
AI：[生成 Markdown 文档，支持直接编辑]
```

### 批量生成

通过工作流实现批量内容生成：
- 数据源（CSV/数据库）→ 模板填充 → LLM 生成 → 人工审核 → 发布

### 多模态

- 图片理解：上传图片，AI 分析内容
- 代码生成：描述需求，生成可运行代码
- 数据分析：上传数据文件，AI 生成分析报告和图表
