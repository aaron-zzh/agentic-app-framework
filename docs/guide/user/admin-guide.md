# 管理指南

## 系统配置

### 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `DB_HOST` | PostgreSQL 地址 | localhost |
| `DB_PORT` | PostgreSQL 端口 | 5432 |
| `DB_NAME` | 数据库名 | aaf-dev |
| `NEO4J_URI` | Neo4j 连接地址 | bolt://localhost:7687 |
| `REDIS_HOST` | Redis 地址 | localhost |
| `JWT_SECRET` | JWT 签名密钥（≥32 字节） | — |
| `JWT_EXPIRE_SECONDS` | Token 过期时间 | 7200 |

### 模型配置

进入 **设置 → 模型管理**：

- 添加模型提供商（OpenAI / Azure / 本地部署）
- 配置 API Key 和端点
- 设置默认模型和 Token 限额
- 按用途分配模型（对话/嵌入/代码生成）

## 用户管理

### 用户 CRUD

路径：**设置 → 用户管理**

- 创建用户：用户名 + 密码 + 角色分配
- 批量导入：CSV 格式（用户名,密码,角色,部门）
- 禁用/启用：软删除，数据保留

### 组织架构

- 支持多级部门树
- 用户可属于多个组织（多租户）
- 顶栏切换当前工作组织

## 权限设置

### 角色管理

内置角色：

| 角色 | 权限范围 |
|------|---------|
| `admin` | 全部权限 |
| `manager` | 部门数据 + 审批 |
| `member` | 个人数据 + 基本操作 |
| `guest` | 只读访问 |

### 权限粒度

- **实体级**：控制模块可见性（能否看到客户管理模块）
- **操作级**：CRUD 分别控制（能看不能改）
- **字段级**：敏感字段隐藏/只读（薪资字段仅 HR 可见）
- **行级**：数据范围限制（只看本部门数据）

### 配置方式

1. 创建角色 → 分配实体权限
2. 配置数据权限规则（行级过滤条件）
3. 将角色分配给用户/部门

## 渠道配置

### 支持渠道

| 渠道 | 接入方式 |
|------|---------|
| Web 嵌入 | iframe / JS SDK |
| API 接入 | REST API + API Key |
| 企业微信 | 应用回调 URL |
| 钉钉 | 机器人 Webhook |
| 飞书 | 事件订阅 |
| 微信公众号 | 消息推送接口 |

### 接入步骤

1. **设置 → 渠道管理 → 新建渠道**
2. 选择渠道类型，填写对应配置（AppID/Secret/回调地址）
3. 绑定 Agent（该渠道使用哪个 Agent 响应）
4. 测试连通性
5. 启用

### 消息路由

- 每个渠道可绑定不同 Agent
- 支持关键词路由（不同问题分发到不同 Agent）
- 兜底策略：无法匹配时转人工或默认 Agent
