# 快速了解 AAF

## 产品简介

AAF（Agentic App Framework）是生产级 AI 原生多智能体应用开发框架。AI 是架构的一等公民——不只是在应用里集成 AI，而是用 AI 驱动整个开发和使用过程。

**核心能力**：

- **多智能体协作**：多个 AI Agent 并行工作，自动分工、协调、汇总
- **工作流引擎**：可视化编排业务流程，审批/自动化/定时任务一站式管理
- **知识库管理**：文档上传 → 向量化 → 智能检索，RAG 开箱即用
- **无代码开发**：对话式创建业务模块，自动建表 + API + UI
- **规范驱动**：规范是人和 AI 的共同真理来源，保证质量一致性

## 核心概念

| 概念 | 说明 |
|------|------|
| Agent | 具备特定能力的 AI 智能体，可调用工具、访问知识库、执行工作流 |
| 工作流 | 可视化编排的业务流程（审批、自动化、Agent 编排） |
| 知识库 | 结构化/非结构化文档的智能存储，支持语义检索 |
| EntityDef | 实体配置定义，驱动自动生成列表/表单/看板/API |
| MCP 工具 | Model Context Protocol 标准工具，Agent 可调用的外部能力 |
| 工作空间 | 多租户隔离的协作环境，团队独立管理 |

## 适用场景

| 场景 | 示例 |
|------|------|
| 企业内部管理系统 | CRM、OA、ERP、项目管理 |
| AI 原生应用 | 智能客服、知识问答、文档助手 |
| 业务流程自动化 | 审批流、数据同步、定时报表 |
| 低代码/无代码平台 | 对话式创建业务模块，拖拽搭建工作流 |
| 多 Agent 协作系统 | 自动开发、智能运维、数据分析 |
