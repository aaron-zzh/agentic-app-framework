# 常见问题

## 使用问题

### AI 回答不准确怎么办？

- 检查知识库是否已上传相关文档
- 调整检索参数（增加召回数量、调整相似度阈值）
- 优化文档分块策略（过大的块会稀释信息）
- 尝试更换模型（不同模型擅长不同任务）

### 工作流执行失败如何排查？

1. 查看工作流执行日志（节点级别）
2. 检查失败节点的输入参数是否正确
3. 确认外部服务（API/数据库）是否可达
4. 使用调试模式逐步执行定位问题

### 文档上传后搜索不到？

- 确认文档已完成向量化（状态为"已就绪"）
- 检查搜索关键词是否与文档内容语义相关
- 尝试调整分块大小（默认 512 token）
- 确认知识库已绑定到当前 Agent

### 如何提升对话响应速度？

- 使用更快的模型（如 GPT-4o-mini 替代 GPT-4）
- 减少知识库检索的召回数量
- 精简系统提示词
- 开启流式输出（默认已开启）

## 部署问题

### Docker 启动失败？

- 确认 Docker 版本 ≥ 24.0
- 检查端口占用：`5432`（PG）、`7687`（Neo4j）、`6379`（Redis）
- 查看日志：`docker compose logs -f`
- 确认 `.env` 文件配置正确

### 数据库连接失败？

- 确认 PostgreSQL 已启动且端口可达
- 检查用户名/密码是否正确
- 确认数据库已创建（`CREATE DATABASE "aaf-dev"`）
- 检查 `pg_hba.conf` 是否允许连接

### 内存不足？

最低要求：4GB RAM。推荐配置：

| 组件 | 最低内存 | 推荐内存 |
|------|---------|---------|
| 后端服务 | 1GB | 2GB |
| PostgreSQL | 512MB | 1GB |
| Neo4j | 512MB | 1GB |
| Redis | 256MB | 512MB |
| 前端 | 512MB | 1GB |

## 错误码说明

### HTTP 状态码

| 状态码 | 含义 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未认证（Token 无效或过期） |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |

### 业务错误码

| 错误码 | 模块 | 说明 |
|--------|------|------|
| `AUTH_001` | 认证 | 用户名或密码错误 |
| `AUTH_002` | 认证 | Token 已过期 |
| `AUTH_003` | 认证 | 无操作权限 |
| `USER_001` | 用户 | 用户名已存在 |
| `USER_002` | 用户 | 用户不存在 |
| `KB_001` | 知识库 | 文档解析失败 |
| `KB_002` | 知识库 | 向量化服务不可用 |
| `KB_003` | 知识库 | 文件格式不支持 |
| `WF_001` | 工作流 | 流程定义无效 |
| `WF_002` | 工作流 | 节点配置错误 |
| `WF_003` | 工作流 | 执行超时 |
| `AGENT_001` | Agent | 模型调用失败 |
| `AGENT_002` | Agent | 工具调用超时 |
| `AGENT_003` | Agent | Token 配额耗尽 |
| `SYS_001` | 系统 | 数据库连接失败 |
| `SYS_002` | 系统 | Redis 连接失败 |
| `SYS_003` | 系统 | 外部服务不可达 |

### 错误响应格式

```json
{
  "code": "AUTH_002",
  "message": "Token 已过期，请重新登录",
  "timestamp": "2026-05-29T15:00:00Z",
  "path": "/api/users/me"
}
```
