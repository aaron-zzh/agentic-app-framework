# UI/UX 设计

> 界面及交互体验设计文档（考虑AI时代界面个性化生成，不同用户在做相同事情或使用功能时看到的时不同界面， 同时考虑 语音交互优先、甚至摄像头实时视觉手势肢体交互、3d空间交互，AIGC带来的高速设计，动画设计及更贴近现实护眼的质感设计（如何毛玻璃、毛绒玩具风格的图标都可以实时生成），物理3d引擎的优势， 对交互界面及沉浸体验有很多新的可能）

AAF 的 UI/UX 设计围绕一个核心命题：**界面是对话的投影，不是预先设计的固定结构**。

UI（视觉呈现）和 UX（用户体验）在 AAF 中不可分割——视觉规范约束"画成什么样"，体验设计决定"怎么感受和交互"。两份文档分工明确，共同构成完整的 UI/UX 设计体系：

| [AAF 设计系统](./design-system.md)   | **UI** — 视觉 token、组件规范、样式约束     | 颜色、字体、间距、组件样式                    |
| [界面与交互体验](./ui-experience.md) | **UX** — 用户体验、交互范式、个性化、沉浸感 | 多模态交互、3D、物理引擎、AIGC 生成、情感体验 |

## AAF 设计系统

[→ design-system.md](./design-system.md)

基于 **OKLCH 颜色空间**的视觉规范，为 AI 助手生成前端代码提供约束边界。

核心内容：

- **颜色体系**：主色（智能蓝）/ 辅助色（知识紫）/ 强调色（行动橙）+ 置信度三态色（绿/黄/红）
- **字体**：中英文混排系统字体栈，代码和 DSL 使用等宽字体
- **组件规范**：置信度门控组件、多层协作可视化（Team/Assistant/Agent 三层色彩）、语义卡片、异常卡片
- **布局**：桌面双栏（工作区 + 助理区）为主，8px 网格

**置信度三态**是 AAF 独有的核心 UI 元素，贯穿所有 AI 执行路径：

```
绿（> 0.9）  →  自动执行，进度条通知
黄（0.7–0.9）→  确认卡片，等待用户决策
红（< 0.7）  →  暂停说明，转人工处理
```

## 界面与交互体验

[→ ui-experience.md](./ui-experience.md)

AI 时代的 UX 新范式，覆盖从个性化生成到沉浸式体验的完整设计思路。

核心内容：

- **个性化界面生成**：同一功能，不同用户（角色/偏好/设备）看到不同界面；AIGC 实时生成图标、插画、动效（毛玻璃、毛绒玩具、纸质等风格）
- **语音交互优先**：语音作为一等公民，与界面双向联动，共享同一套意图理解层
- **视觉与手势**：摄像头实时手势识别、表情感知、眼动追踪，隐私数据本地处理
- **3D 空间交互**：知识地图、工作流可视化、多任务空间管理，2D/3D 无缝切换
- **物理引擎**：弹性、惯性、碰撞带来直觉性操作感；流体粒子表达 AI 思考状态
- **质感设计**：毛玻璃 / 柔软质感 / 材质纹理 / 护眼模式，AIGC 按需生成
- **沉浸体验**：专注模式、空间音效、XR 未来方向（AR/VR/空间计算）

**实现路径**（对应元引擎版本）：

```
v1  语音输入、交互密度切换、标准动效
v2  AIGC 图标生成、手势交互、毛玻璃质感、专注模式
v3  3D 空间交互、物理引擎、空间音效、XR 概念验证
```

## 设计约束

所有 UI/UX 设计遵循以下约束，详见各文档：

- 个性化变体在设计系统 token 边界内生成，不允许超出
- 高级体验（3D、手势、物理引擎）是增强层，基础功能在任何设备都可用
- 摄像头、麦克风数据本地处理，不上传
- 物理引擎和 3D 渲染在低端设备自动降级，核心交互响应 < 100ms
- 所有动效尊重系统 `prefers-reduced-motion` 设置
