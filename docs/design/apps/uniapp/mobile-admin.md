# 移动管理端设计方案

> uniapp 端采用**单项目多角色 + 分包**策略，用户端与管理端共用同一小程序，管理端页面全部放入独立分包。

## 一、定位

| 维度 | 说明 |
|------|------|
| 目标用户 | 管理员、运营人员（移动场景下的轻量管理操作） |
| 与 webui 关系 | webui 是管理主入口（复杂配置、可视化编辑）；移动管理端是补充（随时查看、快速审批、简单配置） |
| 与用户端关系 | 同一小程序，角色切换，管理端页面放 `subPages/admin/` 分包 |

## 二、架构决策：单项目 + 分包

**不拆独立项目**，原因：
- 管理端操作以查看、审批、简单配置为主，体量可控
- AAF 的语义组件 DSL 支持动态页面，管理端大量页面可由后端配置驱动，无需逐页开发
- 分包机制可有效控制主包体积，管理端代码不影响用户端加载速度
- 单项目共享 platform/、store/user、api/ 等基础设施，维护成本低

**拆独立项目的触发条件**（未来按需评估）：
- 管理端分包超过 20MB
- 两端迭代节奏差异明显，互相阻塞发布
- 管理端需要独立的小程序 appid（如企业微信专属入口）

## 三、角色体系

```text
用户角色
├── 普通用户      → pages/（主包）
└── 管理员        → pages/（主包）+ subPages/admin/（管理分包）
    ├── 超级管理员  → 全部管理功能
    ├── 运营人员    → 内容管理、数据查看
    └── 租户管理员  → 本租户范围内的管理
```

角色判断在 `router/index.ts` 的 `uni.addInterceptor` 层统一拦截，进入管理分包前校验权限，无权限跳回用户端首页。

## 四、功能范围

### 4.1 用户端（主包 pages/）

| 功能 | 说明 |
|------|------|
| AI 对话 | 核心功能，完整支持 |
| 智能体广场 | 浏览、使用，创建/编辑在 webui |
| 知识库 | 查看、搜索（放分包） |
| 个人中心 | 账户设置、角色切换入口 |
| 消息通知 | 完整支持 |

### 4.2 管理端（分包 subPages/admin/）

| 功能 | 优先级 | 实现方式 |
|------|--------|---------|
| 数据看板 | P1 | 动态页面（DSL 驱动）+ uni-echarts |
| 用户管理 | P1 | 动态列表 + 简单操作（启用/禁用/角色调整） |
| 内容审核 | P1 | 列表 + 审批操作 |
| 智能体管理 | P2 | 查看状态、启用/停用 |
| 知识库管理 | P2 | 查看、简单配置（复杂操作在 webui） |
| 系统配置 | P3 | 简单 KV 配置项 |
| 工作流管理 | ❌ | 不支持，可视化编辑只在 webui |

### 4.3 功能边界原则

- **移动端做**：查看、审批、状态切换、简单表单、数据概览
- **webui 做**：可视化编辑、复杂配置、批量操作、权限精细管理

## 五、动态页面策略

AAF 的语义组件 DSL 是移动管理端的核心优势：后端下发页面配置，前端动态渲染，大量管理页面无需逐页开发。

```text
后端配置（DSL）
    ↓
uniapp 动态渲染引擎
    ↓
管理页面（列表/表单/看板）
```

**适合动态化的场景**：
- 数据列表（字段、操作按钮由后端配置）
- 详情表单（字段类型、校验规则由后端配置）
- 数据看板（图表类型、数据源由后端配置）

**不适合动态化的场景**：
- 需要复杂交互逻辑的页面
- 性能敏感的高频操作页面

## 六、分包结构

```text
src/
├── pages/                    # 主包（用户端）
│   ├── index/                # 首页
│   ├── chat/                 # AI 对话
│   └── profile/              # 个人中心（含角色切换入口）
│
└── subPages/
    ├── admin/                # 管理分包
    │   ├── dashboard/        # 数据看板
    │   ├── users/            # 用户管理
    │   ├── audit/            # 内容审核
    │   ├── agents/           # 智能体管理
    │   └── settings/         # 系统配置
    ├── knowledge/            # 知识库分包（用户端）
    └── ...
```

主包只加载用户端核心页面，管理分包按需加载，互不影响。

## 七、与 webui 的职责分工

| 操作类型 | webui | uniapp 管理端 |
|---------|-------|--------------|
| 工作流可视化编辑 | ✅ | ❌ |
| 知识库文档上传/编辑 | ✅ | ❌ |
| 智能体创建/配置 | ✅ | 查看/启停 |
| 用户权限精细管理 | ✅ | 简单角色调整 |
| 数据看板 | ✅ | ✅（移动版） |
| 内容审核 | ✅ | ✅（随时审批） |
| 消息推送管理 | ✅ | ✅ |
| 系统监控 | ✅ | 查看告警 |
