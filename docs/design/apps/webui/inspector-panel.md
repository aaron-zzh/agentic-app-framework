# Inspector 面板

> 定位：选中对象（Agent/工作流/Tool/组件）的**运行时状态、属性、执行追踪**面板，嵌入编辑器辅助区。

## 一、定位与边界

```text
编辑器（设计态）                    Playground（运行态）
┌──────────────────────┐          ┌────────────────────────────┐
│  画布/配置/校验        │  "运行"  │  输入 → 执行 → 输出 → Trace │
│  产出：DSL 定义        │ ───────► │  实时看每步状态和中间结果     │
└──────────────────────┘          └────────────────────────────┘
```

- **编辑器** = 定义"做什么"（设计态，画图/配置）
- **Playground** = 验证"做得对不对"（运行态，执行/观测）
- **不是独立页面**——是编辑器右侧/底部的调试面板（类似 IDE Debug 窗口）

## 二、调试对象与能力

| 调试对象 | 输入 | 执行过程可视化 | 输出 |
|---------|------|--------------|------|
| **Agent** | 对话消息 | Tool 调用链 + 思考过程 + 重试 | 回复 + Token 消耗 + 延迟 |
| **工作流** | 起始变量 | 每节点高亮 + 输入/输出/耗时/分支决策 | 最终结果 + 错误节点定位 |
| **Tool** | 参数表单 | 请求/响应 | 返回值 + 错误信息 |
| **Prompt** | 多组变量 | LLM 调用详情 | A/B 对比输出差异 |
| **语义组件/模板** | DSL 定义 + Mock 数据 | Props 解析 + 组件匹配 + 渲染 | 实时预览 + 交互验证 |

## 三、UI 布局

```text
┌─────────────────────────────────────────────────────────┐
│  Header：调试对象选择 | 运行按钮 | 停止 | 历史记录        │
├────────────────────────────┬────────────────────────────┤
│                            │  调试面板（右侧/底部可切换）  │
│  编辑器主区域               │  ┌────────────────────────┐ │
│  （画布/Agent 配置/         │  │ 输入区：参数表单/对话框  │ │
│    Prompt 编辑）            │  ├────────────────────────┤ │
│                            │  │ 执行追踪：              │ │
│                            │  │  节点状态/Tool 调用/     │ │
│                            │  │  LLM 请求/分支决策      │ │
│                            │  ├────────────────────────┤ │
│                            │  │ 输出区：结果/错误/指标   │ │
│                            │  └────────────────────────┘ │
└────────────────────────────┴────────────────────────────┘
```

## 四、面板实现

调试面板采用 `react-resizable-panels`（shadcn/ui Resizable 底层）实现可拖拽分割布局：

- 编辑器 ↔ 调试面板：左右或上下分割，用户可拖拽调整比例
- 面板尺寸持久化到 localStorage，下次打开恢复
- 同一组件复用于工作流编辑器、文档编辑、AI 对话 + Canvas 等场景

## 五、核心功能

### 5.1 Agent 调试

- 对话窗口：发消息 → 流式看回复
- Tool 调用追踪：每次 Tool 调用展示参数 + 返回值 + 耗时
- 思考过程：展示 Agent 的推理链（如果模型支持）
- Token 统计：输入/输出 Token 数 + 费用估算
- 上下文查看：当前对话的完整 messages 数组

### 5.2 工作流调试

- 输入表单：根据工作流 Start 节点的变量定义自动生成
- 节点执行追踪：
  - 运行中节点高亮（画布上）
  - 每节点展示：输入值 → 输出值 → 耗时 → 状态（成功/失败/跳过）
- 分支可视化：IF/ELSE 走了哪条分支
- 错误定位：失败节点红色高亮 + 错误详情
- 重跑单节点：修改某节点输入后单独重跑（不重跑整个流程）

### 5.3 Tool 调试

- 参数表单：根据 Tool Schema 自动生成输入表单
- 单独执行：不依赖 Agent/工作流，直接调用
- 响应查看：JSON 格式化展示 + 错误堆栈

### 5.4 Prompt 调试

- 变量填充：Prompt 模板中的变量可手动填值
- 多组对比：同一 Prompt 不同输入的输出并排对比
- 模型切换：快速切换不同模型看效果差异
- Token 预览：发送前预估 Token 数

### 5.5 语义组件 / 智能模板调试

- 输入模拟：手动填写 DSL 定义或从模板库选取，实时预览渲染结果
- Props 编辑器：根据组件 Schema 自动生成表单，修改 props 即时刷新预览
- 数据注入：模拟后端返回数据（Mock JSON），验证组件在不同数据下的表现
- 响应式预览：切换容器宽度（`@container` 断点），验证组件在不同面板尺寸下的布局
- 交互演练：触发组件内的按钮/表单/事件，观察状态变化和回调输出
- DSL → 组件映射验证：输入 DSL 片段 → 展示解析后匹配的组件 + 传入的 props + 渲染结果

## 六、Trace 面板（通用）

所有调试对象共享的底层观测能力：

| 指标 | 展示 |
|------|------|
| LLM 调用 | 模型/Prompt/响应/Token/延迟 |
| Tool 调用 | 工具名/参数/返回值/耗时 |
| 知识检索 | 查询/召回文档/相似度分数 |
| 错误 | 异常类型/堆栈/重试次数 |
| 耗时分布 | 瀑布图（每步耗时占比） |

## 八、参考

| 项目 | 实现方式 |
|------|---------|
| Mastra Playground | 独立页面，Agent/Workflow/Tool 三个 Tab |
| Dify | 编辑器内嵌右侧调试面板 + 底部运行日志 |
| LangSmith | 独立 Trace 平台（重观测，轻交互） |
| Flowise | 编辑器内"Test"按钮 → 弹出对话窗口 |

AAF 采用 **Dify 模式**：调试面板嵌入编辑器，不单独开页面。
