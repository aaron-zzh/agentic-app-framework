# 面向用户的工作台驾驶舱设计

区别于中台，页面操作简单易用、科技感，沉浸体验，面向终端用户，生活工作使用。

首先实现 AIGC 相关业务，内容创作，生成文案、图片、视频、辅助创作分析等。 默认暗色主题、可切换白色。兼容手机端。

支持工具自助 + 助理对话 + 定时任务的形式

## 主要功能点

### AI 生图

- 多模型生图支持 （3 国内 + 3 国外）
- 文生图
- 图像编辑
- 图片风格、参数可配置

### AI 视频生成

- 文本+图片+首尾帧转视频
- 可选 Happyhorse + Seedance 2个模型
- 视频参数配置（时长、风格、比例等）
- 口播+品牌宣传视频

### AI 智能体（文案）

- 口播文案、小红书
- 爆款复制
- 其他（自定义智能体：产品文案、商业分析、IP定位、短视频脚本、标题选题推荐...）

### 数据资产

- 提示词管理：新建、分类、检索
- 素材管理：上传、分类、检索
- 作品管理：分类、检索、下载
- 任务管理：分类查看历史

### 会员体系

- 登录/注册：支持手机验证码+微信登录。
- 会员套餐
- 积分充值、积分扣减
- 积分兑换码
- 模型能力说明与收费标准
- 微信扫码支付

### 爆款复制工作流

1. 上传爆款文案或图片
2. 分析
3. 产品文案/调整说明
4. 生成
