# 功能模块

按"业务应用层、B 端应用层、AI 能力层、数据与规则层、平台底座"组织，共 22 个模块。每个模块对应 [P0 需求规格](../../prd/memoir/一期需求规格.md) 的 P0 编号、[PRD](../../prd/memoir/产品功能.md) 的 MEM 编号和 [P0 研发任务卡](../../prd/memoir/一期任务.md) 的 T 编号。

## 分层总览

```text
业务应用层   M01 客户与项目   M02 授权合规    M03 预评估     M04 访谈辅助
             M05 转写         M06 记忆结构化  M07 家属确认   M08 成稿生成
             M09 编辑工作台   M10 事实核对★   M11 交付物     M14 订单与结算
             M15 通知协作     M21 运营后台    M22 自助版、家族档案与订阅
B 端应用层   M12 机构控制台   M13 认知友好回顾
AI 能力层    M16 模型网关与提示词治理         M17 评测与回归
数据规则层   M18 知识库与规则库               M19 数据资产
平台底座     M20 租户权限、审计、存储、任务、埋点、适老化组件
```

★ 为护栏模块，不可压缩。模块编号沿用原稿，M14、M15、M21、M22 不按层连续编号。

## P0 范围

22 个模块都含 P0 部分。2026 年 11 月起 P0 分三期研发、各 1 个月：一期是基础引擎与自助闭环，二期是最小人工链路，三期补齐全用户类型。分期以 [P0 需求规格 范围](../../prd/memoir/一期需求规格.md#范围) 为准。

- **全部在 P0（15 个）**：M01 到 M11、M17、M19、M20、M21。
- **部分在 P0（7 个）**：M12 核心、M13 记录与摘要、M14 订单与付款、M15 最小通知、M16 网关、M18 规则库与最小年代事件库、M22 自助版与家族档案。

一期自助闭环用到的模块：M22，以及它复用的 M02 授权、M05 转写、M06 结构化、M10 规则（自助模式）、M11 短片模板与 AI 标识、M16 网关、M19 方言评测集、M20 账号与底座。二期的最小人工链路另外用到转写之后的结构化、成稿、核对模块；预问卷评估、订单付款、排版交付、机构端和运营看板在三期。

它们构成一条闭环：

```text
建档授权 → 访谈转写 → 结构化确认 → 成稿 → 事实核对 → 交付
```

外加机构控制台和平台底座支撑。

P1 补充 M22 的订阅与印刷，以及 M13 的计划与增强、M14 的报价与合同、M15 的消息中心、M16 的提示词治理、M18 的外部库，在第 3 到 6 个月接入，主要用于订阅收入、提升毛利和规模化。

```text
               M14、M15、M21 横向依赖 M01
```

### 三个合流点

| 合流点 | 依赖 | 风险 |
|-------|------|------|
| M05 转写 | 工程（M20）和方言数据（M19） | 方言评测集滑期，后续全部顺延 |
| M07 家属确认 | M06 结构化、M02 授权、M15 通知 | 家属改口和补材料最容易返工；没有通知就无法执行确认时限 |
| M10 事实核对 | M08 成稿、M18 规则库、M19 金标准集、M17 回归 | 抽取误报率决定编辑工时 |

预案见 [P0 研发任务卡 关键路径](../../prd/memoir/一期任务.md#关键路径)。
