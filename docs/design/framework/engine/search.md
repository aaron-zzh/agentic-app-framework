# 搜索引擎设计

> 提供跨资源的统一搜索入口，屏蔽各引擎的检索差异。各引擎（知识库/记忆/文档）自己管各自的检索实现，搜索引擎负责聚合和统一排序。

## 搜索范围

| 资源类型 | 检索来源 |
|---------|---------|
| 知识库内容 | 知识库引擎（向量+图谱+关键词） |
| 文档 | 文档引擎（全文检索） |
| Agent / 工具 / 技能 | 注册表元数据检索 |
| 用户 / 组织 | 用户服务 |
| 市场资产 | 插件引擎（Agent/工具/提示词） |

## 核心能力

- **统一入口**：一个查询，跨多个资源并行检索，结果聚合排序
- **语义搜索**：基于向量相似度，不依赖关键词精确匹配
- **权限过滤**：搜索结果按当前用户权限过滤，不泄露无权访问的内容
- **搜索建议**：输入时实时补全，基于历史和热门搜索
