# 自进化机制

> 自进化是元引擎区别于传统引擎的核心特征。支持两类对象的自进化：引擎自身和业务系统。
> 两者共享同一套评估和审核框架，但触发条件、产物和审核级别不同。

## 两类自进化对比

| | 引擎自进化 | 业务系统自进化 |
|---|---|---|
| 触发方 | 性能异常 / 规范冲突 / 重复模式 | 用户负反馈 / 重复需求 / 行为偏差 |
| 影响范围 | 所有用户 | 当前业务 |
| 审核级别 | 全程强制人工 | 按置信度分级 |
| 产物 | 规范更新 + 重生成代码 | DSL 更新 / 重生成代码 |
| 执行者 | `aaf-auto-dev` | `aaf-auto-dev` |

## 审核分级

所有自进化变更在执行前经过审核分级，不允许绕过：

| 级别 | 条件 | 适用场景 |
|---|---|---|
| 自动执行 | 置信度 > 0.9，低风险 | 业务 DSL 小幅调整（新增字段、修改样式） |
| 用户确认 | 置信度 0.7–0.9，中风险 | 业务流程变更、权限规则调整、新增实体 |
| 人工审核 | 置信度 < 0.7 或高风险 | 引擎模块重生成、架构级变更、安全相关 |
| 硬约束禁止 | 无论置信度 | 引擎核心模块、安全代码、不可逆操作 |

## 引擎自进化闭环

引擎自进化风险高，影响所有用户，全程强制人工审核：

```text
引擎运行数据（性能指标、错误日志、用户反馈）
  ↓ 效果评估（自动分析 + 人工标注）
模式识别（哪些模块性能差、哪些规范需要更新）
  ↓
AI 生成优化方案 + 影响范围分析
  ↓ 强制人工审核（无论置信度）
规范更新（docs/）
  ↓ 人工确认规范变更
auto-dev 重生成受影响模块代码
  ↓ 沙箱编译验证 + 自动化测试
人工审核代码变更
  ↓ 确认后热部署
新一轮数据采集
```

触发条件：
- 性能指标持续异常（响应时间、错误率超阈值）
- 引擎模块规范冲突检测（代码与文档不一致）：元引擎定期扫描 `docs/` 与 `aaf-modules/` 的语义一致性，发现偏离时触发告警并生成修正任务，以文档为准，不依赖人工检查
- 新的架构模式被重复提出（N 次以上）

约束：
- 每次进化保留完整快照，支持一键回滚
- 架构级变更必须人工审核，不允许 AI 自行决定
- 安全相关代码不参与自动重生成

## 业务系统自进化闭环

业务系统自进化风险低，只影响当前业务，按审核分级自动处理：

```text
用户行为数据（操作日志、满意度、修正操作）
  ↓ 效果评估（自动 + 人工标注）
模式识别（哪些 DSL 模式效果好，哪些需要改进）
  ↓ 写入历史决策记录（供下次 AI 决策参考）
AI 生成优化方案（基于当前系统状态 + 历史决策）
  ↓ 审核分级
  ├── 自动执行  → DSL 直接更新，立即生效
  ├── 用户确认  → 对话区展示变更方案，用户确认后生效
  └── 人工审核  → AI 生成代码 → 沙箱验证 → 人工确认 → 热加载
新一轮数据采集
```

触发条件：
- 用户满意度持续下降（连续 N 次负反馈）
- 相似需求被重复提出（可系统化的重复模式）
- 业务 DSL 与实际使用行为出现偏差
- 用户主动发起优化请求

约束：
- 变更范围限定在当前业务，不影响其他业务或引擎
- 每次变更保留快照，支持回滚
- 历史决策记录持久化，保证进化方向一致性

## 与自开发的区别

| | 自开发 | 自进化 |
|---|---|---|
| 触发方 | 人类（提出需求）或 AI（发现改进点） | 系统（行为数据驱动） |
| 目标 | 实现新功能或改进现有功能 | 优化已有功能的效果和性能 |
| 审核级别 | 按置信度分级，架构变更强制人工 | 同左，引擎级变更强制人工 |
| 产物 | 新代码或修改后的代码 | 规范更新 + 重生成代码 |

两者共享同一套代码生成和热部署基础设施（`aaf-auto-dev`），区别在于触发来源和审核流程。

## 包结构与核心接口

```text
core/evolution/
├── EvolutionEngine.java            核心接口
├── BehaviorCollector.java          行为采集
├── EffectEvaluator.java            效果评估
├── EvolutionProposal.java          进化方案（含影响范围分析）
├── AuditLevel.java                 审核分级（AUTO/USER/HUMAN/BLOCKED）
└── impl/
    └── DefaultEvolutionEngine.java
```
