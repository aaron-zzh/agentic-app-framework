# 插件引擎设计

> 插件引擎是生态市场的运行时底座，负责插件的注册、加载、隔离执行和版本管理。

## 插件类型

| 类型 | 说明 |
|------|------|
| Agent 插件 | 可复用的 Agent 定义（含系统提示、技能、工具配置） |
| 工具插件 | 自定义工具实现，注册到工具引擎 |
| 技能插件 | 自定义技能，注册到技能引擎 |
| 知识库插件 | 预构建的领域知识库 |
| 提示词插件 | 提示词模板，注册到提示词库 |
| UI 组件插件 | 自定义语义组件，注册到组件注册表 |

## 核心能力

- **注册与发现**：插件元数据注册，按类型/标签/能力检索
- **动态加载**：运行时热加载，无需重启
- **隔离执行**：插件在沙箱中执行，资源限制，防止影响主进程
- **版本管理**：语义化版本，多版本共存，灰度发布
- **权限控制**：插件声明所需权限，用户授权后才能使用

## 与市场的关系

市场是插件的分发平台（上传/下载/评分/付费），插件引擎是运行时（加载/执行/隔离）。
