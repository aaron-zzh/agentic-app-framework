# 推荐引擎设计

> 推荐引擎为市场和 Assistant 提供个性化推荐，降低用户发现成本。

## 推荐场景

| 场景 | 说明 |
|------|------|
| 市场推荐 | 根据用户画像推荐 Agent/工具/知识库/提示词 |
| 技能推荐 | Assistant 根据当前对话上下文推荐可用技能 |
| 工具推荐 | Agent 执行时推荐可能有用的工具 |
| 相关内容 | 查看某个资产时推荐相关资产 |

## 推荐策略

| 策略 | 说明 |
|------|------|
| 协同过滤 | 相似用户使用了什么 |
| 语义相似 | 基于向量相似度，内容相关推荐 |
| 热度排序 | 使用次数、评分、近期活跃度 |
| 上下文感知 | 当前任务类型匹配最合适的资产 |

## 与其他引擎的关系

- 依赖**语义计算引擎**做向量相似度计算
- 依赖**积分引擎**获取资产质量评分
- 依赖**搜索引擎**做候选集召回

## 定位说明

推荐引擎同时服务框架层（技能/工具推荐）和产品层（市场推荐），是两层共用的横切能力。
