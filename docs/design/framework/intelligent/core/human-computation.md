# 人类计算支撑

> 核心思想来自 Human Computation：通过设计任务和激励机制，让用户在完成自身目标的过程中，
> 宏观上是在解决一个高价值问题。人既是用户，也是计算节点。

## 贡献行为类型

知识贡献：
- 知识标注（为知识库条目打标签、纠错、补充）
- 规范评审（评审用户故事、设计文档、DSL 定义）
- 专家知识输入（领域专家贡献专业知识）
- 知识拆解（将复杂知识拆解为可索引的原子单元）

计算贡献：
- 向量计算（本地设备参与知识索引构建）
- 小模型训练（贡献本地算力参与模型优化）
- 知识索引分片（分布式知识索引构建）

协作贡献：
- 众包任务完成（知识翻译、数据校验、内容生成）
- 反馈与评分（对 AI 输出质量打分、标注好坏）
- 游戏化任务（通过游戏形式完成高价值标注任务）

## 元引擎的职责边界

元引擎负责触发和编排，不实现业务逻辑：

| 模块 | 职责 |
|---|---|
| 元引擎 | 贡献行为事件采集、调用积分引擎、触发结算引擎、众包任务分发、知识质量评估后写入知识库 |
| 积分引擎 | 积分规则解析和执行、积分账户管理、质量评估和积分计算 |
| 结算引擎 | 智能合约调用、结算记录管理、争议仲裁工作流 |

## 积分引擎

积分是人类计算的量化层，将贡献行为转化为可流通的积分：

积分来源：
- 贡献行为积分：按贡献类型和质量评分计算
- 任务完成积分：完成众包任务获得奖励
- 游戏得分积分：游戏化任务的得分转化
- 推荐积分：邀请新用户贡献获得分成

积分质量评估：
- AI 自动评估贡献质量（准确性、完整性、一致性）
- 高质量贡献进入知识库，低质量退回重做
- 多人交叉验证，防止刷分

积分用途：
- 兑换服务额度（API 调用次数、存储空间）
- 解锁功能权限（高级功能、优先队列）
- 社区排行榜（贡献排名、等级勋章）
- 参与治理投票（社区决策权重）

积分规则：
- 规则以 DSL 定义，存储在 dev/prd 域
- 规则变更需社区投票确认，不允许单方面修改
- 所有积分记录链上存储，不可篡改

## 结算引擎

基于智能合约保证结算透明可信：

```text
贡献行为发生
  ↓ 积分引擎量化评分
积分写入用户账户（链上记录）
  ↓ 达到结算条件（周期 / 阈值）
智能合约自动触发结算
  ↓ 验证贡献有效性
积分兑换为对应权益
  ↓ 结算记录归档
用户可查询完整结算历史
```

结算约束：
- 智能合约代码开源，规则透明
- 结算不可逆，归档后不允许修改
- 争议处理走社区仲裁流程，元引擎提供仲裁工作流
