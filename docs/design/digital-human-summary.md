## ✅ 已完成的架构决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 模块一实现方式 | AIGC Blueprint | 完整的版本管理、候选治理、Assistant 协助 |
| 图像生成 API | 复用现有阿里云 | 已对接，无需额外集成 |
| TTS 能力 | 阿里云预设音色 | 5-6 个常用音色足够，无需克隆 |
| 3D 模型 | 暂不支持 | 仅使用 2D 头像图片 |
| 快速工具 | 不保留 | 统一使用 Blueprint 流程 |
| 助理关联 | 双向绑定 | DigitalHuman ↔ Assistant |
| 组织共享 | 支持 | organizationId 字段 + 权限控制 |
| 分组方式 | 仅标签 | tags 字段，不需要文件夹 |
| Hyperframes 对接 | 已有 API | 直接对接 |
| 简单视频生成 | 阿里云 | 提示词 + 参考图 |
| 视频时长约束 | 单段 ≤15秒，总长 ≤600秒 | 阿里云限制 |
| 场景编排 | 完整支持 | 视觉、文字、音频、转场，取决于 Hyperframes |
| 积分消耗 | 按实际成本 | 不预设标准，由执行器返回 |
| 审批流程 | 无需审批 | 创建后直接可用 |

## 🚨 风险与缓解

### 技术风险
1. **Hyperframes API 能力不确定**
   - 缓解: 先实现核心功能，场景配置逐步对接
   
2. **阿里云视频生成质量**
   - 缓解: 提供候选机制，允许重新生成

3. **大量并发生成**
   - 缓解: 队列系统 + 限流

### 业务风险
1. **积分消耗计算复杂**
   - 缓解: 执行器返回实际成本，灵活调整

2. **用户对视频质量不满意**
   - 缓解: 候选机制 + 场景编辑器
