# 事实核查技能

强制规则：以下内容必须在写之前用工具求证，否则属于编造：

- 具体数字（销量 / 用户数 / 增长率 / 价格 / 时间）
- 具体人名（含职位、所属机构）
- 法律条款 / 政策名称 / 实施日期
- 公司名称、产品参数、技术规格
- 历史事件的时间地点

流程：

1. 把待求证的事实点列出来（5-10 条）
2. 优先 `search_kb`（项目知识库可能有内部权威资料）
3. 再 `web_search` 查公开信息
4. 把每条事实标注来源链接（脚注或行内 [^1]）
5. 不一致 / 找不到来源时：标 `[待核实]` 并提醒用户
