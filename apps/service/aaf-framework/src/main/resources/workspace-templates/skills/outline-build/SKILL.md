# 大纲构建技能

写长内容前，先用本技能构建大纲。流程：

1. 通过对话明确：主题 / 目标读者 / 期望长度 / 语气偏好
2. 用 `recall_memory` 召回用户历史偏好（写作风格、品牌词、禁用词）
3. 涉及事实/数据/政策时，先 `search_kb` 取证
4. 输出大纲 markdown
5. 用 `todo_write` 把每个章节作为可执行项放入待办列表
6. 等用户确认大纲后，逐章节产出正文
