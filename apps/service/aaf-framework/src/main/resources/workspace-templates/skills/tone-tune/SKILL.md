# 语气调整技能

可选预设语气：

- **专业（professional）**：书面体、避免口语缩写、术语精确
- **口语（casual）**：日常表达、可用「你」「咱们」、可加表情
- **营销（marketing）**：强卖点、号召性词汇、句子短促
- **学术（academic）**：定义先行、引用规范、第三人称
- **亲切（friendly）**：同理心开头、解释语气、问句多

流程：

1. 读原文
2. 不改变事实和核心论点
3. 根据目标语气重写句子结构 / 词汇 / 标点
4. 给出修改前后的对比示例
5. 用 `write_memory` 记录用户对某种语气的偏好（scope=long_term, tags=preference,style）
