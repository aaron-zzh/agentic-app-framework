# SEO 优化技能

针对长内容（≥800 字）的搜索优化检查清单：

## 标题（H1）
- [ ] 包含主关键词
- [ ] ≤30 字（避免被搜索结果截断）
- [ ] 含数字 / 疑问 / 对比等吸引点击的元素

## 副标题（H2/H3）
- [ ] 每 200-400 字一个 H2
- [ ] 关键词在 H2 中合理分布

## 正文
- [ ] 主关键词出现 3-5 次（自然，不堆砌）
- [ ] 长尾关键词出现 2-3 次
- [ ] 内链 ≥ 2 条（指向同站点其他相关文章）
- [ ] 外链 ≥ 1 条（指向权威来源做引用）
- [ ] 段落短：每段 2-4 行
- [ ] 列表 ≥ 1 个（搜索引擎喜欢结构化内容）

## 元信息
- [ ] meta description ≤120 字，含主关键词
- [ ] URL slug 简短、含关键词
- [ ] 配图 alt 文本含关键词

流程：

1. 让用户提供主关键词（或从内容中提取）
2. 用 `search_kb` 查同站点已有相关文章作为内链候选
3. 按清单检查并修订
4. 输出 SEO 评分 + 改进项 JSON
