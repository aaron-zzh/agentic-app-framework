# 售后与常见问题

> 演示资料：规则为虚构，用于 AAF 智慧农业演示。

## 售后规则

- **配送签收时**：请当面检查数量和外观，发现压损、腐烂或数量不符，可当场拒收对应部分或拍照联系客服。
- **签收后 24 小时内**：因品质问题（如腐烂、严重压伤）可凭照片申请补发或退款，草莓等易损水果请在签收当天反馈。
- **不支持退换**：个人口味原因、签收超过 24 小时，或保存不当导致的变质。
- **到园采摘**：现场称重前可挑选，结算后不退换。

## 保存建议

| 产品 | 保存方式 | 建议食用时间 |
|---|---|---|
| 草莓 | 不清洗、冷藏 0 至 4℃ | 2 天内 |
| 番茄 | 未完全转红的常温放置，熟透后冷藏 | 3 至 5 天 |
| 黄瓜 | 保鲜袋包好冷藏 | 3 天内 |
| 生菜 | 用湿纸巾包根部后冷藏 | 2 至 3 天 |
| 辣椒 | 保鲜袋冷藏 | 5 至 7 天 |

## 常见问题

**问：你们的蔬菜打农药吗？**
答：农场以农业防治、物理防治和生物防治为主，确有需要时按规定使用登记农药，并严格遵守安全间隔期，采收前不用药。种植档案可查询。

**问：是有机蔬菜吗？**
答：农场目前没有有机认证，不宣传为有机产品。

**问：草莓为什么有的大有的小？**
答：同一株草莓不同花序的果实大小不同，属于正常现象，口感不受影响。

**问：可以开发票吗？**
答：企业采购可以开具发票，请在下单时告知开票信息。

**问：下雨天还能采摘吗？**
答：采摘在温室内进行，一般不受下雨影响；遇暴雨、大雪等恶劣天气，农场会提前联系改约。

**问：可以带小朋友来吗？**
答：欢迎亲子采摘，请家长全程陪同，注意棚内温度和地面湿滑。
