# 农场产品与产地介绍

> 演示资料：农场名称、地址、产品与价格均为虚构，用于 AAF 智慧农业演示，价格与演示工具数据保持一致。

## 农场简介

青禾生态农场位于示例县青禾镇，现有标准化日光温室 3 栋，种植番茄、黄瓜、草莓、生菜和辣椒。农场采用滴灌水肥一体化和物联网环境监测，每个大棚实时采集温度、湿度、光照和土壤含水率，按数据精细管理。

种植过程以农业防治、物理防治和生物防治为主，严格遵守农药安全间隔期，产品可提供种植档案查询。农场目前未申请有机认证，宣传中不得使用"有机"字样。

## 推荐宣传要点

- **新鲜**：当天采摘、当天配送，到园采摘现摘现尝。
- **看得见的种植**：大棚环境数据实时监测，种植档案可查。
- **亲子体验**：草莓采摘适合家庭周末出游。
- **合规提醒**：不使用"最好""第一""零农残""纯天然"等无法证明的表述。

单次采购 50 kg 以上可联系农场客服洽谈团购价格；企业福利、节日礼盒可提前 7 天预订。
