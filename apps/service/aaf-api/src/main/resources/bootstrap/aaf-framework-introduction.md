# Agentic App Framework（AAF）框架介绍

AAF 是一个面向 AI 原生应用的生产级开发框架，帮助团队以规范、组件和自动化能力构建多智能体应用。

## 核心能力

- 多智能体协作：通过 Assistant、Role、Skill 与 Tool 组织任务执行和协作。
- 知识库与检索：文档经解析、分块、向量化和事实抽取后，可用于语义、关键词和图谱混合检索。
- 工作流与自动化：以工作流、任务队列和事件机制承载确定性业务流程与异步执行。
- 规范驱动开发：需求、设计、代码和验证产物协同演进，减少实现与目标之间的偏差。
- 可观测与治理：支持模型路由、调用审计、权限、成本与运行状态管理。

## 分层架构

AAF 由交互层、服务层、智能层、引擎层和基础设施层组成。业务模块位于服务层，复用智能层和引擎层提供的通用能力；数据由 PostgreSQL、向量检索、Redis 与可选的 Neo4j 图投影共同支撑。

## 知识库工作方式

知识库的 PostgreSQL 真相数据、文档分块和向量投影是主要检索基础。Neo4j 仅承担事实关系的只读加速投影：图数据库暂不可用时，知识库文档仍可创建和入库，图投影可在 Neo4j 恢复后由管理员重建。

## 使用建议

将项目背景、领域术语、架构决策和操作指南导入知识库。Assistant 在执行任务时可以基于权限和上下文选择相关知识，生成更贴合项目实际的回答。
